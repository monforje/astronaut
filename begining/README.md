# Astronaut

Платформа интеграции данных и мастер-данных для российского рынка: FROM → BY → TO плюс золотая запись. Материалы на 29.10.2026.

| Папка | Что внутри |
|---|---|
| `00-brand/` | Бренд: цвета, шрифты, голос, логотип |
| `01-research/` | DATAREON: техника, интеграции, бизнес, документация; практика золотой записи |
| `02-strategy/` | Бизнес-идея и отличия, go-to-market, рынок |
| `03-requirements/` | Функциональные требования к MVP и бизнес-кейсы B1–B6 |
| `04-analyst-brief/` | Первое ТЗ для аналитика |
| `05-mvp-ui/` | Кликабельный прототип без бэкенда: откройте `index.html` |
| `06-pitch/` | Питч, вопросы и ответы, демо-сценарий |
| `07-presentation/` | Презентация (`index.html`, стрелки ← →, печать в PDF через Ctrl+P) и скриншоты |

Пересобрать скриншоты после правок прототипа: `07-presentation/make-screens.sh` (нужен google-chrome).

# Демо-сценарий: кликабельный прототип Astronaut

Длительность 4–5 минут. Прототип: открыть `05-mvp-ui/index.html` в Chrome. Бэкенда нет, все ответы заготовлены — не уходите с маршрута.

## Перед демо
- Открыть `05-mvp-ui/index.html#/overview`, масштаб браузера 100%, окно не меньше 1280 px по ширине.
- Перезагрузить страницу перед началом: состояние хранится только в памяти, перезагрузка сбрасывает демо.
- Второй вкладкой держать презентацию `07-presentation/index.html` — на случай, если что-то пойдёт не так, показываем скрины.

## Сюжет
Компания «ТД Полюс», дистрибьютор: 1С:УТ и 1С:ERP, сайт на 1С-Битрикс, Битрикс24 у оптовиков, amoCRM у розницы, хранилище на PostgreSQL, MongoDB у мобильного приложения, S3 для архива, API службы доставки.

## Шаги

### 1. Обзор (30 с)
**Экран:** Обзор.
**Говорим:** «Это то, что видит руководитель интеграций утром. Восемь потоков, десять систем, больше 76 тысяч сообщений сегодня. Справа — что требует внимания, и у каждой строки есть действие».
**Показать:** блок «Требует внимания», красную точку у заказов с сайта.

### 2. Поток и четыре способа сборки (60 с)
**Клик:** в таблице «Потоки» внизу — «Контрагенты: 1С:УТ → Битрикс24».
**Говорим:** «Поток — это откуда, как, куда. Сверху траектория: справочник контрагентов из 1С, проверка ИНН, компании в Битрикс24».
**Клик:** переключатель «Как собираем» по очереди: Low-code → Terraform → Код (переключить язык TypeScript → Go → Python) → снова Low-code.
**Говорим:** «Это один поток. Аналитик правит мышкой, разработчик — кодом в git, DevOps — в Terraform. Версия одна».

### 3. AI-помощник (60 с)
**Показать:** в таблице маппинга три красных «не сопоставлено».
**Клик:** «Попросить AI» → в чате кнопка «Предложи маппинг для пустых полей».
**Говорим:** «AI предлагает три сопоставления с уверенностью. Обратите внимание: модель видела только названия и типы полей, не данные клиентов. И она ничего не применяет сама».
**Клик:** «Применить». Таблица обновится, поля отмечены «AI, принято».
**Клик:** «Выкатить» → показать диф и проверки в окне → «Отправить на согласование».
**Говорим:** «В продуктив — только через согласование администратора, и всё это пишется в журнал».

### 4. Ошибка и повтор (60 с)
**Клик:** «Мониторинг» в меню → фильтр «Ошибки» → строка «Заказ №48211».
**Говорим:** «Заказ с сайта не дошёл до 1С. Вот весь его путь по шагам. Он записан в журнал на двух узлах — потерять его нельзя. Падение на проверке контракта: пустой склад».
**Показать:** красный блок «Почему не доставлено». «Это объяснение собрано по журналу и контракту, без AI».
**Клик:** «Предложить исправление (AI)» → «Применить в черновик».
**Клик:** «Повторить отправку». Статус станет «Доставлено».
**Говорим:** «Исправили правило, повторили — заказ в 1С. Без звонка клиента».

### 5. Мастер-данные (60 с)
**Клик:** «Мастер-данные» в меню.
**Говорим:** «12 480 контрагентов в четырёх системах — это 9 112 реальных компаний. 2 084 объединены автоматически по ИНН и КПП, остальные похожие ждут стюарда».
**Клик:** «ООО «Северсталь-Логистик»».
**Говорим:** «Три записи одной компании. Зелёным — какое значение выжило по правилам и почему: доверенный источник, самое полное, самое свежее. Адрес приведён к ФИАС, телефон — к одному формату».
**Клик:** в колонке «1С:УТ 11 — центральная» по строке Email — выбрать info@ вместо zakaz@. Подпись в золотой записи станет «выбрано вручную».
**Клик:** «Объединить в золотую запись».
**Говорим:** «Золотая запись создана, исправления уйдут обратно в 1С:ERP и Битрикс24. Объединение можно отменить 30 дней».

### 6. Доверие (30 с, если есть время)
**Клик:** «Настройки» → блок «AI-помощник».
**Говорим:** «Передача данных модели заблокирована, автоприменения нет. Выключаем AI — платформа работает так же».
**Клик:** выключатель «AI-помощник включён».

## Если что-то пошло не так
- Экран застрял или состояние сбилось — перезагрузить страницу, вернуться на нужный шаг по меню.
- Нет интернета: шрифты подгружаются из Google Fonts; без сети интерфейс останется рабочим со системным шрифтом.
- Не работает браузер — переключиться на презентацию, слайды 4–8 повторяют демо скринами.

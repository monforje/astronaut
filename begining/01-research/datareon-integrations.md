# DATAREON — интеграции

Единого каталога готовых интеграций в открытых источниках нет: раздела «Интеграции» с полным списком на сайте не нашёл. Ниже собрано по кейсам и обзорам.

## Подтверждено
| Система | Как интегрируется | Источник |
|---|---|---|
| 1С (ЗУП, УХ и др.) | Готовый модуль-коннектор. Версии от 8.3.9. Связь через внешнюю компоненту (UDP/TCP) или HTTP REST. | Habr, PDF вендора, кейс workspace.ru |
| Битрикс24 | Курсы по двусторонней интеграции. В кейсе данные о задачах берутся через API-методы DATAREON. | datareon.ru, workspace.ru |
| MS SQL, PostgreSQL, Oracle | Нативные коннекторы: запросы, хранимые процедуры, транзакции. | Habr |
| Другие СУБД | Через ADO.NET/ODBC. | Habr |
| REST и SOAP | Клиент и сервер, у сервера есть Swagger UI. | Habr |
| Kafka, RabbitMQ | Kafka через TCP, RabbitMQ через AMQP. | Habr |
| Файлы, FTP, AS2 | XML, CSV, Excel и др. | Habr |
| E-mail, AD/LDAP | SMTP/IMAP, чтение и запись в AD. | Habr |
| Power BI | Потребитель: забирает данные из витрин DATAREON через API. | workspace.ru |
| AXELOT WMS | Упоминается в кейсах WE FRY, «Импэкс», «Протэк» (WMS ↔ КИС). | datareon.ru |
| SAP, Microsoft | Заявлено вендором в письме для ОКИТ 2022, готового коннектора там не названо. | 4cio.ru |

## Не подтверждено
Готовых коннекторов к «Честному знаку», ЭДО (Диадок, СБИС) и CRM, кроме Битрикс24, не нашёл. Такие интеграции, скорее всего, делаются через REST/SOAP и C#-обработчики.

## Как это работает на практике
Даже с 1С готового «включил и работает» нет. По обзору «Белого кода», для каждого объекта нужно:
1. создать тип данных;
2. написать обработчики чтения и записи;
3. настроить маршрутизацию.

«Интеграции» здесь — универсальный набор протоколов плюс ручная настройка под систему. Исключение — модуль 1С, у которого есть готовая инфраструктура.

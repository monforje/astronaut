# DataTable

Таблица для рабочего списка: вкладки-статусы, поиск и фильтры, сортировка, выбор строк, плотность, страницы и состояния загрузки, ошибки и пусто.

DataTable — основной экран работы с грузами и документами. Граница — кольцо карточки поверх содержимого (видна по бокам в обеих темах); шапка закреплена; цифры и номера в Onest с tabular-nums, не моноширинные. Строка открывает карточку объекта, флажок — выбирает для массовых действий: это разные жесты.

- **id:** `data-table`
- **Группа:** Таблицы (`tables`)
- **CSS-префикс:** `ds-dtable`
- **Origin хореографии:** mockup (8), proposal (1)

## Когда использовать / не использовать

### Использовать

- Граница — кольцо карточки: видно по бокам в светлой и тёмной теме.
- Строка и флажок — разные жесты: клик по строке открывает объект, флажок выбирает.
- Числа вправо, tabular-nums; номера контейнеров Onest 600, не Fira Code.
- В колонке статуса фиксируйте ширину (170): бейдж не должен сдвигать соседей.
- Пустая и пустая-после-фильтра таблицы различаются: «создайте» против «сбросьте».
- Скелетон повторяет высоту строки выбранной плотности.
- Одно главное действие в тулбаре (Primary), массовые действия — в панели выбора.

### Не использовать

- Левая цветная полоска у строки как акцент выбора: выбор — фоном --selected и флажком.
- Моноширинный шрифт для ID, номеров и сумм.
- Сортировка и выбор в одной кнопке заголовка: флажок «все» — отдельная колонка.
- Больше одной строки действий над таблицей (вкладки, тулбар, чипы — каждый слой своё).
- Сжимать колонки статуса до «…»: статус читается целиком или не показывается.
- Прокрутка всей страницы вместо области таблицы, когда строк больше 25: теряется шапка.

## Анатомия

1. **Контейнер** — ds-card ds-card--flush: радиус 14, overflow clip, кольцо 1px --border поверх содержимого (видно по бокам в обеих темах).
2. **Вкладки-статусы** (необязательная) — Высота 44, счётчики в чипах; бегущая линия 2px под выбранной. Меняют набор строк, а не раздел страницы. Необязательны.
3. **Тулбар** (необязательная) — Высота 52: поиск 260 слева, фильтры-кнопки, «Колонки»; справа одно главное действие (Primary sm).
4. **Чипы фильтров** (необязательная) — Появляются под тулбаром при активном фильтре: «Поиск: MSKU» с ×, справа «Сбросить всё». Фон --surface-muted.
5. **Шапка** — Высота 40, sticky, фон --surface-muted, 12/600, линия --border снизу. Сортировка — кнопка с подложкой на hover, цикл asc → desc → сброс.
6. **Строка** — Высота 36 / 48 / 56 по плотности. Первая колонка — флажок. Hover — слой 4 %, выбранная — --selected. «Копировать» и «⋯» появляются на hover.
7. **Панель выбора** (необязательная) — Над подвалом: «Выбрано: N», действия над строками (Выгрузить, Сверить, В архив — destructive) и сброс выбора справа.
8. **Подвал** — «Выбрано: N из M», строк на странице, «с–по из M», кнопки страниц 28 × 28 с «…»; текущая — aria-current.

## Варианты

- **Со вкладками и тулбаром** (`full`): Основной вид списка: вкладки, тулбар, шапка, строки, подвал. Строка открывает карточку объекта справа (в макете — разделённый экран). Когда: главный список раздела: грузы, документы, расхождения.
- **Встроенная** (`embedded`): Без вкладок и тулбара: только шапка, строки и подвал. Для таблицы внутри карточки объекта. Когда: короткий список связанных записей: документы груза, события.
- **Линии: горизонтальные** (`lines-h`): Разделитель --divider между строками. Вариант по умолчанию. Когда: обычный список, колонки разной ширины.
- **Линии: сетка** (`lines-grid`): Вертикальные разделители между колонками (--divider) и горизонтальные. Когда: сверка значений по колонкам, много чисел.
- **Линии: зебра** (`lines-zebra`): Чётные строки темнее на 55 % от --surface-muted, горизонтальных линий нет. Когда: длинные широкие строки, глаз теряет строку.
- **Закреплённая шапка** (`sticky`): Область таблицы с фиксированной высотой: шапка остаётся при прокрутке, подвал и панель выбора — за пределами прокрутки. Когда: высота экрана ограничена, строк много (12–50 на странице).

## Состояния

### Применимые

- **Default · строка** (`default`): Фон --surface, разделитель --divider. Кнопки строки скрыты.
- **Hover · строка** (`hover`): Слой ink 4 % поверх фона строки; проявляются «копировать» и «⋯».
- **Active · строка** (`active`): Слой 7 %. Если нажато на кнопку или флажок внутри строки, слой строки не меняется.
- **Focus · строка** (`focus`): Контур 2px --focus внутри строки (offset −2, чтобы не резался overflow).
- **Selected · строка** (`selected`): Фон --selected, флажок включён, aria-selected. Открытая в карточке строка выглядит так же.
- **Сортировка в шапке** (`other`, `sort`): Hover: подложка 9 %, значок 100 %. Отсортированная: значок «вверх» или «вниз», aria-sort.
- **Loading** (`loading`): Скелетон на месте строк, шапка остаётся, флажок «все» выключен. aria-busy на таблице.
- **Error** (`error`): В теле — ошибка, причина и «Повторить». Тулбар и вкладки живы.
- **Empty** (`empty`): Значок, «Грузов пока нет», два действия: главное и «Подключить 1С».
- **Ничего не нашлось** (`empty`, `noresults`): Фильтр или поиск ничего не дали: «Сбросить всё» вместо создания.

### Не применимы (с причиной)

- **Disabled** (`disabled`): Таблицу целиком не отключают. Недоступные действия — disabled у кнопок и вкладки «Архив»; в loading, empty и error флажок «выбрать все» выключен.

## Доступность

- **role=grid, columnheader** (`aria`): Таблица role="grid" (есть интерактивные ячейки), у заголовков scope="col" (columnheader), aria-rowcount; строка — aria-selected у выбранной. [TODO] определить, нужен ли полный grid-паттерн с навигацией стрелками по ячейкам: в макете Tab идёт по строкам и контролам.
- **aria-sort** (`aria`): У сортируемых колонок aria-sort=none | ascending | descending на <th>; кнопка внутри называется по заголовку. Цикл asc → desc → сброс; сброс возвращает none.
- **aria-busy и aria-live** (`aria`): Таблица в загрузке — aria-busy=true; результат («Найдено 6», «Выбрано: 2») объявляйте в aria-live=polite. [TODO] в макете live-области нет.
- **Tab / Shift+Tab** (`key`): Порядок: тулбар, вкладка выбранная, шапка (сортировка), строки: флажок → «копировать» → «⋯» → следующая строка, затем панель выбора и подвал.
- **Enter / Space** (`key`): На строке — открыть карточку; на флажке Space; на кнопке заголовка — сортировка; на странице — перейти.
- **← / →** (`key`): На вкладках статуса переключают вкладку и переносят фокус (предложение).
- **Контур 2px --focus** (`focus`): У строки — внутрь (outline-offset −2), чтобы overflow таблицы его не резал. У остальных — вокруг элемента.
- **Шапка и подписи** (`contrast`): --text-2 на --surface-muted: светлая 7,1:1, тёмная 9,7:1. Флажок: рамка --text-3 на --surface 4,9:1 (≥ 3:1). Тон err у значка ошибки --err-text — как у бейджа.
- **Слои hover и selected** (`contrast`): Текст на --selected (teal 15 %) — --text, запас большой. Слой 4 % на строке контраст текста почти не меняет. Различие selected и hover только по фону 4 % не спасёт при дальтонизме: у выбранной строки стоит и флажок. [TODO] проверить различимость selected и hover на плохих мониторах.
- **prefers-reduced-motion** (`motion`): Переходы слоёв, бегущая линия вкладок, появление панели выбора и градиент скелетона отключаются.

| 1100 | 125 | Нажатие на строку (не на кнопку внутри): слой 7 %; по отпусканию строка открывается в карточке и становится --selected. | background | ease |
| 2300 | 0 | Фокус с клавиатуры: контур 2px внутри строки; Enter или Space открывают карточку. | outline | — |

- **Фокус:** Строка — tabindex 0; внутри ещё фокусируются флажок, «копировать» и «⋯». Enter на строке открывает, на кнопке — её действие.

- **Reduced motion:** Переход фона отключается.

- **Соседи:** Соседние строки не реагируют; ширины колонок не меняются при появлении кнопок (они занимают место и прозрачны).

## Как использовать

<!-- manual:start -->
Компонент: обобщённый `DataTable<Row>`. Типы: `DataTableProps<Row>`, `DataTableColumn<Row>`, `DataTableTab<Row>`, `DataTableSort`, `DataTableFilterChip`, `DataTableState`, `DataTableDensity`, `DataTableLines`, `SortDirection`. Данные приходят пропсами: сортировка, поиск, фильтр вкладки и страницы считаются на клиенте по переданным `rows`. Корень собран на `Card flush`.

```tsx
import { DataTable } from "@/ui";
```

Основные пропсы (плюс атрибуты `<div>`: `aria-*`, `data-*`, `ref`, `className`). Всё состояние (`tab`, `query`, `sort`, `selected`, `activeId`, `page`, `pageSize`) можно вести снаружи (`value` + `onXxxChange`) или оставить компоненту (`defaultXxx`).

| Проп                       | Тип                                              | По умолчанию        | Описание                                                                                     |
| -------------------------- | ------------------------------------------------ | ------------------- | -------------------------------------------------------------------------------------------- |
| `label`                    | `string`                                         | обязателен          | `aria-label` таблицы.                                                                        |
| `columns`                  | `DataTableColumn<Row>[]`                         | обязателен          | `{ id, header, cell(row), width?, align?: "start" \| "end", sortValue?(row) }`; с `sortValue` колонка сортируется. |
| `rows`, `getRowId`         | `Row[]`, `(row) => string`                       | обязательны         | Данные и стабильный id строки.                                                               |
| `state`                    | `"data" \| "loading" \| "error" \| "empty"`      | `"data"`            | Пустой `rows` в состоянии `data` показывает `empty`.                                         |
| `density`, `lines`         | `"compact" \| "normal" \| "comfort"`, `"h" \| "grid" \| "zebra"` | `"normal"`, `"h"` | Высота строки 36 / 48 / 56 px; линии.                                                |
| `fluid`, `height`          | `boolean`, `number`                              | нет                 | `fluid` — без минимальной ширины 820 px (узкие колонки); `height` — максимальная высота, дальше прокрутка с липкой шапкой. |
| `tabs`                     | `{ id, label, filter?(row), count?, disabled? }[]` | нет               | Вкладки-статусы; счётчик считается по `filter`, если `count` не задан. `tab`, `defaultTab`, `onTabChange`, `tabsLabel`. |
| `searchable`, `searchText` | `boolean`, `(row) => string`                     | нет                 | Поле поиска и текст строки для сравнения. `query`, `defaultQuery`, `onQueryChange`, `searchLabel`, `searchPlaceholder`. |
| `filters`, `toolbarActions`| `ReactNode`                                      | нет                 | Слот слева после поиска и слот справа (кнопки). Панель рисуется, если есть поиск или слот.   |
| `appliedFilters`, `onReset`| `DataTableFilterChip[]`, `() => void`            | нет                 | Чипы внешних фильтров; поиск получает чип сам. «Сбросить всё» чистит поиск, вкладку и страницу и зовёт `onReset`. |
| `sort`                     | `{ column, direction } \| null`                  | `defaultSort`       | Цикл по клику: по возрастанию → по убыванию → сброс. `onSortChange`.                         |
| `selectable`               | `boolean`                                        | нет                 | Колонка флажков и «выбрать все на странице»; `selected`/`defaultSelected`/`onSelectedChange`, слот панели `selectionActions`. |
| `activeId`, `onRowOpen`    | `string \| null`, `(row) => void`                | нет                 | Подсвеченная строка; клик, Enter и Space на строке вызывают `onRowOpen`.                     |
| `rowActions`               | `(row) => ReactNode`                             | нет                 | Последняя колонка (кнопка «⋯»); клики в ней строку не открывают.                             |
| `pagination`, `footer`     | `boolean`                                        | `true`, `true`      | `pagination={false}` — все строки на одной странице; `footer={false}` — спрятать подвал, не меняя разбиение. |
| `page`, `pageSize`, `pageSizeOptions` | `number`, `number`, `number[]`        | `0`, первый из опций, `[10, 25, 50]` | Кнопка «Строк: N» переключает размер по кругу по `pageSizeOptions`.      |
| `skeletonRows`             | `number`                                         | `6`                 | Строк-заглушек в `loading`.                                                                  |
| `emptyTitle`, `emptyText`, `emptyActions`, `errorTitle`, `errorText`, `onRetry`, `retrying` | | | Тексты и действия состояний; кнопка «Повторить» рисуется при `onRetry`.         |

```tsx
const columns: DataTableColumn<Cargo>[] = [
  { id: "id", header: "Контейнер", width: 150, sortValue: (r) => r.id, cell: (r) => <b>{r.id}</b> },
  { id: "weight", header: "Вес, кг", align: "end", sortValue: (r) => r.weight, cell: (r) => r.weight.toLocaleString("ru-RU") },
  { id: "status", header: "Статус", cell: (r) => <Badge tone={r.tone}>{r.status}</Badge> },
];

<DataTable<Cargo>
  label="Грузы" columns={columns} rows={cargo} getRowId={(r) => r.id}
  tabs={[{ id: "all", label: "Все" }, { id: "err", label: "С расхождениями", filter: (r) => r.tone === "err" }]}
  searchable searchText={(r) => r.id} selectable pageSizeOptions={[6, 12, 24]}
  onRowOpen={openCard}
  selectionActions={<Button size="sm" variant="outline">Выгрузить</Button>}
  toolbarActions={<Button size="sm" icon={<Icon name="plus" />}>Новый груз</Button>}
/>

<DataTable label="Документы" columns={docColumns} rows={docs} getRowId={(d) => d.id} density="compact" pagination={false} />

<DataTable label="Грузы" columns={columns} rows={[]} getRowId={(r) => r.id} state="loading" />
```

Доступность:

- `role="grid"`, `aria-label`, `aria-rowcount` и `aria-rowindex`; заголовки `scope="col"`; у сортируемых колонок `aria-sort` на `<th>` (`none`, `ascending`, `descending`); таблица в загрузке — `aria-busy`. Число найденных строк объявляется в скрытой области `role="status"`.
- Порядок Tab: вкладка выбранного статуса, поиск и кнопки панели, кнопки сортировки в шапке, строки (внутри строки — флажок и кнопки ячеек), панель выбора, подвал. Стрелки, Home и End на вкладках переключают их и переносят фокус; строка открывается Enter и Space, только когда фокус на самой строке.
- Флажки подписаны («Выбрать все на странице», «Выбрать <id>»), у «всех» есть промежуточное состояние. Кнопки страниц с `aria-label`, текущая — `aria-current="page"`.
- Принудительных состояний (`force`) у компонента нет; в словаре они ставятся в демо-обёртке.

# Радиусы и размеры

Шесть радиусов по масштабу элемента и четыре высоты контролов: 24, 28, 32, 36 px.

Чем крупнее поверхность, тем больше её радиус: контрол 4, пункт 8, карточка 10, поповер 12, окно 14. Кнопка не пилюля: радиус 8. Пилюля (999) — только для меток и переключателей. Высота контрола берётся из шкалы, а не из внутренних отступов.

- **id:** `radii-sizes`
- **Группа:** Основа (`base`)
- **CSS-префикс:** `ds-radii`
- **Origin хореографии:** mockup (1), proposal (1)
- **Страница основы:** да

## Когда использовать / не использовать

### Использовать

- Радиус вложенного элемента — на ступень меньше внешнего.
- Высоту контрола брать из --h-*, чтобы в строке кнопки, поля и селекты были одной высоты.
- Пилюля — для меток, счётчиков и Toggle.
- Кнопка — радиус 8, не пилюля.

### Не использовать

- Радиусы вне шкалы (6, 16, 20 px).
- Пилюлю на кнопках и карточках.
- Задавать высоту контрола padding-ом.
- Анимировать радиус.

## Анатомия

1. **Радиус** — Один из шести токенов. Вложенный элемент берёт радиус на ступень меньше внешнего.
2. **Высота контрола** — --h-xs 24 · --h-sm 28 · --h-md 32 (по умолчанию) · --h-lg 36.
3. **Высота шапки и ширина панели** — --h-bar 56 px; --w-side 248 px, --w-rail 56 px в свёрнутом виде.

## Варианты

- **4 px · --r-control** (`control`): Кнопка-иконка xs/sm у ghost, link, бейдж-тег, флажок
- **8 px · --r-item** (`item`): Кнопка, пункт меню и сайдбара, поле
- **10 px · --r-card** (`card`): Карточка, подсказка
- **12 px · --r-popover** (`popover`): Поповер и меню
- **14 px · --r-panel** (`panel`): Окно и панель
- **pill · --r-pill** (`pill`): Бейдж, Toggle, счётчик

## Доступность

- **Цель нажатия** (`note`): Кнопки 24–28 px меньше рекомендуемых 44 px для касания. В плотных таблицах это осознанный размер; для тач-режима предусмотрите lg. [TODO] решить правила для планшета.
- **Контур фокуса** (`focus`): Контур 2px повторяет радиус элемента и не занимает места.
- **Рейл** (`motion`): При prefers-reduced-motion ширина панели меняется без перехода.

## Хореография

### Сворачивание панели в рейл (`rail`, origin: mockup)

- **Триггер:** кнопка свёртки в шапке боковой панели

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Подписи пунктов гаснут. | opacity | ease |
| 0 | 300 | Ширина панели и блока логотипа сходит с 248 к 56 px. | width | --glide cubic-bezier(.4,0,.2,1) |
| 0 | 300 | Заголовки групп сменяются значками, отступ между группами сжимается. | opacity, padding-top | --glide |

- **Фокус:** Фокус остаётся на кнопке свёртки; пункты остаются в порядке Tab, подпись — в подсказке при наведении.

- **Reduced motion:** Ширина и прозрачность меняются мгновенно (transition: none).

- **Соседи:** Область содержимого меняет ширину вместе с панелью (grid auto + 1fr): контент перекладывается, а не перекрывается.

### Радиусы не анимируются (`radius-static`, origin: proposal)

- **Триггер:** любое состояние

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Радиус не меняется ни в hover, ни в active, ни в фокусе. Исключение — ButtonGroup: на стыках радиус 0, снаружи 8. | — | — |

- **Фокус:** Контур фокуса повторяет радиус элемента.

- **Reduced motion:** Не применяется.

- **Соседи:** Не затрагиваются.

## Как использовать

<!-- manual:start -->
Страница-основа: компонента нет, радиусы и высоты лежат в CSS-переменных `src/styles/tokens.css`: `--r-control`, `--r-item`, `--r-card`, `--r-popover`, `--r-panel`, `--r-pill`; высоты `--h-xs` … `--h-lg` и `--h-bar`.

```css
.chip {
  min-height: var(--h-sm);
  border-radius: var(--r-item);
}
```

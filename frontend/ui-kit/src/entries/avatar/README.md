# Avatar

Круглая метка человека или организации: инициалы на цвете имени. Особые — вы, агент, «ещё N». Размеры от 16 до 56, присутствие, группа.

Аватар помогает узнать автора и исполнителя с первого взгляда, не читая имя. Цвет не выбирают вручную: его даёт хэш имени, поэтому человек выглядит одинаково во всех списках. Фотографий в макете нет, только инициалы. [TODO] решить, будут ли загруженные фото.

- **id:** `avatar`
- **Группа:** Люди (`people`)
- **CSS-префикс:** `ds-avatar`
- **Origin хореографии:** mockup (1), proposal (1)

## Когда использовать / не использовать

### Использовать

- Рядом с именем автора, исполнителя, участника: аватар узнаётся быстрее текста.
- Организации — скруглённый квадрат, люди — круг.
- Цвет только по имени (хэш): человек везде одного цвета.
- Группа из трёх-четырёх аватаров, дальше «+N» с числом остальных.
- Присутствие — только там, где оно что-то значит (участники обсуждения, список команды).

### Не использовать

- Выбирать цвет вручную или менять его между экранами.
- Вставлять в аватар длинный текст: больше двух букв не помещается.
- Делать аватар кнопкой без обёртки: нажимаемым делает его <button> вокруг.
- Показывать присутствие у организаций.
- Передавать статус только цветом точки: нужен текст рядом или aria-label.

## Анатомия

1. **Контейнер** — Круг (радиус 50 %) или скруглённый квадрат (32 %) для организаций. Подложка — тон 24 % на поверхности.
2. **Инициалы** — Первые буквы первых двух слов имени, Onest 700, заглавные; «ООО», «АО», «ИП» не считаются. Размер шрифта зависит от диаметра.
3. **Индикатор присутствия** (необязательная) — Точка 28 % диаметра (не меньше 7 px) в правом нижнем углу с кольцом цвета поверхности 2px.

## Варианты

- **Человек** (`person`): Инициалы текстом, цвет из шести тонов бренда по хэшу имени (сумма кодов символов по модулю 6). Когда: автор комментария, исполнитель, участник.
- **Вы** (`you`): Teal-заливка и navy-инициалы. Текущий пользователь: в шапке, в меню профиля. Когда: только для текущего пользователя.
- **Агент** (`agent`): Логотип агента вместо инициалов, без подложки. Вариант логотипа пока выбран первый из четырёх. Когда: сообщения агента, метка предложения, пустое состояние чата.
- **Организация** (`square`): Скруглённый квадрат: так отличают компанию от человека. Когда: контрагент, клиент, подключённый сервис.
- **Ещё N** (`more`): Нейтральный круг с «+N» в конце группы, когда участников больше, чем влезает.
- **Неизвестный** (`muted`): Нейтральный круг с «?»: имя неизвестно или удалено.

## Состояния

### Применимые

- **Обычный** (`default`): Инициалы на подложке тона; курсор обычный.
- **С присутствием** (`other`, `status`): Точка: в сети #22c55e, отошёл #f59e0b, занят --danger, не в сети --text-3.
- **Hover (подсказка)** (`hover`, `tooltip`): Сам аватар не меняется. Показывается подсказка с полным именем — компонент Tooltip.

### Не применимы (с причиной)

- **Active** (`active`): Аватар не нажимается. Если открывает профиль, оборачивается в кнопку; состояния даёт кнопка.
- **Focus** (`focus`): Не в порядке Tab. Внутри кнопки или ссылки кольцо рисует она.
- **Disabled** (`disabled`): Нет. Неактивного человека показывают присутствием off.
- **Loading** (`loading`): Нет. Пока автор не загружен — Skeleton круглой формы.
- **Error** (`error`): Нет. Удалённого или неизвестного человека показывает вариант «?».
- **Empty** (`empty`): Нет имени — вариант «?».

## Доступность

- **role="img" + aria-label** (`aria`): Аватар без видимого имени рядом получает aria-label с полным именем. Если имя рядом читается, аватар скрывают: aria-hidden="true".
- **Присутствие** (`aria`): В aria-label добавляют текст статуса («Максим Орлов, в сети»): цвет точки смысл не несёт.
- **Группа** (`aria`): role="group" с aria-label («Участники»); «+N» читается как «ещё N».
- **Клавиатура** (`key`): Аватар не интерактивен и в Tab не входит. Интерактивный аватар — это кнопка (см. Button) с aria-label.
- **Инициалы** (`contrast`): Светлая тема: от 5,6:1 (teal, orange) до 7,3:1; тёмная: от 7,2:1. Teal-вариант «вы»: navy на teal 7,4:1.
- **prefers-reduced-motion** (`motion`): Переход цвета точки присутствия отключается; у подсказки — см. Tooltip.

## Хореография

### Подсказка с именем (`tip`, origin: mockup)

- **Триггер:** курсор над аватаром

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Подсказка создаётся сразу, без задержки, и проявляется: прозрачность 0→1, масштаб .96→1, сдвиг на 4 px вниз к месту. | opacity, scale, translate | --ease |
| 1400 | 0 | Курсор ушёл, нажатие или прокрутка: подсказка удаляется мгновенно, без обратной анимации. | — | — |

- **Фокус:** Подсказка от фокуса не показывается: аватар не фокусируется. В кнопке подсказку покажет Tooltip кнопки.

- **Reduced motion:** Макет не описывает; ожидается: подсказка появляется без анимации. [TODO] подтвердить вместе со страницей Tooltip.

- **Соседи:** В группе наведённый аватар не сдвигается и не поднимается; подсказка лежит поверх соседей и не меняет раскладку.

### Смена присутствия (`presence`, origin: proposal)

- **Триггер:** статус человека изменился

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Точка плавно меняет цвет на новый. Кольцо и размер не меняются. | background | ease |

- **Фокус:** Не затрагивается. Смену статуса озвучивают текстом рядом (aria-label аватара обновляется).

- **Reduced motion:** Цвет меняется мгновенно.

- **Соседи:** Не реагируют. [TODO] подтвердить: в макете цвет присутствия задаётся статически.

## Как использовать

Импорт: в ките — `import { Avatar } from "@/ui"`, в приложении — `import { Avatar } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компонент `Avatar` (`<span role="img">`). Типы: `AvatarProps`, `AvatarKind`, `AvatarSize`, `AvatarPresence`. Группа аватаров — отдельная запись `avatar-group`.

```tsx
import { Avatar } from "@/ui";
```

Пропсы (плюс атрибуты `<span>` кроме `children`: `aria-*`, `data-*`, `ref`):

| Проп        | Тип                                                  | По умолчанию | Описание                                                                                          |
| ----------- | ---------------------------------------------------- | ------------ | ------------------------------------------------------------------------------------------------- |
| `name`      | `string`                                             | `""`         | Имя или организация: из него берутся инициалы (юрформы ООО, АО, ИП и кавычки пропускаются) и цвет. |
| `kind`      | `"person" \| "you" \| "agent" \| "more" \| "muted"`  | `"person"`   | Человек, вы, агент, «+N», неизвестный (`?`).                                                      |
| `size`      | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`               | нет (24 px)  | 16, 18, 32, 40, 56 px; без `size` — 24 px.                                                        |
| `square`    | `boolean`                                            | нет          | Скруглённый квадрат вместо круга.                                                                 |
| `status`    | `"on" \| "away" \| "busy" \| "off"`                  | нет          | Точка присутствия; пишется в `data-status` и в подпись.                                           |
| `count`     | `number`                                             | `3`          | Число для `kind="more"`.                                                                          |
| `toneIndex` | `number` (0-5)                                       | по имени     | Принудительный цвет из шести; без него считается из `name`.                                       |
| `className` | `string`                                             | нет          | Добавляется к классам компонента.                                                                 |

```tsx
<Avatar name="Ирина Петрова" size="md" status="on" />

<Avatar kind="agent" size="md" />

<Avatar kind="more" count={5} size="sm" />
```

Доступность:

- Подпись по умолчанию: имя; для `agent` — «Агент»; для `more` — «ещё N». Свою подпись задаёт `aria-label`.
- Присутствие дописывается в подпись («Ирина Петрова, занят»); сама точка скрыта от скринридера.
- Если `name` пуст и `aria-label` не задан, у аватара нет имени: задайте `aria-label`.
- Аватар не фокусируется. Подсказку с полным именем даст компонент Tooltip.

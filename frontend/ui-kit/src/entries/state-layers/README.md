# Слои состояний

Hover и active — это полупрозрачный слой ink поверх фона, а не отдельные цвета. Четыре ступени: 4, 7, 9 и 12 %.

Слой одинаково работает на белой, графитовой и цветной поверхности и в обеих темах: --ink тёмный в светлой теме и белый в тёмной. Поэтому у компонента нет «своего hover-цвета» для каждой темы. Заливочные кнопки темнеют миксом с чёрным, потому что у них свой цвет, не поверхность.

- **id:** `state-layers`
- **Группа:** Основа (`base`)
- **CSS-префикс:** `ds-layers`
- **Origin хореографии:** mockup (1)
- **Страница основы:** да

## Когда использовать / не использовать

### Использовать

- Для hover и active на нейтральных поверхностях брать --layer-*, а не новый цвет.
- Строка, пункт, поле: 4 → 7 %. Кнопка вне контейнера: 9 → 12 %.
- Заливочным кнопкам — микс собственного цвета с чёрным.
- Выбор — подложка --selected плюс кольцо, не слой.

### Не использовать

- Новый hover-цвет в HEX: слой уже даёт нужный результат в обеих темах.
- Слой на заливке: эффект там слабый и грязный.
- Менять проценты по вкусу: ступени общие для всего продукта.
- Показывать hover на disabled.

## Анатомия

1. **База (--ink)** — #0e1620 в светлой теме и #fff в тёмной.
2. **Слой** — color-mix(in srgb, transparent, var(--ink) N %): прозрачный цвет с N процентами ink. Кладётся поверх любого фона.
3. **Ступень** — 1 уровень (4 → 7 %): строка, пункт, поле. 2 уровень (9 → 12 %): кнопка вне контейнера. Вторая шкала (6 → 9 %): иконки поверх панелей.

## Варианты

- **Шкала поверх поверхности** (`scale`): Те же проценты на --surface: фон строки, пункта и кнопки.
- **Заливка: микс с чёрным** (`fills`): У кнопок с собственным цветом hover и active — микс этого цвета с чёрным в oklch: primary и accent 8 → 15 %, destructive 12 → 20 %.
- **Выбранный элемент** (`selected`): Выбор — не слой, а подложка --selected (teal 15 %) и кольцо; hover по выбранному добавляет ink 8,8 %.

## Состояния

### Применимые

- **Покой** (`default`): Фона нет, текст --text-2.
- **Hover · 4 %** (`hover`): Слой --layer-1, текст --text.
- **Active · 7 %** (`active`): Слой --layer-1p при нажатии.
- **Focus** (`focus`): Контур 2px --focus. Слоя нет: фокус и hover независимы.
- **Выбрано** (`selected`): Подложка --selected, кольцо --border-selected.
- **Выбрано + hover** (`hover`, `selected-hover`): К --selected добавляется ink 8,8 %.
- **Disabled** (`disabled`): Слоя нет, текст --text-ph. Hover не работает.
- **Кнопка · hover 9 %** (`hover`, `btn-hover`): Вне контейнера слой гуще: --layer-2.
- **Кнопка · active 12 %** (`active`, `btn-active`): --layer-3.

### Не применимы (с причиной)

Нет.

## Размеры и токены

### Токены

| Название | Значение | Назначение |
| --- | --- | --- |
| `--layer-1` | ink 4 % | Hover строки, пункта, группы |
| `--layer-1p` | ink 7 % | Active строки, пункта, группы |
| `--layer-n / --layer-np` | ink 6 % / 9 % | Hover и active иконок поверх панелей (закрытие агента) |
| `--layer-2` | ink 9 % | Hover кнопок ghost и outline |
| `--layer-3` | ink 12 % | Active кнопок ghost и outline |
| `--tone` | ink 7 % | Заливка disabled у флажка, радио, переключателя; счётчик во вкладке |
| `--ink` | #0e1620 / #ffffff | База всех слоёв |
| `hover выбранного` | --selected + ink 8,8 % | Выбранная строка при наведении |
| `--dur-f` | 125 мс | Переход слоя |

## Доступность

- **Состояние не только цветом** (`note`): Слой 4 % едва заметен. Выбранное состояние подкреплено кольцом, активный пункт — aria-current, фокус — контуром 2px.
- **Focus-visible** (`focus`): Фокус не использует слой: контур не пропадает на любых поверхностях.
- **prefers-reduced-motion** (`motion`): Переходы слоя отключаются.

## Хореография

### Слой при наведении и нажатии (`layers`, origin: mockup)

- **Триггер:** указатель на строке или кнопке, затем нажатие

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Hover: фон идёт от прозрачного к слою (4 % у строки, 9 % у кнопки). | background | ease (по умолчанию) |
| 800 | 125 | Нажатие: слой гуще (7 % и 12 %). | background | ease |
| 1100 | 125 | Отпускание: возврат к hover. | background | ease |
| 1900 | 125 | Уход: фон возвращается к прозрачному. | background | ease |

- **Фокус:** Слой фокус не заменяет: контур 2px рисуется поверх независимо.

- **Reduced motion:** Переход отключается, слой включается мгновенно.

- **Соседи:** Не реагируют: слой не меняет размеры.

## Примеры

### Строка списка (`css`)

```tsx
.item:hover  { background: var(--layer-1); }
.item:active { background: var(--layer-1p); }
.item[aria-current] { background: var(--selected); }
```

## Как использовать

<!-- manual:start -->
Страница-основа: компонента нет, слои лежат в CSS-переменных `src/styles/tokens.css` (`--layer-1`, `--layer-1p`, `--layer-2`, `--layer-3`) и строятся от `--ink`. Фон hover и active ставьте слоем поверх поверхности, переход — токеном `--dur-f`.

```css
.row:hover {
  background: var(--layer-1);
}
.row:active {
  background: var(--layer-1p);
}
```

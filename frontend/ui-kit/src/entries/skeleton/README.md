# Skeleton

Заглушка в форме будущего содержимого: серые блоки с волной или пульсом, пока данные грузятся.

Skeleton показывает, что здесь будет: строки, плитку, график, таблицу. Страница не прыгает, когда приходят данные, потому что заглушки занимают ровно те же размеры. Для индикации «идёт процесс неопределённой длины» берите Spinner, для известной доли — Progress.

- **id:** `skeleton`
- **Группа:** Обратная связь (`feedback`)
- **CSS-префикс:** `ds-skel`
- **Origin хореографии:** mockup (2), proposal (2)

## Когда использовать / не использовать

### Использовать

- Повторять форму будущего содержимого: круг под аватар, строки под текст, плашки под бейджи.
- Ставить aria-busy на контейнер, а не на каждый блок.
- Сохранять размеры: данные приходят без смещения макета.
- Один вид анимации на экране: волна или пульс.
- Показывать заглушку только пока ответа нет; при ошибке — состояние error.

### Не использовать

- Крутить заглушку без конца: у загрузки должен быть таймаут и состояние error.
- Заглушка не по форме: один большой прямоугольник вместо карточки.
- Смешивать Skeleton и Spinner в одном блоке.
- Заглушка для действия (отправка формы): это loading кнопки.
- Свои цвета и градиенты: только --tone и слой ink 9 %.

## Анатомия

1. **Группа** — Контейнер с aria-busy=true и data-anim (wave или pulse). Внутри — скрытая подпись «Загрузка…» для скринридера.
2. **Круг** — Аватар, значок: border-radius 50 %, размер как у настоящего (32 px для аватара md).
3. **Строка текста** — Высота 12 (заголовок) и 10–11 (подпись), радиус 4; ширина 38–100 %, чтобы строки отличались.
4. **Плашка** (необязательная) — Радиус 8: кнопка, бейдж, плитка, столбик графика.

## Варианты

- **Список** (`list`): Круг 32 + две строки + плашка бейджа. Ширина первой строки меняется (70 % / 55 %). Когда: список людей, документов, событий.
- **Карточка** (`card`): Заголовок 14, три строки 11 и два блока-кнопки 28 в подвале 50/50. Когда: карточка расхождения, KPI-плитка.
- **График** (`chart`): Двенадцать столбиков разной высоты (радиус 8) вместо осей и линий: оси не рисуются, пока нет данных. Когда: LineChart, Donut, HBar до прихода данных.
- **Таблица** (`table`): Строки высотой 38: блок 70 % на ячейку. У DataTable — свой вариант заглушки со сдвигом анимации на 80 мс по строкам. Когда: первая загрузка списка.
- **Пульс вместо волны** (`pulse`): Те же блоки, но мигают целиком (прозрачность 100 → 45 %, 1,1 с). Когда: мелкие блоки, где волна читается плохо; один вид анимации на экран.

## Состояния

### Применимые

- **Волна** (`default`): Фон --tone, поверх полоса ink 9 % слева направо за 1,4 с, бесконечно.
- **Пульс** (`loading`, `pulse`): Прозрачность 100 → 45 → 100 % за 1,1 с.
- **Без анимации** (`other`, `static`): prefers-reduced-motion или anim=none: статичные блоки --tone.
- **Данные пришли** (`other`, `loaded`): Контейнер снимает aria-busy, заглушки заменены содержимым тех же размеров.

### Не применимы (с причиной)

- **Hover** (`hover`): Заглушка не интерактивна: курсор обычный, слоя нет.
- **Active** (`active`): Нет: ничего нельзя нажать.
- **Focus** (`focus`): Не в Tab, aria-hidden у блоков.
- **Disabled** (`disabled`): Нет: недоступное показывают как есть, не заглушкой.
- **Error** (`error`): Ошибка загрузки заменяет заглушку: Alert или состояние error компонента. Skeleton вечно не крутят.
- **Empty** (`empty`): Пустой результат — состояние empty самого компонента, не заглушка.

## Размеры и токены

### Размеры

| Название | Значение | Назначение |
| --- | --- | --- |
| Высоты блоков | 10 · 11 · 12 · 14 · 28 · 32 | как у настоящего элемента |

### Токены

| Название | Значение | Назначение |
| --- | --- | --- |
| `--tone` | ink 7 % | Фон блока |
| `ink 9 %` | color-mix(--ink 9 %) | Полоса волны |
| `--r-control / --r-item` | 4 / 8 px | Строка · плашка; круг 50 % |
| `height` | 10 · 11 · 12 · 14 · 28 · 32 px | Как у настоящего элемента |
| `wave` | 1,4 с ease-in-out, бесконечно | Волна |
| `pulse` | 1,1 с ease-in-out, 100 → 45 % | Пульс |
| `swap fade` | 200 мс ease | Проявление данных (предложение) |

## Доступность

- **aria-busy** (`aria`): У группы aria-busy=true, пока данные грузятся; блоки aria-hidden. После загрузки атрибут снимается.
- **Подпись «Загрузка…»** (`aria`): Скрытый текст внутри группы для скринридера; при необходимости обновлять через aria-live у родителя.
- **Клавиатура** (`key`): Заглушка не фокусируется. Фокус в соседних элементах не отбирается.
- **Блоки** (`contrast`): Контраст блока --tone с --surface намеренно низкий: заглушка не несёт информации, ей достаточно быть заметной формой. [TODO] проверить заметность в светлой теме на экранах с низкой яркостью.
- **prefers-reduced-motion** (`motion`): Волна и пульс выключены, остаются статичные блоки. (Макет сокращал анимацию до 3 с; в словаре она убрана совсем.)

## Хореография

### Волна (`wave`, origin: mockup)

- **Триггер:** блок вошёл в состояние loading (aria-busy)

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 1400 | Полоса градиента ink 9 % едет слева направо через каждый блок по отдельности (translate -100 % → 100 %). | translate (::after) | ease-in-out |
| 1400 | 0 | Цикл повторяется, пока идёт загрузка. | — | — |

- **Фокус:** Заглушка не получает фокус; фокус на соседних элементах не теряется.

- **Reduced motion:** Волна выключается: остаются статичные блоки --tone. (В макете: animation: none.)

- **Соседи:** Блоки не меняют размеры, анимация внутри каждого блока (overflow: clip), соседи не реагируют.

### Пульс (`pulse`, origin: mockup)

- **Триггер:** data-anim=pulse на контейнере

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 550 | Прозрачность блоков падает с 100 % до 45 %. | opacity | ease-in-out |
| 550 | 550 | Возвращается к 100 %; повтор. | opacity | ease-in-out |

- **Фокус:** Не применимо.

- **Reduced motion:** Пульс выключен: статичные блоки.

- **Соседи:** Мигают все блоки группы одновременно; соседние компоненты не затрагиваются.

### Заглушка → данные (`swap`, origin: proposal)

- **Триггер:** данные получены

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | aria-busy снимается; заглушки заменяются содержимым тех же размеров, строки не сдвигаются. | разметка | — |
| 0 | 200 | Новое содержимое проявляется. | opacity | ease |
| 0 | 0 | Минимальное время показа заглушки — 300 мс, чтобы быстрый ответ не мигал. [TODO] подтвердить значение. | — | — |

- **Фокус:** Если фокус был в соседнем элементе — остаётся. Фокус внутрь новых данных не переносится.

- **Reduced motion:** Проявление отключается: данные появляются сразу.

- **Соседи:** Размеры заглушки совпадают с данными, соседи не прыгают.

### Строки таблицы (`table-swap`, origin: proposal)

- **Триггер:** первая загрузка списка

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 1800 | Четыре строки по 38 px с блоками 70 %, 60 %, 50 % в ячейках. | — | — |
| 1800 | 200 | Данные проявляются, высота строк не меняется. | opacity | ease |

- **Фокус:** Не применимо.

- **Reduced motion:** Волны нет, проявления нет.

- **Соседи:** Шапка и подвал таблицы стоят на месте, как и колонки.

## Примеры

### Список людей (`list`)

```tsx
<SkeletonGroup loading={isLoading}>
  <SkeletonRow />
</SkeletonGroup>
```

### График (`chart`)

```tsx
{isLoading ? <SkeletonChart /> : <LineChart … />}
```

## Как использовать

<!-- manual:start -->
Компоненты: `Skeleton` (блок-заглушка), `SkeletonGroup` (обёртка с `aria-busy` и анимацией), пресеты `SkeletonRow` (аватар + две строки + плашка) и `SkeletonChart` (столбики). Типы: `SkeletonProps`, `SkeletonGroupProps`, `SkeletonRowProps`, `SkeletonChartProps`, `SkeletonShape`, `SkeletonAnimation`.

```tsx
import { Skeleton, SkeletonGroup, SkeletonRow, SkeletonChart } from "@/ui";
```

Пропсы `Skeleton` (плюс атрибуты `<span>`, `ref`, `className`, `style`):

| Проп     | Тип                             | По умолчанию | Описание                                    |
| -------- | ------------------------------- | ------------ | ------------------------------------------- |
| `width`  | `string \| number`              | `"100%"`     | Ширина (число — px).                        |
| `height` | `number`                        | `12`         | Высота в px.                                |
| `shape`  | `"rect" \| "round" \| "item"`   | `"rect"`     | Скругление: контрол, круг, как у элементов. |

Пропсы `SkeletonGroup` (плюс атрибуты `<div>`):

| Проп        | Тип                            | По умолчанию   | Описание                                                                  |
| ----------- | ------------------------------ | -------------- | ------------------------------------------------------------------------- |
| `animation` | `"wave" \| "pulse" \| "none"`  | `"wave"`       | Анимация всех блоков внутри.                                              |
| `loading`   | `boolean`                      | `true`         | Пока `true`: `aria-busy="true"` и скрытая подпись для скринридера.        |
| `label`     | `string`                       | `"Загрузка…"`  | Подпись для скринридера.                                                  |

`SkeletonRow`: `narrow` (первая строка текста короче). `SkeletonChart`: `bars` (высоты столбиков в процентах, по умолчанию 12 штук).

```tsx
<SkeletonGroup loading={isLoading}>
  <SkeletonRow />
  <SkeletonRow narrow />
</SkeletonGroup>

<SkeletonGroup animation="pulse">
  <Skeleton width="45%" height={14} />
  <Skeleton height={11} />
  <Skeleton height={28} shape="item" />
</SkeletonGroup>

{isLoading ? <SkeletonChart /> : <LineChart labels={weeks} series={series} />}
```

Доступность:

- Блоки `aria-hidden`; смысл несёт группа: `aria-busy` и скрытый текст «Загрузка…». Заглушка не фокусируется.
- Размеры заглушки должны повторять размеры будущего содержимого, иначе страница прыгает.
- При `prefers-reduced-motion` волна и пульс выключаются, остаются статичные блоки.
- Принудительных состояний (`force`) у компонента нет.

# Toast

Всплывающее подтверждение действия в углу экрана. Карточка с тоном, заголовком и действием; автозакрытие через 5 с; стопка раскрывается по наведению.

Toast отвечает «получилось» или «идёт», не отнимая у пользователя внимание и не требуя решения: «Документы сверены», «Груз в архиве · Отменить». Важное и постоянное (ошибка формы, статус подключения) — Alert; требующее решения — Dialog. Тост не должен быть единственным источником важной информации: он исчезает сам.

- **id:** `toast`
- **Группа:** Обратная связь (`feedback`)
- **CSS-префикс:** `ds-toast`
- **Origin хореографии:** mockup (6)

## Когда использовать / не использовать

### Использовать

- Один тост — одно событие, заголовок до 40 символов, глагол в прошедшем времени: «Документы сверены».
- Для обратимого действия — «Отменить» в самом тосте, пока он на экране.
- Долгие операции — тост «идёт» и обновление на месте, а не два тоста.
- Ошибка в тосте с «Повторить»; причину и последствия пишите в пояснении.
- Положение одно на приложение (по умолчанию внизу справа), не меняйте его для отдельных тостов.

### Не использовать

- Единственный источник важной информации: тост исчезает, пользователь мог не заметить.
- Тост, требующий решения: «Удалить?» — это Dialog.
- Больше одного действия в тосте.
- Тосты на каждый клик: подтверждайте только то, чего не видно на экране.
- Закрывать тост по Esc, если фокус в форме под ним: Esc принадлежит содержимому [TODO] подтвердить.

## Анатомия

1. **Карточка** — Фон --surface, кольцо 1px --border, тень --shadow-pop, радиус --r-popover (12), ширина 360 px (но не шире окна − 48).
2. **Значок или Spinner** — 20 px слева: ✓ (ok), i (info), ! (warn, err); цвет тона. У тоста «идёт» вместо значка Spinner md.
3. **Заголовок** — Жирный (600): одна фраза о результате («Документы сверены»).
4. **Пояснение** (необязательная) — 12 px, --text-2: что именно, сколько («128 грузов»).
5. **Действие** (необязательная) — Кнопка outline sm справа: «Отменить», «Повторить», «Открыть». Одно.
6. **Крестик** — Ghost xs, квадратный; закрывает тост с анимацией ухода.
7. **Контейнер стопки** — Невидимый слой в углу: задаёт положение (data-pos), z-index 1200, pointer-events: none (кликабельны только карточки), высоту по передней карточке или по всей раскрытой стопке.

## Варианты

- **Тоны** (`tones`): ok (по умолчанию) · info · warn · err меняют цвет значка; цвет карточки не меняется. Когда: ok — сделано; info — к сведению; warn — внимание; err — не вышло, есть «Повторить».
- **С отменой** (`undo`): Действие «Отменить» возвращает операцию. Тост висит все 5 с; нажатие закрывает его и ставит «Возвращено». Когда: обратимое действие без Dialog: архив, удаление в корзину.
- **Процесс → результат** (`progress`): Идёт: Spinner, не закрывается сам. Готово: тот же тост обновляется, получает значок и действие. Когда: операция дольше секунды, пользователь мог уйти на другой экран.
- **Стопка** (`stack`): Новые встают поверх, старые выглядывают на 10 px и уменьшаются на 5 %. Видны три, остальные скрыты; всего не больше пяти. Когда: несколько событий подряд: файлы загружены, документы сверены.
- **Раскрытая стопка** (`expanded`): Наведение на контейнер раскрывает все карточки друг под другом через 8 px; таймеры закрытия стоят. Когда: пользователь хочет прочитать более ранние уведомления.
- **Живая стопка** (`live`): Все сценарии макета: тона, отмена, «идёт → результат», четыре подряд, шесть положений. Кнопки работают. Когда: посмотреть поведение руками: наведите на стопку.

## Состояния

### Применимые

- **Default** (`default`): Карточка на месте, автозакрытие идёт.
- **Hover** (`hover`): Наведение на стопку раскрывает её и ставит таймеры на паузу. У кнопки действия — слой 6 %.
- **Active** (`active`): Слой 9 % у нажатого действия; сразу после нажатия тост закрывается.
- **Focus** (`focus`): Карточка в порядке Tab (tabindex=0): кольцо 2 px --focus со смещением 2 px.
- **Loading** (`loading`): Spinner вместо значка; автозакрытия нет, пока не придёт результат.
- **Error · тон err** (`error`): Красный значок и «Повторить». Тост ошибки закрывается как остальные; важное дублируйте в Alert.

### Не применимы (с причиной)

- **Disabled** (`disabled`): Нет. Недоступное действие в тосте не показывают: нет прав — нет кнопки.
- **Empty** (`empty`): Нет. Нет событий — нет контейнера (высота стопки 0).

## Доступность

- **role=status, aria-live=polite** (`aria`): Каждая карточка — role="status". Контейнер стопки лучше сделать общей live-областью (aria-live="polite", aria-relevant="additions"): тосты объявляются по приходу. Ошибки по предложению [TODO] role="alert" для err-тоста, в макете role status у всех.
- **Tab, Enter, Esc** (`key`): Карточка в порядке Tab (tabindex=0), внутри — действие и «Закрыть». Enter и Space активируют кнопки. Предложение [TODO]: Esc на карточке закрывает тост; в макете нет.
- **Фокус при появлении и закрытии** (`focus`): Тост фокус не забирает: пользователь продолжает работу. Если тост закрыт, пока фокус был в нём, фокус нужно вернуть на элемент, с которого уходил (предложение [TODO]: в макете теряется на body).
- **Время чтения** (`aria`): 5 секунд — мало для чтения текста с действием. Пока фокус внутри стопки или курсор на ней, таймер стоит (в макете — только наведение; предложение: ещё и focus-within) [TODO]. Для WCAG 2.2.1 пользователю нужно дать продлить время: раскрыть стопку можно и с клавиатуры.
- **Текст и значки** (`contrast`): Заголовок --text на surface 16,5:1, пояснение --text-2 8,2:1. Значки: link 4,9:1, warn-text 5,0:1, danger 4,9:1, info 5,2:1 (порог для графики 3:1). Кольцо карточки --border 1,6:1 (светлая) и 2,5:1 (тёмная) — границу дополняет тень.
- **prefers-reduced-motion** (`motion`): Появление, уход и раскладка стопки без переходов: карточки встают и исчезают мгновенно, раскрытие по hover остаётся.

- **Соседи:** Стопка перекрывает содержимое страницы в углу (z-index 1200) и не сдвигает его. Dialog (800) и поповеры (900) под ней; контейнер pointer-events: none, клики по странице проходят сквозь пустое место.

```tsx
<Toaster />

<Button

    archive(id);

  В архив

```

### Процесс → результат (`progress`)

```tsx
<Toaster />

<Button
  variant="outline"
  onClick={() => {
    const id = toast({ title: "Сверяем документы…", description: "128 грузов", loading: true });
    window.setTimeout(
      () => toast.update(id, { loading: false, title: "Сверка завершена", tone: "warn" }),
      2000,
    );
  }}
>
  Сверить документы
</Button>
```

## Как использовать

Импорт: в ките — `import { ToastCard, ToastContent, Toaster, TOAST_DURATION_MS, ToastStack } from "@/ui"`, в приложении — `import { ToastCard, ToastContent, Toaster, TOAST_DURATION_MS, ToastStack } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { toast, Toaster } from "@/ui"`. Положите `<Toaster />` один раз в корень приложения, вызывайте `toast(...)` откуда угодно.

| Вызов / пропс | Тип | Что делает |
| --- | --- | --- |
| `toast(options)` | возвращает `id` | Показать тост поверх стопки (не больше 5 живых) |
| `toast.update(id, patch)` | — | Изменить тост на месте («идёт» → результат) |
| `toast.dismiss(id)` / `toast.clear()` | — | Закрыть с анимацией ухода (300 мс) |
| `options.title` | `ReactNode` | Заголовок, обязателен |
| `options.description` | `ReactNode` | Пояснение |
| `options.tone` | `"ok" \| "info" \| "warn" \| "err"` | Значок и цвет, по умолчанию `ok` |
| `options.action` | `{ label, onClick? }` | Одно действие («Отменить»): после клика тост закрывается |
| `options.loading` | `boolean` | Спиннер вместо значка, таймера нет |
| `options.icon` | `ReactNode` | Свой значок |
| `options.duration` | `number` (мс) | Автозакрытие, по умолчанию 5000; `Infinity` — не закрывать |
| `Toaster.position` | `"br" \| "bc" \| "bl" \| "tr" \| "tc" \| "tl"` | Угол стопки, по умолчанию `br` |
| `Toaster.store` | `ToastStore` | Своё хранилище (`createToastStore()` + `bindToast(store)`); по умолчанию общее |
| `Toaster.container` | `HTMLElement` | Рисовать стопку не в `body`, а в узле (превью, тесты) |

```tsx
toast({ title: "Груз отправлен в архив", description: id,
  action: { label: "Отменить", onClick: restore } })

const id = toast({ title: "Сверяем документы…", loading: true })
toast.update(id, { loading: false, title: "Сверка завершена", tone: "warn" })
```

Стопка: передний тост виден целиком, остальные выглядывают; наведение или фокус внутри раскрывают её и ставят таймеры на паузу. `ToastStack` и `ToastCard` — презентационные части без хранилища. Доступность: область `role="region"` «Уведомления», каждая карточка `role="status"` и в порядке Tab; Esc на карточке закрывает её, крестик подписан.

# Типографика

Один шрифт интерфейса, Onest, и Fira Code только для кода и логов. Шесть размеров от 11 до 22 px.

Иерархию задают размер и вес, а не гарнитура: заголовки 700–800, подписи 600, текст 400. Числа и идентификаторы (MSKU4821907, 18 420 кг) набираются тем же Onest, но с tabular-nums, чтобы колонки выравнивались. Fira Code не используют для обычных данных, только для кода и логов.

- **id:** `typography`
- **Группа:** Основа (`base`)
- **CSS-префикс:** `ds-type`
- **Origin хореографии:** mockup (1), proposal (1)
- **Страница основы:** да

## Когда использовать / не использовать

### Использовать

- Иерархия размером и весом, не новой гарнитурой.
- Числа, ID и суммы с tabular-nums.
- Fira Code только для кода, запросов и логов.
- Заголовка страницы нет, пока есть хлебные крошки.
- Подписи 11–12 px — цветом --text-2 или --text-3, не мельче.

### Не использовать

- Добавлять третью гарнитуру.
- Fira Code для номеров грузов и сумм.
- Размеры вне шкалы (14, 16, 20 px) без роли в токенах.
- Капс для длинных слов: капс — только у тегов (Badge tag).
- Вес ниже 400 в интерфейсе.

## Анатомия

1. **Гарнитура** — Onest (переменный, 100–900) — весь интерфейс. Fira Code (300–700) — код и логи. Файлы из idea/skelet/brand/design/fonts, подключаются симлинком.
2. **Размер** — Токены --fs-info 11 · --fs-control 12 · --fs-body 13 · --fs-qty 15 · --fs-heading 18 · --fs-title 22.
3. **Вес** — 400 текст, 500 пункты меню, 600 подписи и кнопки, 700 заголовки окон и панелей, 800–900 заголовок страницы и логотип.
4. **Цифры** — font-variant-numeric: tabular-nums для чисел, ID, сумм, сроков.

## Варианты

- **Заголовок** (`title`): Onest 800. Токен --fs-title 22 px; в образце макета «Шрифты» показан 26 px. [TODO] свести к одному значению.
- **Заголовок окна и панели** (`heading`): Onest 700, --fs-heading 18 px.
- **Текст интерфейса** (`body`): Onest 400, --fs-body 13 px, межстрочный 1,4. Основной размер продукта.
- **Шапка таблицы, подпись** (`control`): Onest 600, --fs-control 12 px, цвет --text-2.
- **Мелкая подпись** (`info`): Onest 400–600, --fs-info 11 px: счётчики во вкладках, описание под полем, подпись метки.
- **Крупное число** (`qty`): --fs-qty 15 px: значение показателя в карточке. Цифры tabular.
- **Числа и ID** (`numbers`): Тот же Onest, tabular-nums: колонки сумм и ID выравниваются по разрядам.
- **Код и логи** (`code`): Fira Code, 12 px. Только код, запросы, логи — не обычные данные.

## Размеры и токены

### Токены

| Название | Значение | Назначение |
| --- | --- | --- |
| `--font` | Onest, system-ui, sans-serif | Весь интерфейс (из --font-sans бренда) |
| `--mono` | Fira Code, ui-monospace, monospace | Код и логи (из --font-mono бренда) |
| `--fs-info` | 11 px | Мелкая подпись, xs-кнопка, tag |
| `--fs-control` | 12 px | Подписи, шапка таблицы, sm-кнопка |
| `--fs-body` | 13 px | Основной текст и кнопки |
| `--fs-qty` | 15 px | Значение показателя |
| `--fs-heading` | 18 px | Заголовок окна и панели |
| `--fs-title` | 22 px | Заголовок |
| `line-height` | 1,4 | Базовый межстрочный body |

## Доступность

- **Мелкий текст** (`contrast`): 11–12 px в --text-3 на белом 4,9:1: проходит порог 4,5:1, запаса мало. Не светлее --text-3.
- **Масштаб** (`note`): Размеры заданы в px и не зависят от настройки размера шрифта браузера. [TODO] решить, переводить ли шкалу в rem.
- **Язык** (`note`): <html lang="ru"> обязателен: от него зависят переносы и озвучка.
- **font-display: swap** (`motion`): Текст виден сразу, ожидание шрифта не блокирует чтение.

## Хореография

### Загрузка шрифтов (`font-load`, origin: mockup)

- **Триггер:** первая отрисовка страницы

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Текст сразу виден системным шрифтом (system-ui): страница не ждёт файл. | font-display: swap | — |
| 100 | 0 | Onest загрузился: гарнитура подменяется. Размеры строк почти совпадают, но возможен небольшой сдвиг строки. | — | — |

- **Фокус:** Не затрагивается.

- **Reduced motion:** Не применяется.

- **Соседи:** Строки могут пересчитать переносы при подмене шрифта. [TODO] проверить preload основного начертания, чтобы сдвиг не был заметен.

### Обновление чисел (`numbers`, origin: proposal)

- **Триггер:** значение показателя изменилось (сумма, вес, счётчик)

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Новое число заменяет старое на месте. Цифры одинаковой ширины (tabular-nums): ширина блока и положение соседей не меняются. | — | — |

- **Фокус:** Не затрагивается.

- **Reduced motion:** Не применяется: анимации счёта нет.

- **Соседи:** Соседние колонки не прыгают благодаря tabular-nums и min-width значения.

## Как использовать

<!-- manual:start -->
Страница-основа: компонента нет, размеры лежат в CSS-переменных `src/styles/tokens.css`. Основной текст — `var(--fs-body)` (13 px), подписи — `var(--fs-control)` и `var(--fs-info)`, цифры — Onest с `font-variant-numeric: tabular-nums`; Fira Code (`var(--mono)`) только для кода и логов.

```css
.total {
  font-size: var(--fs-qty);
  font-variant-numeric: tabular-nums;
}
```

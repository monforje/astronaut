# Separator

Разделитель: тонкая линия между блоками, с подписью, вертикальная в тулбарах и заголовок раздела со сворачиванием.

Линия — самый тихий способ сказать «здесь начинается другое». Она не заменяет заголовок и не рисует рамку. Горизонтальная делит блоки страницы и списки, вертикальная стоит между кнопками тулбара, а «раздел с заголовком» объединяет линию, подпись и кнопку сворачивания: так оформляют группы документов внутри карточки.

- **id:** `separator`
- **Группа:** Навигация (`navigation`)
- **CSS-префикс:** `ds-sep`
- **Origin хореографии:** mockup (1), proposal (1)

## Когда использовать / не использовать

### Использовать

- Линией отделяйте группы, а не каждый элемент: чем меньше линий, тем спокойнее экран.
- Сильная линия (--border) — только между крупными частями; обычная — внутри.
- Вертикальный разделитель держите в тулбаре между группами по 2–4 кнопки.
- У раздела со сворачиванием всегда есть краткое содержание свёрнутого.
- Для декоративной линии ставьте role="none"; осмысленная — role="separator".

### Не использовать

- Рамки и линии вокруг каждой карточки и каждой строки: хватает отступов.
- Вертикальные разделители в таблице вместо колонок.
- Линия вместо заголовка: у группы без подписи читатель не поймёт, что это.
- Цветные линии: разделитель всегда нейтральный.
- Толщина больше 1 px: акцент — это не разделитель.

## Анатомия

1. **Кнопка сворачивания** (необязательная) — Шеврон 12 px на подложке 20 px (радиус 4, отрицательный отступ −4 px, чтобы шеврон стоял по сетке). Открыто — шеврон вниз (поворот 90°).
2. **Заголовок раздела** — Onest 700, в одну строку, без переноса.
3. **Линия** — 1 px, --border (в разделе) или --divider (отдельный разделитель); тянется до края.
4. **Содержимое** — Ряды и поля раздела. Свёрнутый раздел оставляет только краткое содержание.
5. **Краткое содержание** (необязательная) — 12 px, --text-3: «3 документа · 1 с расхождением». Показывается только в свёрнутом виде.

## Варианты

- **Линия и сильная линия** (`line`): 1 px; обычная --divider, сильная --border. Когда: обычная — между строками и блоками; сильная — между крупными частями страницы или панелями.
- **С подписью** (`labelled`): Подпись по центру («или»), линии по бокам. 12 px, 600, --text-3. Когда: альтернативы: «Войти через 1С» — «или» — «Загрузить файл».
- **Вертикальный** (`vertical`): 1×20 px, отступы 6 px по бокам. Между кнопками тулбара. Когда: группы действий: «Фильтр | Колонки | Экспорт». Не для строк таблицы.
- **Раздел с заголовком** (`section`): Заголовок, линия, кнопка сворачивания и краткое содержание в свёрнутом виде. Когда: группы внутри карточки груза: «Документы», «Участники». Если разделов несколько и они объёмные, берите Accordion.

## Состояния

### Применимые

- **Default** (`default`): Линия статична. Состояния есть только у кнопки раздела.
- **Hover (кнопка)** (`hover`): Подложка шеврона слоем 9 % (--layer-2).
- **Active (кнопка)** (`active`): Слой 12 % (--layer-3).
- **Focus (кнопка)** (`focus`): Кольцо 2 px --focus вокруг подложки шеврона.
- **Свёрнут** (`selected`, `collapsed`): aria-expanded=false, шеврон вправо, вместо рядов — краткое содержание.
- **Disabled (кнопка)** (`disabled`): Раздел нельзя свернуть: шеврон --text-ph. [TODO] предложение; в макете такого нет.

### Не применимы (с причиной)

- **Loading** (`loading`): Линия не загружается. Загрузку показывает содержимое раздела (Skeleton).
- **Error** (`error`): Красной линии нет: ошибка выражается плашкой или текстом внутри раздела.
- **Empty** (`empty`): Пустой раздел не показывают; нет данных — нет заголовка.

## Размеры и токены

### Токены

| Название | Значение | Назначение |
| --- | --- | --- |
| `--divider` | #e0e4e9 / #323e4b | Линия обычная, вертикальная, у подписи |
| `--border` | #c6cdd6 / #4d5b6b | Сильная линия; линия заголовка раздела |
| `--text-3` | #66727f | Подпись «или», краткое содержание |
| `--layer-2 / --layer-3` | 9 % / 12 % ink | Hover/active кнопки раздела |
| `height` | 1 px · 20 px | Горизонтальная · вертикальная |
| `margin` | 0 6 px | Вертикальный разделитель |
| `--dur · --ease` | 200 мс | Поворот шеврона раздела (rotate) |

## Доступность

- **role=separator** (`aria`): <hr> по умолчанию имеет эту роль. Декоративную линию помечают role="none" или aria-hidden, чтобы её не объявляли. Вертикальный — aria-orientation="vertical".
- **Раздел: aria-expanded** (`aria`): Кнопка сворачивания держит aria-expanded и aria-label «Свернуть: …» / «Развернуть: …»; название раздела в самом ярлыке.
- **Enter / Space** (`key`): Сворачивают и разворачивают раздел. Линии в Tab не входят.
- **Куда идёт фокус** (`focus`): Остаётся на кнопке раздела; при сворачивании содержимое выпадает из порядка Tab (display:none / inert).
- **Контраст линий** (`contrast`): Линия — не носитель смысла: --divider (#e0e4e9) на белом 1,3:1, --border 1,7:1. Разделение не должно быть единственным признаком группы: рядом всегда отступ или заголовок. Подпись «или» --text-3 на --surface 4,9:1.
- **prefers-reduced-motion** (`motion`): Шеврон поворачивается без перехода; плавное сворачивание высоты отключается.

## Хореография

### Сворачивание раздела (`collapse`, origin: mockup)

- **Триггер:** клик по кнопке раздела, Enter или Space

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: подложка шеврона. | background | ease |
| 500 | 0 | Клик: aria-expanded=false, ряды исчезают, появляется краткое содержание. В макете содержимое перерисовывается сразу. | display | — |
| 500 | 200 | Шеврон поворачивается 90° → 0 (вправо). | rotate | --ease |
| 1300 | 0 | Повторный клик: возврат с поворотом шеврона и показом рядов. | display, rotate | — |

- **Фокус:** Остаётся на кнопке раздела.

- **Reduced motion:** Шеврон меняет положение мгновенно.

- **Соседи:** Блоки ниже сдвигаются мгновенно вслед за высотой раздела. [TODO] в макете нет плавности высоты; вариант ниже предложен.

### Плавная высота (предложение) (`animated`, origin: proposal)

- **Триггер:** то же, но с анимацией содержимого

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 200 | Содержимое сворачивается: grid-template-rows 1fr→0fr, одновременно шеврон поворачивается. | grid-template-rows, rotate | --ease |
| 0 | 0 | Краткое содержание появляется сразу и занимает место свёрнутого. | display | — |
| 1200 | 200 | Обратно: 0fr→1fr; краткое содержание скрывается. | grid-template-rows | --ease |

- **Фокус:** Остаётся на кнопке.

- **Reduced motion:** Высота меняется мгновенно.

- **Соседи:** Соседние блоки сдвигаются плавно вместе с высотой, как под Accordion (250 мс там, 200 мс здесь: [TODO] выровнять).

## Примеры

### Тулбар списка (`toolbar`)

```tsx
<div role="toolbar" aria-label="Действия со списком">
  <Button variant="ghost" size="sm">Фильтр</Button>
  <Separator orientation="vertical" decorative />
  <Button variant="ghost" size="sm">Колонки</Button>
</div>
```

### Раздел карточки (`section`)

```tsx
<SectionHeader title="Документы груза" summary="3 документа · 1 с расхождением">…</SectionHeader>
```

## Как использовать

<!-- manual:start -->
Компоненты: `Separator`, `SectionHeader`. Типы: `SeparatorProps`, `SeparatorOrientation`, `SectionHeaderProps`.

```tsx
import { SectionHeader, Separator } from "@/ui";
```

`Separator` (атрибуты `<hr>`, с подписью `<div>`; `ref`):

| Проп          | Тип                          | По умолчанию   | Описание                                                                                    |
| ------------- | ---------------------------- | -------------- | ------------------------------------------------------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Направление. Вертикальная линия 20 px с полями 6 px.                                        |
| `strong`      | `boolean`                    | нет            | Горизонтальная линия цвета границы вместо разделителя.                                      |
| `decorative`  | `boolean`                    | нет            | `role="none"`: линия не объявляется скринридером.                                           |
| `children`    | `ReactNode`                  | нет            | Подпись («или»): линия с текстом по центру, `role="separator"`.                             |

`SectionHeader` (атрибуты `<section>`): `title` (обязателен, строка), `collapsible` (`true`), `open` / `defaultOpen` (`true`) / `onOpenChange`, `animated` (плавное сворачивание вместо мгновенного), `summary` (текст под свёрнутым разделом), `summaryAlways` (показывать и у раскрытого), `headingLevel` (`3`), `disabled`. Дочерние элементы — содержимое раздела.

```tsx
<Separator />
<Separator strong />
<Separator>или</Separator>

<div role="toolbar" aria-label="Действия со списком">
  <Button variant="ghost" size="sm">Фильтр</Button>
  <Separator orientation="vertical" decorative />
  <Button variant="ghost" size="sm">Колонки</Button>
</div>

<SectionHeader title="Документы груза" summary="3 документа · 1 с расхождением" animated>
  <DocumentsList />
</SectionHeader>
```

Доступность:

- Горизонтальная линия — `<hr>`; чисто декоративную помечайте `decorative`. Вертикальная получает `aria-orientation="vertical"`.
- Кнопка раздела: `aria-expanded`, `aria-controls`, `aria-label` «Свернуть: …» / «Развернуть: …»; название раздела — заголовок `role="heading"` с `aria-level`. Свёрнутое содержимое `inert`. Линии в Tab не входят.

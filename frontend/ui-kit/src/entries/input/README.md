# Input

Текстовое поле: с подписью и подсказкой, с значком, единицей и ×, многострочное, inline и поиск над списком.

Input принимает короткий текст или число: номер контейнера, вес, комментарий. Подпись всегда над полем, подсказка и ошибка под ним. Inline-поле правит значение прямо в тексте карточки; search фильтрует список без рамки. Для выбора из готовых значений берите Select, для даты DatePicker.

- **id:** `input`
- **Группа:** Поля (`fields`)
- **CSS-префикс:** `ds-input`
- **Origin хореографии:** mockup (2), proposal (1)

## Когда использовать / не использовать

### Использовать

- Подпись над полем всегда: placeholder её не заменяет.
- Placeholder показывает формат (MSKU4821907), а не повторяет подпись.
- Подсказка о формате под полем; при ошибке на её месте текст ошибки.
- Ошибка говорит, что исправить и сколько («Нужно 11 символов, сейчас 9»).
- Единицу («кг») выносите внутрь поля, а не в подпись.
- Inline-поле — для правки значения в карточке, где рамка шумела бы.

### Не использовать

- Placeholder вместо подписи: пропадает после первого символа.
- Показывать ошибку на пустое поле до того, как человек начал вводить.
- Цвет без текста: красной рамки без сообщения недостаточно.
- Disabled для данных, которые пользователь должен видеть и копировать: берите read-only текст.
- Ставить поля вплотную: ореол фокуса 3px заезжает на соседа.

## Анатомия

1. **Поле (field)** — Колонка: подпись, рамка, подсказка или ошибка; зазор 4. Растягивается на ширину контейнера.
2. **Подпись** — 12 px 600 над рамкой. Обязательна: нет подписи — нужен aria-label.
3. **Значок слева** (необязательная) — 14 px --text-3; в фокусе --link. Для поиска и поля с типом данных. Необязателен.
4. **Ввод** — Рамка 1px, радиус 8, высота 32 (28 в compact), padding 0 12. Placeholder --text-ph. Числа выравниваются вправо, цифры табличные.
5. **Единица** (необязательная) — «кг», «м³» справа внутри рамки, --text-3. Необязательна.
6. **Подсказка / ошибка** (необязательная) — Под рамкой 12 px: подсказка --text-3; при ошибке заменяется текстом --err-text. Ещё могут быть × (очистка) и подсказка клавиши (kbd).

## Варианты

- **Поле формы** (`field`): Подпись над рамкой, подсказка под ней. Высота 32. Когда: любая форма: номер, имя, ИНН.
- **Со значком, единицей и ×** (`content`): Значок слева, единица справа, очистка × у поиска. Числа выравниваются вправо (tabular-nums). Когда: поиск с фильтром по клиенту; вес и объём с единицей.
- **Compact · 28** (`compact`): Высота 28 вместо 32. Та же рамка и ореол. Когда: фильтры над таблицей, плотные панели.
- **Textarea** (`area`): Несколько строк, padding 7 12, значки и единица прижаты вверх; ручки изменения размера нет. Когда: комментарий к грузу, примечание.
- **С подсказкой клавиши** (`kbd`): Справа рамка 11 px с клавишей: «/» фокусирует поиск. Когда: глобальный поиск, где есть горячая клавиша. [TODO] в макете подсказка нарисована, но сама клавиша «/» не обработана.
- **Inline** (`inline`): Поле как текст: на hover подложка --layer-1, в фокусе --layer-1p, ошибка — красная линия под текстом. Когда: правка значения прямо в карточке: название, получатель.
- **Search** (`search`): Без рамки, лупа 16 px; подложка --layer-1 на hover и --layer-1p в фокусе. Лупа лежит на вертикали галочек списка под ним. Когда: поиск над списком или меню (Select с поиском использует тот же ряд).

## Состояния

### Применимые

- **Обычное** (`default`): Рамка 1px --border, фон --field, подпись над полем, подсказка под ним.
- **Hover** (`hover`): Рамка темнеет до --text-3.
- **Focus** (`focus`): Рамка --focus и ореол 3px --selected вокруг. Значок слева переходит в --link. Показывается и на клик, и на Tab.
- **Ошибка** (`error`): Рамка --danger, под полем текст --err-text 500. В фокусе ореол 3px красный (danger 22 %).
- **Ошибка в фокусе** (`error`, `error-focus`): Красная рамка сохраняется, ореол переходит с teal на красный.
- **Disabled** (`disabled`): Фон прозрачный, рамка --divider, текст --text-ph, курсор default. Для значений, которые заполняет система.
- **Пустое** (`empty`): Placeholder --text-ph подсказывает формат (MSKU4821907), а не повторяет подпись. Кнопка очистки скрыта.

### Не применимы (с причиной)

- **Active** (`active`): Отдельного вида нет: нажатие ставит курсор, и поле переходит в фокус. [TODO] подтвердить.
- **Loading** (`loading`): Нет в макете. Поле не показывает ожидание. [TODO] для проверки на сервере (уникальность номера) решить: значок-спиннер справа и aria-busy.

## Доступность

- **Подпись** (`aria`): Видимая подпись связана с input (aria-labelledby или label); без видимой подписи — aria-label.
- **Подсказка и ошибка** (`aria`): aria-describedby на элемент с подсказкой или ошибкой; при ошибке aria-invalid="true". Появление ошибки при вводе можно объявить через role="status" на строке сообщения. [TODO] в макете этого нет.
- **Tab / Shift+Tab** (`key`): Ходят по полям; кнопка × входит в порядок после input; kbd-подсказка — не элемент управления.
- **Esc** (`key`): [TODO] предложение: в поле поиска очищает текст.
- **Фокус** (`focus`): Рамка --focus и ореол 3px --selected вместо outline. Рамка --focus на белом 3,65:1, в тёмной 10,0:1. Ореол как единственный сигнал слабый (teal 15 %), поэтому рамка обязательно меняет цвет.
- **Рамка поля** (`contrast`): --border на белом 1,6:1 (светлая) и 2,7:1 на --field в тёмной: ниже 3:1 для границ компонентов. На hover --text-3 даёт 4,9:1. [TODO] решить, усиливать ли обычную рамку.
- **Текст** (`contrast`): Текст --text 16,5:1; подсказка и единица --text-3 4,9:1 (светлая), 8,1:1 (тёмная); ошибка --err-text 5,5:1 и 7,8:1; placeholder --text-ph на --field 3,2:1 (светлая) и 5,4:1 (тёмная): в светлой ниже 4,5:1, подсказка в нём не должна быть единственной.
- **prefers-reduced-motion** (`motion`): Переходы рамки, ореола, значка и подложки отключаются.

## Хореография

### Наведение и фокус (`focus`, origin: mockup)

- **Триггер:** курсор входит в поле, затем клик или Tab

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Hover: рамка --border → --text-3. | border-color | ease |
| 800 | 125 | Фокус: рамка идёт к --focus, вокруг появляется ореол 3px --selected. | border-color, box-shadow | ease |
| 800 | 125 | Значок слева перекрашивается --text-3 → --link. | color | ease |
| 2400 | 125 | Потеря фокуса: ореол и цвета возвращаются. | border-color, box-shadow, color | ease |

- **Фокус:** Клик в любое место рамки (в том числе в padding и на значок) ставит курсор в input: рамка — это label. Кольца outline нет: роль кольца играет ореол.

- **Reduced motion:** Переходы отключены: рамка, ореол и значок меняются мгновенно.

- **Соседи:** Размеры не меняются: ореол рисуется box-shadow'ом и соседей не двигает. Но он выходит за рамку на 3px: между полями оставляйте зазор не меньше 8.

### Проверка при вводе (`validate`, origin: mockup)

- **Триггер:** ввод символа в поле «Номер контейнера»

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Каждый символ приводится к верхнему регистру; проверка по шаблону: 4 буквы и 7 цифр. | value | — |
| 1000 | 125 | Введён хотя бы один неверный символ: рамка идёт к --danger, подсказка под полем заменяется текстом «Нужно 4 буквы и 7 цифр, сейчас N симв.» (сразу, без анимации); ореол в фокусе красный. | border-color, box-shadow | ease |
| 2100 | 125 | Введено верное (11 символов): рамка возвращается к --focus, возвращается подсказка «4 буквы и 7 цифр», кнопка «Продолжить» в диалоге разблокируется. | border-color, box-shadow | ease |

- **Фокус:** Остаётся в поле всё время ввода. Пустое поле ошибкой не считается: она появляется только когда что-то введено неверно.

- **Reduced motion:** Рамка меняет цвет мгновенно, текст сообщения заменяется как обычно.

- **Соседи:** Подсказка и ошибка занимают одну строку под полем и заменяют друг друга: высота формы не меняется. Если сообщение длиннее строки, формы ниже сдвигаются.

### Очистка × (`clear`, origin: proposal)

- **Триггер:** клик по × в поле поиска

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Hover на ×: подложка --layer-2 (20×20, радиус 4). | background | ease |
| 600 | 0 | Клик: значение очищается, × исчезает вместе с текстом. | value | — |
| 600 | 0 | Фокус возвращается в input, курсор в пустом поле; список под полем переходит в «все». | focus | — |

- **Фокус:** После очистки фокус в поле, не на ×: иначе второй клик по пустому месту приходит в никуда. × в Tab входит (после input), Esc внутри поля тоже очищает. [TODO] в макете × нарисован, но не обработан.

- **Reduced motion:** Подложка кнопки меняется без перехода.

- **Соседи:** Единица справа остаётся на месте: × появляется внутри рамки, а ширина поля не меняется (отрицательный отступ −6 убирает сдвиг текста).

## Как использовать

Импорт: в ките — `import { InlineInput, Input, SearchInput, Textarea } from "@/ui"`, в приложении — `import { InlineInput, Input, SearchInput, Textarea } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компоненты `Input`, `Textarea`, `InlineInput`, `SearchInput`. Типы: `InputProps`, `TextareaProps`, `InlineInputProps`, `SearchInputProps`.

```tsx
import { Input, Textarea, InlineInput, SearchInput } from "@/ui";
```

Пропсы `Input` (плюс атрибуты `<input>`: `type`, `name`, `placeholder`, `disabled`, `aria-*`, `ref`, `className` — всё попадает на `input`):

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `label` | `ReactNode` | нет | Видимая подпись над полем (связана через `aria-labelledby`). Без неё имя берётся из `aria-label` или `placeholder`. |
| `hint` | `ReactNode` | нет | Подсказка под полем (`aria-describedby`). |
| `error` | `ReactNode` | нет | Текст ошибки вместо подсказки; ставит `aria-invalid` и красную рамку. |
| `invalid` | `boolean` | нет | Красная рамка без текста ошибки. |
| `value` / `defaultValue` | `string` | `""` | Управляемое и начальное значение. |
| `onValueChange` | `(value: string) => void` | нет | Новое значение; нативный `onChange` тоже работает. |
| `lead` | `ReactNode` | нет | Значок слева (скрыт от скринридера, синеет в фокусе). |
| `unit` | `ReactNode` | нет | Единица справа («кг»). |
| `kbd` | `ReactNode` | нет | Подсказка клавиш справа; не элемент управления. |
| `clearable` | `boolean` | нет | Кнопка «Очистить» при непустом значении; Esc в поле тоже очищает. |
| `onClear` | `() => void` | нет | Вызывается после очистки. |
| `compact` | `boolean` | нет | Высота 28 px вместо 32 px. |
| `numeric` | `boolean` | нет | Цифры по правому краю, `tabular-nums`. |
| `fieldClassName` | `string` | нет | Класс на внешнюю обёртку поля. |

`Textarea` принимает те же `label`, `hint`, `error`, `invalid`, `unit`, `compact`, `value`, `defaultValue`, `onValueChange`, `fieldClassName` и атрибуты `<textarea>` (`rows` по умолчанию 3). `InlineInput` — поле правки прямо в тексте: `width?: number`, `invalid`, `value`, `onValueChange`, `wrapperClassName`. `SearchInput` — поиск без рамки: значок лупы, `placeholder` (по умолчанию «Поиск», он же имя), `role="searchbox"`, Esc очищает.

```tsx
<Input label="Номер контейнера" placeholder="MSKU4821907" hint="4 буквы и 7 цифр"
  error={bad ? `Нужно 4 буквы и 7 цифр, сейчас ${v.length} симв.` : undefined}
  value={v} onValueChange={setV} />

<Input compact lead={<SearchIcon />} clearable placeholder="Фильтр по клиенту" kbd="/" />

<Input label="Вес" unit="кг" numeric defaultValue="18420" />

<Textarea label="Комментарий" hint="Видят все участники" />
```

Доступность:

- Видимая подпись связана через `aria-labelledby`, подсказка и ошибка — через `aria-describedby`; при ошибке `aria-invalid="true"`.
- Фокус показывает рамка `--focus` и ореол, а не `outline`.
- Tab идёт сначала к полю, затем к кнопке «Очистить».
- Переходы рамки и ореола отключаются при `prefers-reduced-motion`.

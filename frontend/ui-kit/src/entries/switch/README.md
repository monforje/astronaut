# Switch

Переключатель «включено / выключено» для настройки. Срабатывает сразу, без кнопки «Сохранить».

Switch лежит в строке настроек: заголовок и пояснение слева, переключатель справа. Положение сразу применяется и сразу действует: «Уведомления о расхождениях», «Автосверка при загрузке». Если выбор нужно подтвердить вместе с другими полями формы, берите Checkbox; если это фильтр или режим рядом с контентом, Toggle.

- **id:** `switch`
- **Группа:** Поля (`fields`)
- **CSS-префикс:** `ds-switch`
- **Origin хореографии:** mockup (2)

## Когда использовать / не использовать

### Использовать

- Настройка, которая действует сразу после переключения.
- Строка настроек: заголовок слева, переключатель справа, пояснение мелким текстом.
- Подпись описывает функцию («Автосверка»), а не действие («Включить автосверку»).
- Недоступную настройку оставляйте в списке с disabled и причиной в пояснении.
- При ошибке сохранения верните положение назад и скажите об этом в Toast.

### Не использовать

- Switch в форме, которая отправляется кнопкой: нужен Checkbox.
- Выбор из трёх и более вариантов: ToggleGroup или Radio.
- Switch без подписи: читателю экрана и пользователю неясно, что он включает.
- Один и тот же параметр одновременно Switch и Checkbox на странице.
- Менять подпись при переключении («Включено» / «Выключено»).

## Анатомия

1. **Дорожка** — 36×20 px (28×16 в sm), радиус pill. Выключена: ink 24 % на --surface; включена: --primary.
2. **Бегунок** — Круг 16 px (12 в sm), всегда белый, тень 0 1px 2px. Сдвигается на 16 px (12 в sm); отступ от края 2 px.
3. **Подпись** — Справа от дорожки или слева в строке настроек, вместе с пояснением 11 px --text-3. Подпись обязательна: input получает имя из label или aria-label.

## Варианты

- **Строка настроек** (`settings-row`): Заголовок и пояснение слева, переключатель справа. Строки разделены линией --divider, зазор 16. Когда: экран настроек: уведомления, автосверка, экспорт. Основной вид.
- **С подписью справа** (`label-right`): Подпись рядом, зазор 8. Вся подпись нажимаема, как у Checkbox. Когда: один параметр в панели, где строка настроек избыточна.

## Состояния

### Применимые

- **Выключен** (`default`): Дорожка ink 24 % на --surface, бегунок слева.
- **Hover** (`hover`): Дорожка темнее: ink 34 % вместо 24 %.
- **Focus** (`focus`): Кольцо 2px --focus с отступом 2px вокруг дорожки, только от клавиатуры.
- **Включён** (`selected`, `on`): Дорожка --primary (teal), бегунок справа (сдвиг 16 px).
- **Hover включённого** (`hover`, `on-hover`): Дорожка темнее на 9 % (смешение с чёрным в oklch).
- **Disabled выключен** (`disabled`): Дорожка --tone, бегунок --surface с кольцом --divider. Свои цвета, не прозрачность.
- **Disabled включён** (`disabled`, `disabled-on`): Дорожка teal 30 % на --surface; бегунок справа.

### Не применимы (с причиной)

- **Active** (`active`): Отдельного вида нет: нажатие сразу переключает, а hover остаётся под курсором. [TODO] решить, нужен ли слой на время нажатия.
- **Loading** (`loading`): Нет в макете: переключатель срабатывает сразу. Если действие идёт на сервер, положение меняется оптимистично, а при ошибке возвращается с Toast. [TODO] подтвердить.
- **Error** (`error`): Нет: у Switch нет неверного положения. Ошибку сохранения показывает Toast, переключатель возвращается назад.
- **Empty** (`empty`): Нет: у Switch всегда одно из двух положений.

## Доступность

- **role="switch"** (`aria`): Нативный <input type="checkbox" role="switch">: состояние хранит checked, aria-checked ставит браузер. Имя — из label или aria-label.
- **Space** (`key`): Переключает. Enter не переключает (как у checkbox). Tab и Shift+Tab ходят по переключателям.
- **Кольцо** (`focus`): 2px --focus, outline-offset 2px, только :focus-visible. 3,65:1 на белом, 9,34:1 в тёмной.
- **Дорожка и бегунок** (`contrast`): Светлая тема: выключенная дорожка на белом 1,7:1, включённая teal 1,85:1, белый бегунок на teal 1,85:1: все ниже 3:1 для границ компонентов. В тёмной: выключенная 2,2:1, включённая 9,3:1, бегунок на ней 1,85:1. Состояние читается и по положению бегунка, но [TODO] усилить дорожку или добавить обводку.
- **Подпись** (`contrast`): Заголовок --text на --surface 16,5:1; пояснение --text-3 4,9:1 (светлая), 7,6:1 (тёмная). Disabled — --text-ph, вне нормы.
- **prefers-reduced-motion** (`motion`): Ход бегунка и смена цвета дорожки отключаются.

## Хореография

### Переключение (`flip`, origin: mockup)

- **Триггер:** клик по дорожке или подписи, тап

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: дорожка темнеет (ink 24 % → 34 %). | background | ease |
| 600 | 125 | Клик: дорожка меняет цвет к --primary (teal). | background | ease |
| 600 | 200 | Бегунок едет вправо на 16 px (12 в sm). Обратно при выключении — тем же ходом. | translate | var(--ease) = cubic-bezier(.6,0,.05,.95) |

- **Фокус:** Остаётся на переключателе. Клик по подписи (label) переключает и ставит фокус на input.

- **Reduced motion:** Бегунок и дорожка переключаются мгновенно.

- **Соседи:** Не двигаются: размеры не меняются. В строке настроек подпись не реагирует на положение, пояснение остаётся тем же.

### Клавиатура (`keyboard`, origin: mockup)

- **Триггер:** Tab до переключателя, Space

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Tab: кольцо 2px --focus с отступом 2px появляется сразу. | outline | — |
| 900 | 200 | Space: бегунок едет, дорожка меняет цвет (125 мс). Повторный Space возвращает назад. | translate, background | var(--ease) |

- **Фокус:** Остаётся на переключателе; Tab идёт к следующему. Кольцо вокруг дорожки, не вокруг строки.

- **Reduced motion:** Бегунок перескакивает, кольцо фокуса остаётся.

- **Соседи:** Строка настроек не меняет высоты, соседние строки не затрагиваются.

## Как использовать

Импорт: в ките — `import { SettingRow, Switch } from "@/ui"`, в приложении — `import { SettingRow, Switch } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компоненты `Switch` (`<input type="checkbox" role="switch">`) и `SettingRow` (строка настроек). Типы: `SwitchProps`, `SwitchSize`, `SettingRowProps`.

```tsx
import { Switch, SettingRow } from "@/ui";
```

Пропсы `Switch` (плюс атрибуты `<input>`: `name`, `value`, `disabled`, `aria-*`, `ref` — всё попадает на `input`):

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `checked` | `boolean` | нет | Управляемое положение. |
| `defaultChecked` | `boolean` | `false` | Начальное положение без управления. |
| `onCheckedChange` | `(checked: boolean) => void` | нет | Вызывается с новым положением; нативный `onChange` тоже работает. |
| `size` | `"md" \| "sm"` | `"md"` | Дорожка 36×20 или 28×16. |
| `label` | `ReactNode` | нет | Подпись справа: переключатель оборачивается в `<label>`, `className` попадает на неё. Без `label` нужен `aria-label`. |

Пропсы `SettingRow` (плюс атрибуты `<label>`): `title: ReactNode` — заголовок, `hint?: ReactNode` — пояснение; `children` — сам `Switch`.

```tsx
<Switch label="Автосверка" checked={auto} onCheckedChange={setAuto} />

<SettingRow title="Автосверка при загрузке" hint="Сразу после загрузки">
  <Switch checked={auto} onCheckedChange={setAuto} />
</SettingRow>

<Switch size="sm" aria-label="Компактный вид" />
```

Доступность:

- Нативный checkbox с `role="switch"`: Space переключает, Enter нет; состояние в `checked` (`aria-checked` держится в синхроне).
- Имя из `label`, объемлющего `<label>` (`SettingRow`) или `aria-label`.
- Строки `SettingRow` стоит класть в общий контейнер: разделительная линия рисуется между соседними строками.
- Ход бегунка и смена цвета отключаются при `prefers-reduced-motion`.

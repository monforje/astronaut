# Topbar

Верхняя панель экрана: крошки слева, глобальный поиск по Ctrl K по центру, тема, уведомления и профиль справа.

Топбар общий для всех страниц. Крошки слева заменяют заголовок страницы, поиск по центру всегда под рукой (Ctrl K), справа — то, что нужно человеку, а не странице: смена темы, уведомления, профиль с меню. Высота равна высоте бренда в сайдбаре (56 px), поэтому две панели образуют одну линию. Топбар липкий и не прокручивается с контентом.

- **id:** `topbar`
- **Группа:** Навигация (`navigation`)
- **CSS-префикс:** `ds-top`
- **Origin хореографии:** mockup (2), proposal (1)

## Когда использовать / не использовать

### Использовать

- Крошки слева вместо заголовка страницы; последний пункт — страница.
- Один поиск на весь продукт, открывается по Ctrl K откуда угодно.
- Справа только персональное: тема, уведомления, профиль; действия страницы живут в самой странице.
- Счётчик уведомлений — число до 9, дальше «9+»; пропадает, когда всё прочитано.
- Высота 56 px совпадает с брендом сайдбара: линия под ними единая.

### Не использовать

- Заголовок страницы в топбаре рядом с крошками: дублирование.
- Кнопки действий («Создать груз») в топбаре: они принадлежат странице.
- Больше трёх иконок справа: остальное в меню профиля.
- Цветной фон топбара или navy: панель нейтральная.
- Перекрывать топбар панелями и диалогами: он остаётся под overlay затемнением, а не над ним.

## Анатомия

1. **Контейнер header** — Липкий, высота 56 px (--h-bar), фон --surface, линия --divider снизу, поля 16 px. Сетка из трёх колонок: minmax(0,1fr) · minmax(0,420px) · minmax(max-content,1fr), зазор 12: крошки сжимаются, действия всегда целиком.
2. **Крошки** — nav слева: ссылки --text-2, текущая --text 600. Разделитель — шеврон, как в Breadcrumb (в макете был «/»: сведено к одному). Левая колонка сжимается первой: промежуточные пункты усекаются с многоточием, последний держится дольше.
3. **Поиск** — Поле 28 px с радиусом 8: значок, подсказка «Поиск по грузам, клиентам, документам», метка «Ctrl K». Ширина до 420 px, по центру страницы.
4. **Смена темы** — Квадратная ghost-кнопка 32 px: луна в светлой теме, солнце в тёмной.
5. **Уведомления** — Квадратная ghost-кнопка с колоколом; число непрочитанного — красная капсула в углу. [TODO] открытие панели уведомлений в макете не показано.
6. **Профиль** — Кнопка-капсула: аватар 24 px + шеврон, открывает меню (aria-haspopup=menu): имя и роль, «Профиль», «Настройки», «Выйти».

## Варианты

- **Полный** (`full`): Все три зоны: крошки, поиск, действия. Для экрана от ~900 px шириной. Когда: обычные страницы приложения.
- **Узкий (мобильный)** (`narrow`): Поиск скрыт, колонки minmax(0,1fr) и auto. В макете (≤ 760 px) пропадает и сайдбар. [TODO] кнопка поиска-значка вместо поля и мобильное меню в макете не нарисованы. Когда: экраны уже 760 px (в словаре — контейнер уже 720 px).
- **Корневая страница** (`no-crumbs`): Крошек нет (раздел верхнего уровня): слева остаётся название страницы текстом, остальное то же. [TODO] предложение; в макете даже у корня две крошки. Когда: «Главная», дашборд: страница без вложенности.

## Состояния

### Применимые

- **Default** (`default`): Кнопки --text-2 без подложки, поиск с рамкой --border.
- **Hover** (`hover`): Кнопка и профиль: слой 9 % (--layer-2). Поиск: рамка --text-3. Ссылка-крошка: слой 9 %.
- **Active** (`active`): Слой 12 % (--layer-3) на нажатой кнопке.
- **Focus** (`focus`): Кнопки: кольцо 2 px --focus. Поиск: рамка --focus + ореол 3 px --selected, значок --link.
- **Профиль · меню открыто** (`selected`, `expanded`): aria-expanded=true: подложка hover остаётся, шеврон повёрнут на 180°.
- **Loading (поиск)** (`loading`): Поиск в процессе: вместо значка лупы спиннер 14 px (0,8 с на оборот), поле остаётся активным. [TODO] предложение.
- **Empty** (`empty`): Нет непрочитанных: красной капсулы нет, колокол обычный (слева). Поиск без ввода показывает подсказку и «Ctrl K».

### Не применимы (с причиной)

- **Disabled** (`disabled`): Нет: элементы топбара доступны всегда; недоступные действия убирают из меню профиля или показывают в нём серыми.
- **Error** (`error`): Нет собственного вида: ошибку поиска показывает выпадающий список результатов («Не удалось выполнить поиск»), не топбар. Ошибка загрузки уведомлений — внутри их панели.

## Доступность

- **header + nav** (`aria`): Топбар — header (banner); крошки внутри nav aria-label «Навигация», текущая страница aria-current="page". Для поиска — aria-label «Глобальный поиск» и aria-keyshortcuts="Control+K".
- **Кнопки-иконки** (`aria`): У каждой есть aria-label («Сменить тему», «Уведомления, 3 новых», «Профиль»). Профиль: aria-haspopup="menu" и aria-expanded.
- **Ctrl + K** (`key`): Фокус в поле поиска из любого места (в макете без Cmd у Mac: [TODO] добавить Meta+K).
- **Enter / Esc в меню** (`key`): Профиль открывается Enter/Space/↓; Esc закрывает меню и возвращает фокус на кнопку профиля. [TODO] макет не описывает клавиатуру меню, это предложение.
- **Порядок фокуса** (`focus`): Крошки → поиск → тема → уведомления → профиль. Skip-ссылка «К содержимому» перед топбаром [TODO] предложение.
- **Контраст** (`contrast`): Значки --text-2 на --surface 8,2:1; подсказка поиска --text-ph 3,4:1 (placeholder, допустимо для подсказки); метка Ctrl K --text-3 4,9:1; белый на красной капсуле счётчика 4,9:1.
- **prefers-reduced-motion** (`motion`): Меню профиля и подсказки появляются без масштаба и сдвига; спиннер поиска вращается в три раза медленнее; hover без перехода.

## Хореография

### Поиск: Ctrl K и ввод (`search`, origin: mockup)

- **Триггер:** Ctrl K или клик в поле

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: рамка поиска темнеет до --text-3. | border-color | ease |
| 700 | 0 | Фокус (Ctrl K или клик): курсор в поле. | focus | — |
| 700 | 125 | Рамка уходит к --focus, появляется ореол 3 px --selected, значок лупы красится в --link. | border-color, box-shadow, color | ease |
| 1100 | 0 | Ввод: список результатов открывается под полем. [TODO] в макете у топбара только поле; результаты — общий компонент Select/Popover. | — | — |
| 2400 | 125 | Esc или уход: рамка и ореол возвращаются. | border-color, box-shadow | ease |

- **Фокус:** В поле поиска. Esc возвращает фокус туда, где он был до Ctrl K.

- **Reduced motion:** Рамка и ореол меняются без перехода.

- **Соседи:** Поле не меняет размер и не сдвигает крошки или кнопки; сетка с центральной колонкой до 420 px фиксирована.

### Смена темы (`theme`, origin: mockup)

- **Триггер:** клик по кнопке «Сменить тему»

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение и нажатие: слои 9 % и 12 %. | background | ease |
| 600 | 0 | Значок меняется мгновенно: луна ↔ солнце. В макете innerHTML заменяется целиком. | icon | — |
| 600 | 0 | Токены переключаются через data-theme на документе: все цвета меняются разом. [TODO] перехода между темами в макете нет; плавная смена фона 200 мс — предложение. | color, background | — |

- **Фокус:** Остаётся на кнопке.

- **Reduced motion:** Не затрагивается: переходов между темами нет.

- **Соседи:** Весь экран перекрашивается одновременно; размеры и положение не меняются. Выбор хранится в localStorage (ключ темы).

### Меню профиля (`profile`, origin: proposal)

- **Триггер:** клик, Enter или Space по аватару

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: подложка капсулы (слой 9 %). | background | ease |
| 600 | 125 | Меню появляется под кнопкой: opacity 0→1, scale .96→1, сдвиг −4 px→0. | opacity, scale, translate | --ease |
| 600 | 200 | Шеврон поворачивается на 180°, подложка остаётся пока меню открыто. | rotate | --ease |
| 2600 | 0 | Esc, выбор пункта или клик вне меню закрывает его мгновенно. | — | — |

- **Фокус:** В меню — на первый пункт; Esc возвращает на аватар.

- **Reduced motion:** Меню без масштаба и сдвига, шеврон без поворота-перехода.

- **Соседи:** Меню лежит поверх страницы; соседние кнопки топбара не сдвигаются. [TODO] время и движение берутся у общего popover (125 мс); отдельно в макете не заданы.

## Как использовать

Импорт: в ките — `import { Topbar, TopbarAction, TopbarProfile, TopbarSearch } from "@/ui"`, в приложении — `import { Topbar, TopbarAction, TopbarProfile, TopbarSearch } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компоненты: `Topbar`, `TopbarSearch`, `TopbarAction`, `TopbarProfile`. Типы: `TopbarProps`, `TopbarCrumb`, `TopbarSearchHotkey`, `TopbarSearchProps`, `TopbarSearchRootProps`, `TopbarActionProps`, `TopbarProfileProps`, `TopbarMenuItem`.

```tsx
import { Topbar, TopbarAction, TopbarProfile, TopbarSearch } from "@/ui";
```

`Topbar` (атрибуты `<header>`, `ref`) — три слота в сетке; ниже 720 px контейнера поиск скрывается:

| Проп           | Тип                         | По умолчанию | Описание                                                                                   |
| -------------- | --------------------------- | ------------ | ------------------------------------------------------------------------------------------ |
| `crumbs`       | `TopbarCrumb[]`             | нет          | Крошки `{ label, href?, onClick? }`; последняя текущая, без `href` — кнопка.               |
| `crumbsLabel`  | `string`                    | «Навигация»  | Название навигации крошек.                                                                 |
| `start`        | `ReactNode`                 | нет          | Заменяет крошки (например, заголовок страницы).                                            |
| `search`       | `ReactNode`                 | нет          | Центральный слот, обычно `TopbarSearch`; нет: слот не рисуется.                            |
| `actions`      | `ReactNode`                 | нет          | Правый слот: `TopbarAction`, `TopbarProfile`.                                              |
| `searchHotkey` | `"topbar" \| "global" \| false` | `"topbar"`   | Ctrl/Cmd+K переводит фокус в поле поиска: при фокусе в шапке, на всей странице или никак. |

`TopbarSearch` (атрибуты `<input>`, `ref` на поле): `loading` (спиннер, `aria-busy`), `shortcut` (`"Ctrl K"`, `false` убирает подсказку), `rootProps` (атрибуты рамки `<label>`). `TopbarAction` (атрибуты `<button>`): `label` (обязателен), `icon`, `badge` (число, больше 9 — «9+»; попадает в `aria-label`). `TopbarProfile` (атрибуты `<button>`): `avatar`, `menuAvatar`, `name`, `subtitle`, `items: TopbarMenuItem[]` (`label`, `icon`, `href`, `separatorBefore`, `onSelect`), `open` / `defaultOpen` / `onOpenChange`.

```tsx
<Topbar
  crumbs={[
    { label: "Грузы", href: "/cargo" },
    { label: "Морской импорт", href: "/cargo/sea" },
    { label: "MSKU4821907" },
  ]}
  search={<TopbarSearch placeholder="Поиск по грузам, клиентам, документам" />}
  actions={
    <>
      <TopbarAction label="Сменить тему" icon={<MoonIcon />} onClick={toggleTheme} />
      <TopbarAction label="Уведомления" icon={<BellIcon />} badge={3} />
      <TopbarProfile
        avatar={<Avatar name="Иван Петров" kind="you" />}
        name="Иван Петров"
        subtitle="Оформление · Владивосток"
        items={[
          { label: "Профиль", icon: <UserIcon /> },
          { label: "Выйти", icon: <LogoutIcon />, separatorBefore: true, onSelect: logout },
        ]}
      />
    </>
  }
/>
```

Доступность:

- `<header>`; крошки в `<nav aria-label>`, поиск в `role="search"`, поле подписано «Глобальный поиск» и `aria-keyshortcuts="Control+K Meta+K"`.
- Профиль: `aria-haspopup="menu"`, `aria-expanded`; Enter, Space и ↓ открывают меню и ставят фокус на первый пункт, стрелки/Home/End двигают, Escape закрывает и возвращает фокус, клик вне закрывает.
- Иконки-кнопки обязаны иметь `label`; значок и бейдж скрыты от скринридера, число читается в подписи («Уведомления, 3 новых»).

# Loader

Анимация бренда с подписью для ожидания области, карточки или всей страницы. Только готовые файлы из brand/animated, без своих анимаций.

Loader занимает место содержимого, пока оно грузится дольше пары секунд: «Загружаем грузы», «Сверяем документы». Он состоит из анимированного знака astronaut (loader.svg) и подписи. Для мелкой операции в кнопке — Spinner, для известного процента — Progress, для заглушки строк таблицы — Skeleton. Новые анимации не рисуем: любая нужна — добавляется в idea/skelet/brand/animated, а в словарь попадает ссылкой.

- **id:** `loader`
- **Группа:** Обратная связь (`feedback`)
- **CSS-префикс:** `ds-loader`
- **Origin хореографии:** mockup (2)

## Когда использовать / не использовать

### Использовать

- Подпись всегда, глаголом в настоящем времени: «Загружаем грузы».
- Для ожидания дольше 2 секунд; для короче — Skeleton или Spinner.
- Подключайте файлы из brand/animated как есть: <img src="/brand/animated/loader.svg">.
- Если блок уже есть на экране, используйте затемнение (busy), а не заменяйте его Loader.
- Дайте выход: через 10 секунд — Alert с «Повторить».

### Не использовать

- Рисовать свою анимацию или перекрашивать знак бренда.
- Показывать page-loader при каждом переходе между экранами.
- Вешать Loader на кнопку: там Spinner.
- Сочетать Loader и Skeleton в одном блоке.
- Лоадер без подписи: знак не объясняет, что происходит.

## Анатомия

1. **Контейнер** — Колонка по центру, отступы 36 × 16, gap 14, цвет текста --text-2. Роль status, aria-live polite.
2. **Знак** — loader.svg как <img alt="">: астронавт с мигающими искрами, цикл 1,4 с. Ширина 150 px (96 у компактного, 220 у страницы).
3. **Подпись** — 13 px: что происходит («Загружаем грузы»). Мягко дышит: прозрачность до 50 % за 1,6 с.
4. **Пояснение** (необязательная) — 12 px, --text-3: сколько ждать или где мы («Astronaut · Владивосток»).

## Варианты

- **Область** (`area`): Знак 150 px и подпись внутри блока, на месте содержимого. Когда: загружается таблица, карточка, раздел.
- **Компактный** (`compact`): Знак 96 px, без пояснения. Когда: небольшая панель, поповер, вкладка внутри Sheet.
- **Страница** (`page`): Знак 220 px на фоне страницы поверх всего окна; уходит через 0,25 с. Когда: первая загрузка рабочего пространства; не для переходов между разделами.
- **Карточка с затемнением** (`busy`): Содержимое остаётся, поверх — слой surface 72 % с blur 2 px и Spinner xl с подписью. Когда: блок обновляется, данные уже есть и их не нужно прятать.

## Состояния

### Применимые

- **Loading** (`loading`): Единственное состояние компонента: знак и подпись, пока данные не пришли.
- **Обновление** (`other`, `busy`): Содержимое видно, поверх затемнение и Spinner xl, у блока aria-busy.

### Не применимы (с причиной)

- **Hover** (`hover`): Не интерактивен.
- **Active** (`active`): Не интерактивен.
- **Focus** (`focus`): Не в порядке Tab. Затемнение не ловит фокус; содержимое под ним недоступно, пока aria-busy и слой на месте [TODO] проверить inert.
- **Disabled** (`disabled`): Нет. Недоступный блок затемняет слой busy.
- **Error** (`error`): Загрузка не удалась — Loader заменяют на Alert err или пустое состояние с «Повторить».
- **Empty** (`empty`): Загрузка закончилась пустым ответом — это пустое состояние блока, не Loader.

## Доступность

- **role=status, aria-live=polite** (`aria`): Контейнер объявляет подпись при появлении. Знак — alt="": он декоративен.
- **aria-busy** (`aria`): Блок, который обновляется, получает aria-busy="true" на время затемнения; когда данные пришли — атрибут снимается и в aria-live уходит итог («Данные обновлены»).
- **Фокус** (`focus`): Страничный лоадер перекрывает всё окно: фокус не должен оставаться под ним. Предложение [TODO]: inert на приложение, пока он виден; после закрытия фокус на заголовок страницы.
- **Подпись** (`contrast`): --text-2 на surface 8,2:1, пояснение --text-3 4,9:1. Во время «дыхания» прозрачность падает до 50 %, поэтому подпись при минимуме на длительное время не читаем: смысл читает скринридер, а вторую подпись не прячем.
- **prefers-reduced-motion** (`motion`): Дыхание подписи выключено. Анимация внутри SVG отключается самим файлом (в brand/animated у каждого svg есть @media (prefers-reduced-motion: reduce) { * { animation: none } }) — остаётся статичный знак.

## Хореография

### Загрузка страницы (`page`, origin: mockup)

- **Триггер:** открытие приложения, пока грузится рабочее пространство

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 200 | Слой на всё окно (z-index 1100, фон --page) проявляется с 0 до 1. | opacity | ease |
| 0 | 1400 | loader.svg играет свой цикл: астронавт качается, искры мигают. | svg animation | ease-in-out |
| 0 | 1600 | Подпись «дышит»: opacity 1 → 0,5 → 1. | opacity | ease-in-out |
| 2000 | 250 | Данные пришли: слой гаснет 1 → 0, затем удаляется из DOM. | opacity | ease |

- **Фокус:** Фокус в слой не входит. [TODO] приложение под ним получить inert, чтобы Tab не бродил по невидимому интерфейсу; после ухода слоя фокус на заголовок страницы.

- **Reduced motion:** Появление и уход мгновенные, подпись не дышит, знак статичный.

- **Соседи:** Слой перекрывает всё, включая шапку и боковое меню; Toast (z-index 1200) остаётся выше.

### Карточка с затемнением (`busy`, origin: mockup)

- **Триггер:** нажатие «Обновить»

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | У блока aria-busy; поверх появляется слой surface 72 % с blur 2 px, по центру Spinner xl акцентного цвета и подпись «Обновляем…». | — | — |
| 0 | 800 | Кольцо Spinner вращается: оборот за 0,8 с. | rotate | linear |
| 2000 | 0 | Слой удаляется, aria-busy снимается; через Toast: «Данные обновлены». | — | — |

- **Фокус:** Кнопка «Обновить» блокируется на время обновления, фокус остаётся на ней (disabled — заменить на aria-busy [TODO]).

- **Reduced motion:** Spinner крутится медленнее (3 с на оборот); слой появляется мгновенно.

- **Соседи:** Размер блока не меняется; соседние блоки живут как раньше.

## Примеры

### Область (`area`)

```tsx
<Loader label="Загружаем грузы" hint="Это займёт пару секунд" />
```

### Блок обновляется (`busy`)

```tsx
<Card aria-busy style={{ position: "relative" }}><BusyOverlay label="Обновляем…" /></Card>
```

## Как использовать

Импорт: в ките — `import { BusyOverlay, LOADER_SRC, Loader, MARK_SRC, PageLoader } from "@/ui"`, в приложении — `import { BusyOverlay, LOADER_SRC, Loader, MARK_SRC, PageLoader } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { Loader, BusyOverlay, PageLoader, LOADER_SRC, MARK_SRC } from "@/ui"`. Анимация только фирменная: `brand/animated/loader.svg` (`LOADER_SRC`), знак `logo-mark.svg` (`MARK_SRC`).

| Компонент и пропс | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `Loader.size` | `"sm" \| "md" \| "page"` | `"md"` | Размер анимации (96 / 150 / 220 px) |
| `Loader.label` | `string` | `"Загружаем"` | Подпись под анимацией (она же читается скринридером) |
| `Loader.hint` | `string` | нет | Вторая строка серым |
| `Loader.fill` | `boolean` | нет | Занять всю высоту родителя |
| `BusyOverlay.label` | `string` | `"Обновляем…"` | Полупрозрачная плёнка со спиннером поверх блока; родителю нужны `position: relative` и `aria-busy` |
| `PageLoader.open` | `boolean` | обязателен | Показать загрузчик страницы: появление 0,2 с, уход 0,25 с |
| `PageLoader.fixed` | `boolean` | нет | `position: fixed` на весь экран (иначе заполняет родителя) |
| `PageLoader.label` / `hint` | `string` | «Загружаем рабочее пространство» / нет | Тексты |

Корень каждого компонента — `div` с `role="status"`; атрибуты, `className`, `ref` пробрасываются.

```tsx
<Loader label="Загружаем грузы" hint="Это займёт пару секунд" />
<Card aria-busy style={{ position: "relative" }}>…<BusyOverlay /></Card>
<PageLoader open={!ready} fixed />
```

Доступность: закрытый `PageLoader` получает `inert` и `aria-hidden`, поэтому не ловит фокус. Анимацию бренда замораживает только браузер при `prefers-reduced-motion` (подпись перестаёт мигать).

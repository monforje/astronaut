# ScrollArea

Кастомная прокрутка: тонкая полоса, затухание краёв там, где есть что прокручивать, три направления.

Область с ограниченной высотой или шириной, содержимое которой прокручивается внутри себя: список грузов в панели, ряд чипов-фильтров, широкая таблица. Тонкая полоса не крадёт ширину, а мягкий край подсказывает, что за ним есть ещё. Полоса остаётся родной (scrollbar-width: thin): клавиатура, колесо и жесты работают как у браузера.

- **id:** `scroll-area`
- **Группа:** Навигация (`navigation`)
- **CSS-префикс:** `ds-scroll`
- **Origin хореографии:** mockup (3)

## Когда использовать / не использовать

### Использовать

- Ограничивайте высоту окна по месту (панель, карточка); внешняя страница остаётся страницей.
- Горизонтально прокручивайте только ряд чипов и широкие таблицы.
- overscroll-behavior: contain: достигнув края, прокрутка не передаётся странице.
- Давайте окну aria-label и tabindex=0, если внутри нет фокусируемых элементов.
- У таблицы шапку закрепляйте (sticky), у списка — нет.

### Не использовать

- Вложенные прокручиваемые области: палец и колесо застревают.
- Скрывать полосу у вертикального списка: пользователь не поймёт, что есть ещё.
- Рисовать свою полосу на div: теряются клавиатура, жесты и доступность.
- Затухание у шапки таблицы или заголовка: маска съест текст.
- Высота окна в 100vh без вычета шапки: двойная прокрутка.

## Анатомия

1. **Рамка** — Контейнер с радиусом 8 и кольцом 1px --divider, фон --surface. Держит радиус для всего, что внутри.
2. **Окно (viewport)** — Элемент с overflow и max-height (или max-width). tabindex=0 и role=region с aria-label, чтобы прокручиваться стрелками.
3. **Содержимое** — Ряды, чипы или таблица. Отступы задаёт содержимое, а не окно.
4. **Полоса** — Тонкая (thin), ползунок --border, при наведении --text-ph; дорожка прозрачная. У горизонтальной одиночной полосы нет совсем.
5. **Затухание края** — Маска-градиент 24 px сверху и снизу (28 px слева и справа). Появляется только со стороны, куда ещё можно прокрутить.

## Варианты

- **Вертикальная** (`vertical`): max-height по месту, полоса справа, затухание сверху и снизу. Когда: списки в панелях: расхождения, документы, участники.
- **Горизонтальная** (`horizontal`): Ряд чипов: полоса скрыта (scrollbar-width: none), затухание слева и справа 28 px. Когда: фильтры-чипы, вкладки в узкой панели. Пользователь тянет жестом или колесом с Shift.
- **В обе стороны** (`both`): Широкая таблица: обе полосы видны (потемнее при наведении), затухания нет: заголовок таблицы должен оставаться читаемым. Когда: таблицы шире экрана. Шапку таблицы закрепляют (sticky top).

## Состояния

### Применимые

- **Top (начало)** (`default`): Полоса светлая (--border), затухание только снизу.
- **Middle** (`other`, `mid`): Содержимое со всех сторон: затухание сверху и снизу.
- **End (конец)** (`other`, `end`): Нижнее затухание снято: последний ряд виден целиком.
- **Hover** (`hover`): Ползунок темнее (--text-ph). [TODO] макет красит только сам ползунок при наведении на него; здесь — при наведении на область, потому что браузеры не дают стилизовать ползунок.
- **Focus** (`focus`): Кольцо 2 px --focus внутри рамки (offset −2): область прокручивается стрелками, PageUp/PageDown, Home/End.
- **Empty / короткое содержимое** (`empty`): Нечего прокручивать: полосы и затухания нет. Пустое состояние рисует содержимое.

### Не применимы (с причиной)

- **Active** (`active`): Нет собственного нажатого вида: перетаскивание ползунка рисует браузер.
- **Disabled** (`disabled`): Нет: недоступное содержимое делают неактивным само, прокрутка остаётся.
- **Loading** (`loading`): Внутри показывают Skeleton или Spinner; прокрутка не блокируется. Дозагрузку («ещё 20») добавляют в конец ряда. [TODO] предложение.
- **Error** (`error`): Нет: ошибка загрузки — плашка внутри содержимого.

| --- | --- | --- |

| `--divider` | #e0e4e9 | Кольцо рамки |
| `--r-item` | 8 px | Радиус рамки |
| `scrollbar-width` | thin | Тонкая полоса |
| `--ds-scroll-ft / fb` | 0 → 24 px | Высота затухания сверху и снизу |
| `--ds-scroll-fl / fr` | 0 → 28 px | Ширина затухания слева и справа |
| `--dur-f` | 125 мс | Появление затухания (предложение, @property) |
| `max-height` | по месту, 150–220 px | Окно (--h в макете: 200 / 150) |

## Доступность

- **role=region + aria-label** (`aria`): Окно прокрутки получает название («Список грузов»): скринридер сообщает, что это область.
- **Стрелки, PageUp/PageDown, Home/End** (`key`): Родные: окно прокручивается, если оно в фокусе (tabindex=0). Своих горячих клавиш нет.
- **Shift + колесо** (`key`): Горизонтальная прокрутка колесом; ряд чипов также прокручивается Tab: фокус на чипе подтягивает его в область.
- **Кольцо** (`focus`): 2 px --focus внутри рамки (outline-offset −2): рамка с радиусом не обрезает кольцо.
- **Полоса** (`contrast`): Ползунок --border на --surface 1,7:1: для не несущей смысла полосы допустимо, при hover --text-ph темнее. Затухание не должно перекрывать текст, который нужно прочесть: отступы 24/28 px.
- **prefers-reduced-motion** (`motion`): Появление и исчезновение затухания (125 мс) отключается: край меняется сразу. Плавную прокрутку scroll-behavior не включаем вовсе.

## Хореография

### Затухание краёв при прокрутке (`fade`, origin: mockup)

- **Триггер:** пользователь прокручивает содержимое

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Окно в начале: верхнее затухание 0, нижнее 24 px — виден «хвост». | --ds-scroll-fb | — |
| 700 | 125 | Прокрутка > 2 px: верхнее затухание вырастает до 24 px. В макете значение меняется скачком; плавность через @property — [TODO] предложение. | --ds-scroll-ft | ease |
| 1700 | 125 | До конца < 2 px: нижнее затухание уходит в 0, последний ряд виден целиком. | --ds-scroll-fb | ease |
| 2700 | 125 | Возврат вверх: верхнее затухание снимается, нижнее возвращается. | --ds-scroll-ft, --ds-scroll-fb | ease |

- **Фокус:** Не меняется. Если фокус на самом окне, кольцо остаётся на месте.

- **Reduced motion:** Края меняются мгновенно, без 125 мс.

- **Соседи:** Затухание рисует маска на самом окне: рамка, соседние блоки и тени не затрагиваются.

### Наведение и фокус (`hover`, origin: mockup)

- **Триггер:** указатель над областью, затем Tab на окно

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Указатель над областью: ползунок темнеет до --text-ph. [TODO] в макете — только при наведении на сам ползунок. | scrollbar-color | — |
| 1200 | 0 | Tab: на окне кольцо фокуса 2 px (внутри рамки); стрелки прокручивают. | outline | — |
| 2300 | 0 | Уход фокуса и указателя: возврат к спокойному виду. | — | — |

- **Фокус:** Окно получает фокус как один элемент; внутри него Tab идёт по фокусируемым элементам содержимого.

- **Reduced motion:** Анимации нет.

- **Соседи:** Соседние блоки не реагируют.

### Горизонтальный ряд (`horizontal`, origin: mockup)

- **Триггер:** жест, колесо с Shift, Tab по чипам

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Ряд в начале: левое затухание 0, правое 28 px. | --ds-scroll-fr | — |
| 0 | 125 | После сдвига > 2 px левое затухание растёт до 28 px; у конца правое снимается. | --ds-scroll-fl, --ds-scroll-fr | ease |
| 0 | 0 | Полоса скрыта всегда: прокрутку подсказывает только затухание. | scrollbar-width | — |

- **Фокус:** Tab на скрытый чип подтягивает его в видимую часть, затухание пересчитывается.

- **Reduced motion:** Края меняются мгновенно.

- **Соседи:** Чипы не меняют размер; ряд не переносится, ширина по содержимому (max-content).

## Примеры

### Список в панели (`list`)

```tsx
<ScrollArea direction="vertical" maxHeight={200} aria-label="Список грузов">…</ScrollArea>
```

### Ряд фильтров (`chips`)

```tsx
<ScrollArea direction="horizontal"><ChipRow>…</ChipRow></ScrollArea>
```

## Как использовать

<!-- manual:start -->
Компонент: `ScrollArea`. Типы: `ScrollAreaProps`, `ScrollAreaDirection`, `ScrollAreaStart`.

```tsx
import { ScrollArea } from "@/ui";
```

Атрибуты, `ref`, `className`, `style` и `onScroll` попадают на само окно прокрутки (`role="region"`, `tabIndex=0`); `rootClassName` — на внешнюю рамку.

| Проп            | Тип                                   | По умолчанию | Описание                                                                                  |
| --------------- | ------------------------------------- | ------------ | ----------------------------------------------------------------------------------------- |
| `direction`     | `"vertical" \| "horizontal" \| "both"` | `"vertical"` | Куда прокручивается. У `horizontal` полосы нет, у остальных тонкая.                       |
| `maxHeight`     | `number \| string`                    | нет          | Предел высоты; у горизонтального окна не нужен.                                           |
| `initialScroll` | `"top" \| "middle" \| "end"`           | `"top"`      | Положение при монтировании (например, лента с конца).                                     |
| `rootClassName` | `string`                              | нет          | Класс внешней рамки.                                                                      |
| `aria-label`    | `string`                              | нет          | Название области; задайте обязательно.                                                    |

```tsx
<ScrollArea direction="vertical" maxHeight={200} aria-label="Список грузов">
  {rows}
</ScrollArea>

<ScrollArea direction="horizontal" aria-label="Фильтры">
  <ChipRow />
</ScrollArea>

<ScrollArea direction="both" maxHeight={240} aria-label="Таблица" initialScroll="end">
  <WideTable />
</ScrollArea>
```

Доступность:

- `role="region"` с названием и `tabIndex=0`: окно прокручивается стрелками, PageUp/PageDown, Home/End, когда оно в фокусе.
- Мягкие затухающие края включаются только там, где есть что прокручивать; `ResizeObserver` пересчитывает их при смене размеров. Полосу цвета границы усиливает наведение.
- `overscroll-behavior: contain` не даёт прокрутке уходить на страницу.

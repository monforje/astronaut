# Цвета

Нейтральный графит с teal-акцентом. Navy — только логотип и текст на teal и orange; orange — сигнал. Две темы: светлая и тёмная.

Компонент берёт цвет по роли (--text, --border, --primary), а не по HEX и не по бренду. Так тёмная тема получается заменой значений ролей, а не правкой компонентов. Новый оттенок получают через color-mix от существующих ролей.

- **id:** `colors`
- **Группа:** Основа (`base`)
- **CSS-префикс:** `ds-colors`
- **Origin хореографии:** mockup (2)
- **Страница основы:** да

## Когда использовать / не использовать

### Использовать

- Брать цвет ролью (--text, --primary), не HEX и не --teal напрямую.
- Текст на teal и orange — всегда navy.
- Одна главная кнопка (teal) на экране; orange — только сигнал.
- Состояние передавать тоном и словом вместе (Badge, Alert).
- Новый оттенок получать color-mix от ролей, добавляя роль в tokens.css.

### Не использовать

- Красить интерфейс navy: navy — это логотип и текст на цвете, не фон.
- Писать HEX в css компонента: тёмная тема сломается.
- Передавать смысл одним цветом, без текста или значка.
- Использовать --text-ph для текста, который нужно прочитать: это подсказка и disabled.
- Менять цвета бренда в словаре: они приходят симлинком из idea/skelet/brand.

## Анатомия

1. **Бренд** — Четыре цвета из idea/skelet/brand/design/tokens.css: navy #082f53, teal #00d4d0, orange #ff9455, off-white #fbf5eb. Источник правды, в словаре не копируется.
2. **Роли** — Имена по назначению: --page, --surface, --text, --border, --primary, --danger. Значения зависят от темы.
3. **Слои** — Прозрачный ink 4–12 % поверх любого фона: состояния hover и active (страница «Слои состояний»).

## Варианты

- **Поверхности** (`surfaces`): Фон страницы под карточками, сами карточки, приглушённые блоки, поле ввода и выбранный элемент.
- **Текст и линии** (`text`): Четыре ступени текста и три линии: границы контролов, разделители, граница выбранного.
- **Акцент** (`accent`): Teal — главное действие и выбор; orange — сигнал; navy — только текст на teal и orange. Ссылки и фокус — тёмный teal, читаемый на белом.
- **Смысл** (`semantic`): Опасность, информация и тексты статусов. Заливка тона — одна, текст тона — отдельная роль, чтобы читаться на подложке.

## Доступность

- **Текст** (`contrast`): --text на белом 16,5:1, --text-2 8,2:1, --text-3 4,9:1 (подписи 11–12 px на пределе), --text-ph 3,2:1 — только подсказки и disabled.
- **Тексты статусов** (`contrast`): На белом: ok 4,8:1, warn 5,0:1, err 5,5:1, info 6,7:1, ссылка 4,9:1. В тёмной теме на --surface от 7,6:1.
- **Navy на заливке** (`contrast`): Navy на teal 7,4:1, на orange 6,2:1. Белый на --danger #d03538 в светлой теме 4,9:1 (hover 5,6:1, active 6,5:1), в тёмной --on-danger на #ff6b6b 6,6:1: норма 4,5:1 выполнена без смесей в компонентах.
- **Линии** (`contrast`): --border на белом 1,6:1, --divider 1,3:1: это обрамление, не единственный носитель смысла. Кольцо фокуса --focus — 3,7:1 на белом.
- **Цвет не единственный носитель** (`note`): Статус всегда в паре со словом или значком; точка присутствия — с текстовой альтернативой.
- **prefers-color-scheme** (`motion`): Без сохранённого выбора тема берётся из системной.

color: var(--on-primary);   /* не navy HEX и не --text */

## Как использовать

<!-- manual:start -->
Страница-основа: компонента нет, значения лежат в CSS-переменных `src/styles/tokens.css` (светлая и тёмная тема). В стилях берите роль, а не HEX: `var(--surface)`, `var(--text)`, `var(--primary)`; заливка опасности — пара `--danger` и `--on-danger`.

```css
.card {
  background: var(--surface);
  color: var(--text);
  box-shadow: inset 0 0 0 1px var(--border);
}
```

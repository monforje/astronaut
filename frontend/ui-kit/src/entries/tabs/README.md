# Tabs

Вкладки: переключают представления одного экрана. Подчёркивание переезжает к выбранной вкладке, на вкладке может быть счётчик.

Вкладки делят один объект или один список на равноправные представления: «Все / С расхождениями / Ждут документов» над таблицей грузов, «Обзор / Обсуждение / История» в карточке расхождения. Выбранная вкладка заметна весом и подчёркиванием, а не цветом бренда: навигация держится на нейтральном графите. Вкладка не ведёт на другую страницу: для этого — крошки и сайдбар.

- **id:** `tabs`
- **Группа:** Навигация (`navigation`)
- **CSS-префикс:** `ds-tabs`
- **Origin хореографии:** mockup (1), proposal (2)

## Когда использовать / не использовать

### Использовать

- Равноправные представления одного объекта или списка; одно выбрано всегда.
- Подпись — одно-два слова; счётчик — когда число помогает выбрать («С расхождениями 8»).
- Первая вкладка выбрана по умолчанию; выбор запоминается в адресе (?tab=err) для ссылки и «Назад».
- Недоступную вкладку оставляйте на месте серой: так раздел не «пропадает» у коллег с другими правами.
- Подчёркивание — нейтральный графит; акцентный цвет отдан выбранной строке и кнопкам действия.

### Не использовать

- Вкладки для шагов процесса: порядок важен — это Stepper.
- Вкладки-ссылки на другие страницы: это сайдбар или крошки.
- Вложенные вкладки: второй ряд ломает иерархию — берите ToggleGroup или секции.
- Закрываемые вкладки в этом словаре: они не нужны ни одному экрану макета.
- Больше 8–9 вкладок: заменяйте фильтром или меню.

## Анатомия

1. **Список вкладок (tablist)** — Строка с линией-разделителем снизу (--divider), отступ 6 px по краям, зазор 2 px. Роль tablist и aria-label.
2. **Вкладка (tab)** — Кнопка высотой 44 px (36 у sm). Внутри подложка 4×8 px с радиусом 4: на ней рисуются hover, active и кольцо фокуса, а не на всей высоте кнопки. Подпись Onest 500, у выбранной 600.
3. **Счётчик** (необязательная) — Число в капсуле: 11 px, 600, --tone. У выбранной вкладки капсула teal-подложка с кольцом и текстом --link-strong.
4. **Подчёркивание (ink)** — Полоса 2 px --text под выбранной вкладкой, ширина по подложке (без отступов по краям линии). Одна на весь список, переезжает.
5. **Панель (tabpanel)** (необязательная) — Содержимое вкладки; связана с вкладкой через aria-controls и aria-labelledby. В макете панели свои у каждого экрана; здесь показана одна.

## Варианты

- **С подчёркиванием** (`line`): Основной вид: подпись, бегущая линия, линия-разделитель под списком. Когда: представления одного объекта: «Обзор / Обсуждение / История».
- **Со счётчиками** (`counts`): Счётчик показывает, сколько объектов в представлении. Недоступная вкладка («Архив») без счётчика и серая. Когда: фильтры над таблицей: сколько грузов в каждом срезе.
- **Много вкладок** (`overflow`): Не помещаются: список прокручивается по горизонтали, правый край затухает; полоса прокрутки скрыта. Выбранную вкладку прокручивают в зону видимости. ## Состояния

### Применимые

- **Default** (`default`): Подпись --text-2, 500. Без подложки.
- **Hover** (`hover`): Подложка 4×8 слоем 6 % (--layer-2), текст --text.
- **Active** (`active`): Слой 12 % (--layer-3) на подложке, пока кнопка нажата.
- **Focus** (`focus`): Кольцо 2 px --focus по подложке (не по всей высоте). Только с клавиатуры.
- **Selected** (`selected`): aria-selected=true: текст --text, 600, под вкладкой подчёркивание, счётчик с teal-подложкой.
- **Disabled** (`disabled`): Текст --text-ph, без hover, из порядка Tab выпадает. Пример: «Архив» без прав.
- **Loading** (`loading`): Счётчик ещё считается: капсула-заглушка пульсирует (1,1 с). Сама вкладка активна. [TODO] предложение.
- **Error** (`error`): Красная точка после подписи: во вкладке нужно что-то исправить. [TODO] предложение.
- **Empty** (`empty`): Срез пуст: счётчик «0» бледнее (--text-3), вкладка остаётся. Панель показывает пустое состояние, вкладку не скрывают.

### Не применимы (с причиной)

- **Toggle / pressed** (`other`, `pressed`): Вкладка не «нажата и удержана»: это selected.

## Доступность

- **tablist / tab / tabpanel** (`aria`): Контейнер role=tablist с aria-label; каждая вкладка role=tab, aria-selected, aria-controls на панель; панель role=tabpanel с aria-labelledby на вкладку. Связи панелей ставит сам компонент (id и aria-controls/aria-labelledby от useId).
- **← / →** (`key`): Двигают фокус на соседнюю доступную вкладку по кругу и сразу выбирают её (автоматическая активация, панели лёгкие). Roving tabindex: в Tab входит только выбранная вкладка. [TODO] предложение: макет стрелок не умеет.
- **Home / End** (`key`): Первая и последняя доступная вкладка. Disabled пропускаются.
- **Tab** (`key`): Из списка фокус идёт в панель (у панели tabindex=0, если в ней нет своих фокусируемых элементов).
- **Кольцо** (`focus`): 2 px --focus по подложке 4×8; контраст --focus (#00968f) на белом 3,6:1, в тёмной teal на графите выше 7:1.
- **Текст вкладок** (`contrast`): Обычная --text-2 на --surface 8,2:1 (светлая); --text-ph у disabled около 3:1 — это допустимо для недоступного, но не для читаемого. Счётчик выбранной: --link-strong на teal 15 % ≈ 6:1.
- **prefers-reduced-motion** (`motion`): Подчёркивание встаёт на место мгновенно, переход подложки hover отключается.
- **Счётчик** (`note`): Читается вместе с подписью («С расхождениями, 8»). Если число критично, добавляйте скрытое «грузов» (aria-label на вкладке).

## Хореография

### Переключение вкладки (`switch`, origin: mockup)

- **Триггер:** клик (или Enter/Space, стрелка) по вкладке

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: подложка вкладки заливается слоем hover. | background | ease |
| 400 | 0 | Нажатие: слой active (12 %). | background | — |
| 550 | 0 | Выбор: aria-selected переходит на новую вкладку, у прежней вес 600→500 и цвет --text-2, у новой наоборот. | font-weight, color | — |
| 550 | 200 | Подчёркивание едет: сдвиг по X и смена ширины идут одновременно к подложке новой вкладки. | translate, width | --ease |
| 550 | 0 | Содержимое панели меняется сразу, без перехода. [TODO] макет не анимирует панель; затухание панели 125 мс — только предложение. | — | — |

- **Фокус:** Остаётся на нажатой вкладке (при клике мышью) или переезжает на новую (стрелки). В панель не уходит.

- **Reduced motion:** Подчёркивание появляется под новой вкладкой мгновенно.

- **Соседи:** Соседние вкладки не сдвигаются: подпись держит ширину жирного начертания (пустой ::after в 600), поэтому смена веса не толкает остальные. В макете ширина прыгает на 2–4 px: [TODO] подтвердить решение.

### Стрелки, Home и End (`keyboard`, origin: proposal)

- **Триггер:** → ← Home End при фокусе на вкладке

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Фокус и выбор переходят на следующую доступную вкладку; disabled пропускается. | tabindex, aria-selected | — |
| 0 | 200 | Подчёркивание едет тем же движением, что при клике. | translate, width | --ease |
| 700 | 0 | Дальше — следующий шаг; за последней вкладкой фокус возвращается к первой. | — | — |

- **Фокус:** Roving tabindex: tabindex=0 только у выбранной, у остальных −1; кольцо фокуса на подложке выбранной.

- **Reduced motion:** Как в «Переключении»: линия без движения.

- **Соседи:** Панель сменяется сразу; прокрутка страницы не двигается (preventDefault у стрелок).

### Первая отрисовка и смена ширины (`first-paint`, origin: proposal)

- **Триггер:** вкладки появились на экране или контейнер изменил ширину

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Подчёркивание рассчитывается по выбранной вкладке без перехода (transition включается после первого кадра). | translate, width | — |
| 16 | 0 | Флаг готовности: дальше любые смены идут с переходом 200 мс. | transition | — |
| 16 | 0 | ResizeObserver пересчитывает положение при смене ширины: линия не отстаёт от вкладки. | translate | — |

- **Фокус:** Не затрагивается.

- **Reduced motion:** Переходов нет в любом случае.

- **Соседи:** В макете положение считается при смене страницы (requestAnimationFrame); без этого линия при первом показе выезжала бы из нуля. [TODO] в макете нет пересчёта при resize.

## Примеры

### Фильтр над таблицей грузов (`cargo`)

```tsx
<Tabs value={tab} onValueChange={setTab}>
  <TabList aria-label="Фильтр грузов">
    <Tab value="all" count={128}>Все</Tab>
    <Tab value="err" count={8}>С расхождениями</Tab>
    <Tab value="archive" disabled>Архив</Tab>
  </TabList>
</Tabs>
```

### Представления карточки (`card`)

```tsx
<Tabs defaultValue="ov">
  <TabList aria-label="Представления">
    <Tab value="ov">Обзор</Tab>
    <Tab value="chat" count={8}>Обсуждение</Tab>
  </TabList>
  <TabPanel value="ov">…</TabPanel>
  <TabPanel value="chat">…</TabPanel>
</Tabs>
```

## Как использовать

<!-- manual:start -->
Компоненты: `Tabs`, `TabList`, `Tab`, `TabPanel`. Типы: `TabsProps`, `TabsSize`, `TabListProps`, `TabProps`, `TabPanelProps`.

```tsx
import { Tab, TabList, TabPanel, Tabs } from "@/ui";
```

`Tabs` (плюс атрибуты `<div>`):

| Проп            | Тип                       | По умолчанию | Описание                                                                      |
| --------------- | ------------------------- | ------------ | ----------------------------------------------------------------------------- |
| `value`         | `string`                  | нет          | Выбранная вкладка (управляемый режим).                                        |
| `defaultValue`  | `string`                  | первая доступная | Начальная вкладка (неуправляемый режим).                                  |
| `onValueChange` | `(value: string) => void` | нет          | Вызывается при смене вкладки кликом или стрелками (не при повторном выборе). |
| `size`          | `"md" \| "sm"`            | `"md"`       | Высота вкладки 44 или 36 px.                                                  |

`TabList` (атрибуты `<div>`, `ref` на список): `scroll` — затухание правого края для длинного ряда; `aria-label` задаёт название списка. `Tab` (атрибуты `<button>`): `value` (обязателен), `count` (число или `"loading"`), `error` (красная точка), `disabled`. `TabPanel` (атрибуты `<div>`): `value`; содержимое рисуется только у выбранной панели, остальные остаются в разметке пустыми и скрытыми.

```tsx
<Tabs value={tab} onValueChange={setTab}>
  <TabList aria-label="Фильтр грузов">
    <Tab value="all" count={128}>Все</Tab>
    <Tab value="err" count={8}>С расхождениями</Tab>
    <Tab value="archive" disabled>Архив</Tab>
  </TabList>
  <TabPanel value="all">…</TabPanel>
  <TabPanel value="err">…</TabPanel>
</Tabs>

<Tabs defaultValue="ov" size="sm">
  <TabList aria-label="Представления">
    <Tab value="ov">Обзор</Tab>
    <Tab value="chat" count="loading">Обсуждение</Tab>
  </TabList>
</Tabs>
```

Доступность:

- `role="tablist"` / `tab` / `tabpanel`; связи `aria-controls` и `aria-labelledby` ставятся сами (`useId`). Дайте `TabList` `aria-label`.
- Roving tabindex: в Tab входит только выбранная вкладка. Стрелки влево и вправо по кругу, Home и End переносят фокус и сразу выбирают вкладку (автоматическая активация); `disabled` пропускаются.
- Подчёркивание считается по выбранной вкладке без перехода при первом показе, дальше ездит 200 мс; `ResizeObserver` держит его при смене ширины.
- Счётчик читается вместе с подписью; для критичных чисел добавьте `aria-label` на `Tab`.

# Select

Выбор одного значения из списка: кнопка-поле или компактный контрол и всплывающий список, при длинном списке с поиском.

Select показывает текущее значение закрытой кнопкой и по клику раскрывает список под ней: заголовок, необязательный поиск, пункты со значками и пояснениями. Нужен, когда вариантов больше пяти или на экране нет места; для 2-5 вариантов лучше Radio или ToggleGroup, для команд Dropdown (меню).

- **id:** `select`
- **Группа:** Поля (`fields`)
- **CSS-префикс:** `ds-select`
- **Origin хореографии:** mockup (5)

## Когда использовать / не использовать

### Использовать

- Список от шести пунктов; от восьми добавляйте поиск.
- Заголовок списка повторяет подпись поля: «Клиент», «Статус».
- Пояснение под названием — когда пункты похожи («Сверено»: документы совпадают).
- Недоступный пункт оставляйте в списке с причиной, а не прячьте.
- Placeholder называет действие: «Выберите клиента».
- Контрол — в тулбарах и заголовках, поле — в формах.

### Не использовать

- Select для двух-пяти вариантов: Radio или ToggleGroup быстрее.
- Select для команд («Копировать», «Удалить»): это Dropdown (меню).
- Поиск в списке из трёх пунктов.
- Длинные названия без пояснения: кнопка обрежет текст многоточием.
- Несколько открытых списков сразу: открытие второго закрывает первый.
- Мультивыбор в одном Select: нужны Checkbox или меню с флажками.

## Анатомия

1. **Поле со списком** — Кнопка и всплывающий список вместе. Кнопка 32 px (контрол 28), список от её левого края на 4 px ниже; flip вверх, если внизу нет места.
2. **Кнопка (trigger)** — Значение или placeholder слева, стрелка 14 px справа; рамка 1px, радиус 8. aria-haspopup=listbox, aria-expanded. При открытии стрелка поворачивается на 180°.
3. **Заголовок списка** (необязательная) — 11 px --text-3: имя поля («Клиент», «Статус»). Необязателен.
4. **Поиск** (необязательная) — Строка с лупой над пунктами, нижняя линия --divider. Есть, когда пунктов больше семи-восьми. Подсвечивает совпадение <mark>.
5. **Пункты** — Строки padding 5 8, радиус 8. Значок 14 слева, пояснение 11 px под названием, галочка справа у выбранного. Список прокручивается после 240 px.
6. **Состояния пункта** — Выбран: подложка --selected, 600, галочка; активный (курсор или стрелки): слой --layer-1; недоступный: --text-ph. В клавиатурном режиме активный получает кольцо 2px.

## Варианты

- **Поле** (`field`): Кнопка на ширину формы со значением и стрелкой. Список без поиска. Когда: короткий список до 7 пунктов: сортировка, тип, клиент из шести.
- **С поиском** (`search`): Над пунктами строка поиска, фокус сразу в ней. Фильтр по вхождению без учёта регистра, совпадение подсвечено. Когда: длинный справочник: клиенты, порты, коды ТН ВЭД.
- **Значок и пояснение** (`rich`): У пункта значок и строка пояснения; недоступный пункт виден, но не выбирается. Выбранное значение в кнопке тоже со значком. Когда: статусы, роли, тарифы: где одного названия мало.
- **Контрол** (`control`): Компактная кнопка без рамки, 28 px: «Сортировка: Новые сверху». На hover и открытом слой --layer-2. Когда: тулбар, заголовок таблицы, график: когда рамка поля шумела бы.

## Состояния

### Применимые

- **Закрыт, значение выбрано** (`default`): Рамка --border, фон --field, значение 13 px слева, стрелка --text-3 справа.
- **Пусто (placeholder)** (`empty`): Значения нет: подсказка «Выберите клиента» цветом --text-ph. Поле остаётся обычным, без ошибки.
- **Hover** (`hover`): Рамка темнеет до --text-3.
- **Focus** (`focus`): Кольцо outline 2px --focus вплотную, только от клавиатуры (Tab).
- **Открыт** (`selected`, `open`): aria-expanded=true: рамка --focus и ореол 3px --selected, стрелка повёрнута на 180°. Список под кнопкой.
- **Ошибка** (`error`): data-invalid: рамка --danger; под полем текст --err-text. В открытом виде ореол красный (danger 22 %).
- **Disabled** (`disabled`): Фон прозрачный, рамка --divider, текст --text-ph; не открывается и не получает фокус.
- **Ничего не нашлось** (`empty`, `no-results`): В списке с поиском нет совпадений: строка «Ничего не нашлось» вместо пунктов, поиск остаётся.

### Не применимы (с причиной)

- **Active** (`active`): У поля отдельного вида нет: клик сразу открывает список. У контрола-кнопки в тулбаре — слой --layer-3.
- **Loading** (`loading`): Нет в макете: список берётся из готового массива. [TODO] для вариантов с сервера: строка Skeleton или Spinner внутри списка и aria-busy на listbox; поле остаётся доступным.

## Доступность

- **Кнопка** (`aria`): aria-haspopup="listbox", aria-expanded, aria-controls на список; имя из видимой подписи (aria-labelledby). Значение — часть имени кнопки.
- **Список и пункты** (`aria`): role="listbox" и role="option" с aria-selected; недоступные — aria-disabled="true". Активный пункт задаётся aria-activedescendant на элементе в фокусе (поиск или listbox).
- **Поиск** (`aria`): Поле поиска — role="combobox" с aria-controls, aria-activedescendant и aria-autocomplete="list". Пустой результат объявляется role="status".
- **Enter / Space** (`key`): На кнопке открывают список. В списке Enter выбирает активный пункт.
- **↑ ↓** (`key`): Двигают активный пункт по кругу; после первой стрелки включается кольцо. В поиске двигают только по найденным.
- **Esc** (`key`): Закрывает список и возвращает фокус на кнопку.
- **Tab / Home / End** (`key`): [TODO] предложение: Tab закрывает список и идёт дальше; Home и End — первый и последний пункт. В макете не реализовано.
- **Фокус** (`focus`): Кнопка: outline 2px --focus (3,65:1 на белом, 9,3:1 в тёмной). Открытая: рамка --focus и ореол. Активный пункт в клавиатурном режиме — кольцо 2px внутри пункта.
- **Рамка и текст** (`contrast`): Рамка --border на белом 1,6:1: ниже 3:1 для границ компонентов; hover --text-3 4,9:1. Пункт --text-2 на белом 8,2:1, выбранный --text на --selected 14,8:1, пояснение --text-3 4,9:1. Placeholder --text-ph 3,2:1 в светлой. [TODO] усилить рамку и placeholder.
- **prefers-reduced-motion** (`motion`): Отключаются появление списка (масштаб, прозрачность, сдвиг), поворот стрелки и переходы цвета.

## Хореография

### Открытие, наведение, выбор мышью (`open-pick`, origin: mockup)

- **Триггер:** клик по кнопке Select, затем клик по пункту

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Hover на кнопке: рамка --border → --text-3. | border-color | ease |
| 600 | 125 | Клик: рамка идёт к --focus, вокруг ореол 3px --selected. | border-color, box-shadow | ease |
| 600 | 200 | Стрелка поворачивается на 180°. | transform: rotate | var(--ease) = cubic-bezier(.6,0,.05,.95) |
| 600 | 125 | Список появляется под кнопкой: прозрачность 0 → 1, масштаб 0,96 → 1, сдвиг вверх на 4px → 0. Активный пункт — выбранный (или первый). | opacity, scale, translate | var(--ease) |
| 1200 | 125 | Наведение на пункт: слой --layer-1 (--layer-1p при нажатии); активный пункт переходит под курсор, кольцо клавиатурного режима гаснет. | background | ease |
| 2000 | 0 | Клик по пункту: значение в кнопке меняется, список закрывается сразу, без анимации. | — | — |
| 2000 | 200 | Стрелка возвращается; рамка и ореол уходят. Фокус на кнопке. | transform, border-color, box-shadow | var(--ease) / ease |

- **Фокус:** При открытии фокус уходит в список: в поле поиска, если оно есть, иначе на сам listbox. При выборе фокус возвращается на кнопку.

- **Reduced motion:** Появление списка (масштаб, прозрачность, сдвиг) и поворот стрелки отключены: список возникает сразу.

- **Соседи:** Список лежит поверх страницы (position: fixed, z-index 900) и ничего не сдвигает. Если внизу не хватает места, он открывается вверх; кнопка и список ограничены экраном с отступом 8px. Любая прокрутка страницы и изменение размера окна закрывают список.

### Клавиатура: стрелки, Enter, Esc (`keyboard`, origin: mockup)

- **Триггер:** Tab до кнопки, затем Enter или Space

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Фокус на кнопке: кольцо 2px --focus (outline). | outline | — |
| 600 | 125 | Enter или Space открывают список; активен выбранный пункт; кольца у пункта пока нет. | opacity, scale, translate | var(--ease) |
| 1400 | 125 | ↓: активный пункт на следующий; появляется кольцо 2px --focus внутри пункта (outline-offset −2px); список прокручивается к нему. | background, outline | ease |
| 2000 | 0 | ↓ на последнем пункте замыкается на первый; ↑ на первом уходит на последний. | — | — |
| 3300 | 0 | Enter выбирает активный пункт и закрывает список; Esc закрывает без выбора. Фокус возвращается на кнопку. | focus | — |

- **Фокус:** В списке без поиска фокус на listbox, активный пункт задаётся aria-activedescendant. Мышь возвращает «мышиный режим»: кольцо у активного пункта исчезает. [TODO] в макете недоступный пункт можно активировать стрелкой (Enter на нём ничего не делает); предложение: пропускать его.

- **Reduced motion:** Список возникает без анимации, прокрутка к активному пункту — мгновенная.

- **Соседи:** Стрелки не прокручивают страницу (preventDefault). Tab в макете список не закрывает: [TODO] предложение — Tab закрывает список и уходит к следующему полю; Home и End — первый и последний пункт.

### Поиск с фильтрацией (`search`, origin: mockup)

- **Триггер:** ввод букв в поле поиска над списком

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Открытие: фокус сразу в поле поиска, лупа --text-3 → --link в фокусе. | color | ease |
| 800 | 0 | Каждая буква: список перерисовывается мгновенно, остаются пункты, где есть вхождение без учёта регистра. | список | — |
| 800 | 0 | Совпадение подсвечивается <mark> (--highlight: orange 45 % на --surface, радиус 2). | background | — |
| 800 | 0 | Активным становится первый найденный пункт (act = 0); ↑ ↓ идут только по найденным. | — | — |
| 2600 | 0 | Enter выбирает активный пункт, список закрывается, поиск очищается при следующем открытии. | — | — |

- **Фокус:** Фокус остаётся в поле поиска всё время: стрелки двигают aria-activedescendant, а не фокус. Выбранный ранее пункт остаётся помечен галочкой, даже если его скрыл фильтр.

- **Reduced motion:** Анимации у фильтрации нет; список и подсветка обновляются мгновенно.

- **Соседи:** Высота списка меняется по числу найденных (до 240 px), кнопка и страница не сдвигаются: список поверх. Если пунктов не осталось, показывается «Ничего не нашлось».

### Пустой результат (`empty`, origin: mockup)

- **Триггер:** в поиск введено то, чего нет в списке

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Пункты исчезают, на их месте строка «Ничего не нашлось» (12 px --text-3, padding 10 8). Поиск остаётся над ней. | список | — |
| 1300 | 0 | Стёрли часть текста: совпадения вернулись, пункты снова в списке. | список | — |

- **Фокус:** В поле поиска; Enter при пустом результате ничего не делает.

- **Reduced motion:** Без анимации.

- **Соседи:** Список сжимается до заголовка, поиска и одной строки; под ним ничего не двигается. [TODO] «Ничего не нашлось» стоит объявлять через role=status (сделано в демо).

### Закрытие без выбора: Esc и клик вне списка (`close`, origin: mockup)

- **Триггер:** Esc или клик мимо списка

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Список снимается сразу, без анимации: обратного хода у появления нет. | — | — |
| 0 | 200 | Стрелка возвращается на 0°, рамка и ореол уходят. | transform, border-color, box-shadow | var(--ease) / ease |
| 0 | 0 | Esc возвращает фокус на кнопку; клик мимо — нет (фокус там, куда кликнули). | focus | — |

- **Фокус:** Esc: фокус на кнопку (кольцо видно). Клик вне: фокус у того элемента, по которому кликнули; повторный клик по кнопке открытого Select закрывает его (а не переоткрывает).

- **Reduced motion:** Поворот стрелки отключён, остальное и так мгновенно.

- **Соседи:** Значение не меняется. Другой открытый Select или меню закрывается при открытии этого: одновременно открыт один список.

## Примеры

### Клиент с поиском (`client`)

```tsx
const clients = [
  { value: "ООО «Дальснаб»", label: "ООО «Дальснаб»" },
  { value: "ИП Кравец", label: "ИП Кравец" },
  { value: "ООО «Порт-Трейд»", label: "ООО «Порт-Трейд»" },
];

<Select
  label="Клиент"
  title="Клиент"
  searchable
  value={client}
  onValueChange={setClient}
  options={clients}
  placeholder="Выберите клиента"
/>
```

### Сортировка в заголовке таблицы (`sort`)

```tsx
const sorts = [
  { value: "n", label: "Новые сверху" },
  { value: "o", label: "Старые сверху" },
  { value: "w", label: "По весу" },
];

<Select
  variant="control"
  controlLabel="Сортировка"
  value={sort}
  onValueChange={setSort}
  options={sorts}
/>
```

## Как использовать

Импорт: в ките — `import { Select } from "@/ui"`, в приложении — `import { Select } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компонент `Select` (кнопка `aria-haspopup="listbox"` и список под ней). Типы: `SelectProps`, `SelectOption`, `SelectVariant`, `SelectOpenReason`.

```tsx
import { Select } from "@/ui";
```

Пропсы (плюс атрибуты `<button>`: `disabled`, `aria-*`, `data-*`, `className`, `ref` — всё попадает на кнопку):

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `options` | `SelectOption[]` | — | `{ value, label, icon?, hint?, disabled? }`; `icon` — `ReactNode`. |
| `value` / `defaultValue` | `string` | `""` | Управляемое и начальное значение. |
| `onValueChange` | `(value: string) => void` | нет | Вызывается при выборе другого значения. |
| `open` / `defaultOpen` | `boolean` | `false` | Управляемое и начальное состояние списка. |
| `onOpenChange` | `(open, reason) => void` | нет | `reason`: `trigger`, `key`, `select`, `escape`, `tab`, `dismiss` (клик мимо, прокрутка, размер окна, открытие другого списка). |
| `variant` | `"field" \| "control"` | `"field"` | Поле на ширину формы или компактная кнопка «Сортировка: По весу». |
| `label` | `string` | нет | Видимая подпись; имя кнопки = подпись + значение. |
| `controlLabel` | `string` | нет | Префикс внутри кнопки `control`. |
| `title` | `string` | нет | Заголовок списка (он же имя `listbox`). |
| `placeholder` | `string` | `"Выберите"` | Текст при пустом значении. |
| `searchable` | `boolean` | нет | Поле поиска над списком с фильтром и подсветкой. |
| `searchPlaceholder` / `emptyText` | `string` | `"Поиск"` / `"Ничего не нашлось"` | Тексты поиска. |
| `invalid` / `error` | `boolean` / `string` | нет | Красная рамка; `error` рисует текст под полем (`aria-describedby`). |
| `name` | `string` | нет | Добавляет скрытое поле формы со значением. |
| `fieldClassName` | `string` | нет | Класс внешней обёртки. |

```tsx
<Select label="Клиент" searchable value={client} onValueChange={setClient}
  options={clients} placeholder="Выберите клиента" />

<Select variant="control" controlLabel="Сортировка" value={sort} onValueChange={setSort}
  options={[{ value: "n", label: "Новые сверху" }, { value: "w", label: "По весу" }]} />

<Select label="Статус" error="Выберите статус" options={statuses} />
```

Поведение и доступность:

- Enter, Space или клик открывают список; ↓ и ↑ на закрытой кнопке тоже открывают. Фокус уходит в поле поиска (или на `listbox`), активный пункт — выбранный; без поиска фокус остаётся на `listbox`.
- ↓ ↑ двигают активный пункт по кругу, пропуская недоступные; Home и End — первый и последний (без поиска); Enter выбирает; Esc закрывает и возвращает фокус на кнопку; Tab закрывает и идёт дальше. Активный пункт указывает `aria-activedescendant`, кольцо у него только в клавиатурном режиме.
- Поиск — `role="combobox"` с `aria-autocomplete="list"`; пустой результат объявляется через `role="status"`.
- Список открывается вверх, если снизу нет места, и прижимается к правому краю при нехватке ширины; клик мимо, прокрутка страницы и изменение размера окна закрывают его. Одновременно открыт один список или меню.
- Список позиционируется абсолютно внутри обёртки поля и обрезается предком с `overflow: hidden`.
- Появление списка и поворот стрелки отключаются при `prefers-reduced-motion`.

# Sheet

Боковая панель от правого края с крестом. Три режима: panel 430, wide 760, на весь экран. Для карточек, длинных форм и панели агента.

Sheet показывает объект или процесс рядом со страницей, не уводя с неё: карточку груза, длинную форму, переписку с агентом. В отличие от Dialog он не требует мгновенного решения: его можно развернуть, прочитать, закрыть крестом или Esc. Короткий вопрос — Dialog, пояснение у элемента — Popover.

- **id:** `sheet`
- **Группа:** Окна и панели (`overlays`)
- **CSS-префикс:** `ds-sheet`
- **Origin хореографии:** mockup (3), proposal (1)

## Когда использовать / не использовать

### Использовать

- Крест всегда в шапке; он дублируется Esc и кликом по затемнению.
- Режим выбирайте по содержимому: panel для карточки, wide для таблицы, full для работы без контекста.
- Правка внутри панели — подвал с «Отмена» слева и «Сохранить» справа.
- Запоминайте режим для агента (panel/wide/full) между открытиями [TODO].
- Один Sheet на экран; открытие нового заменяет прежний.

### Не использовать

- Решение «да/нет» в Sheet: для него Dialog.
- Форма короче четырёх полей: хватит Popover или Dialog.
- Креста без Esc: оба способа закрытия обязательны.
- Вкладывать Sheet в Sheet.
- Закрывать панель при ошибке сохранения: данные останутся нетронутыми, пока пользователь не решит.

## Анатомия

1. **Затемнение** — Слой --overlay на весь экран, z-index 800; клик по нему закрывает панель. В режиме full прозрачность 0, клики не ловит.
2. **Панель** — От края до края по высоте, без скруглений, фон --surface, тень --shadow-dialog и линия слева; ширина 430 / 760 / 100 %, не шире экрана − 32 (кроме full).
3. **Шапка** — Заголовок 18 px, 700, описание --text-2 под ним, справа «развернуть» и «закрыть» (ghost, квадратные md). Отступы 14 16 14 24, линия снизу.
4. **Крест** — Всегда есть; Esc и клик по затемнению дублируют его.
5. **Середина** — Прокручивается, отступы 24, интервал 16. В full содержимое центрируется колонкой до 820 px.
6. **Подвал** (необязательная) — Две кнопки 50/50: «Отмена» слева, «Сохранить» справа. Нужен, если в панели есть правка.

## Варианты

- **panel · 430** (`panel`): Узкая панель справа: карточка объекта, короткая форма. Страница остаётся видна и затемнена. Когда: по умолчанию.
- **wide · 760** (`wide`): Широкая панель: таблица внутри карточки, длинная переписка. Когда: нужна ширина, но контекст страницы всё ещё важен.
- **full · весь экран** (`full`): Панель занимает окно целиком; затемнения нет; содержимое колонкой до 820 px по центру. Когда: работа без отвлечения: агент в режиме чата, объёмная форма.
- **Живая панель** (`live`): Откройте, раскройте до full, закройте крестом, Esc или кликом по затемнению. Tab ходит по кругу внутри панели. Когда: проверить режимы и клавиатуру.

## Состояния

### Применимые

- **Default** (`default`): Панель открыта, фокус в первом поле формы.
- **Hover кнопок шапки** (`hover`): Слой 9 % на «развернуть» и «закрыть»; сама панель от hover не меняется.
- **Active** (`active`): Слой 12 % при нажатии.
- **Focus** (`focus`): Кольцо 2 px --focus на кнопке; Tab ходит по кругу внутри панели.
- **Disabled «Сохранить»** (`disabled`): Нечего сохранять или форма невалидна: кнопка отключена своими цветами. [TODO] в макете «Сохранить» всегда доступна; предложено словарём.
- **Loading** (`loading`): Сохранение: «Сохранить» с Spinner (aria-busy), «Отмена» отключена; панель остаётся. [TODO] предложено словарём.
- **Error** (`error`): Alert err вверху содержимого: «Не удалось сохранить», данные формы остаются. [TODO] предложено словарём.
- **Empty** (`empty`): Нечего показать (например, переписки нет): в середине пустое состояние с одним действием. [TODO] словарь предлагает, в макете пустой карточки нет.

## Доступность

- **role=dialog, aria-modal, aria-labelledby** (`aria`): Панель — <aside role="dialog" aria-modal="true" aria-labelledby=… tabindex="-1">. Название — заголовок шапки. В макете aria-label фиксированный («Карточка», «Агент»).
- **Фокус-ловушка** (`focus`): [TODO] в макете ловушки нет, хотя aria-modal=true. Предложение: Tab и Shift+Tab ходят по кругу внутри панели, страница под ней — inert. Исключение: язычок агента на левой кромке панели (см. AgentTab).
- **Куда идёт фокус при открытии** (`focus`): В первое поле формы (в макете — первый textarea) или в заголовок панели с tabindex=-1, если полей нет.
- **Куда возвращается при закрытии** (`focus`): На элемент, открывший панель; в момент начала закрытия.
- **Esc** (`key`): Закрывает панель, если сверху нет Dialog и поповера (Esc принадлежит верхнему слою). Крест и кнопка «Отмена» делают то же.
- **Кнопка «развернуть»** (`aria`): aria-label меняется по шагу: «Расширить» → «На весь экран» → «Свернуть в панель»; иконка aria-hidden. Новый размер объявлять не нужно.
- **Контраст** (`contrast`): Заголовок --text на surface 16,5:1, описание --text-2 8,2:1 (тёмная 16,4:1 и 11,3:1). Затемнение 45 % на белом: 3,0:1 между панелью и страницей.
- **prefers-reduced-motion** (`motion`): Выезд, смена ширины и затемнение — мгновенно.

## Хореография

### Открытие (`open`, origin: mockup)

- **Триггер:** нажатие на кнопку, открывающую панель

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Запоминается элемент в фокусе. Слой (z-index 800) и панель вставляются в body. | — | — |
| 0 | 300 | Затемнение: opacity 0 → 1. | opacity | ease |
| 0 | 300 | Панель выезжает справа: translate 100 % → 0. | translate | --ease |
| 300 | 0 | Фокус уходит в первое поле формы (в макете — textarea). | focus | — |

- **Фокус:** С кнопки-источника в первое поле (или заголовок панели). Ловушка включается при открытии.

- **Reduced motion:** Панель и затемнение появляются мгновенно.

- **Соседи:** Страница не сдвигается: панель накладывается поверх (z-index 800, как Dialog), под ней inert. Язычок агента (810) при открытой панели агента прилипает к её кромке.

### Смена режима panel → wide → full (`size`, origin: mockup)

- **Триггер:** нажатие «развернуть» в шапке

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Кнопка: слой hover → active. | background | ease |
| 0 | 300 | Ширина панели идёт 430 → 760 → 100 % (max-width переходит синхронно, у full снимается). | width, max-width | --ease |
| 0 | 0 | Иконка и подпись кнопки меняются на следующий шаг: развернуть → расширить → свернуть. Подсказка скрывается. | — | — |
| 0 | 200 | На full затемнение гаснет 1 → 0 и перестаёт ловить клики. | opacity | ease |
| 0 | 0 | В full содержимое и подвал центрируются колонкой до 820 px; у агента появляется история чатов слева. | — | — |
| 300 | 0 | После перехода (320 мс) пересчитывается положение язычка агента. | — | — |

- **Фокус:** Остаётся на кнопке «развернуть»: она не перерисовывается целиком, меняются иконка и подпись.

- **Reduced motion:** Режим меняется мгновенно.

- **Соседи:** Содержимое перекладывается в процессе перехода ширины: у таблиц фиксируйте ширину колонок. Страница под панелью не реагирует.

### Закрытие (`close`, origin: mockup)

- **Триггер:** крест / «Отмена» / Esc / клик по затемнению

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Кнопка получает hover и active. | background | ease |
| 0 | 0 | Фокус сразу возвращается на кнопку-источник; слушатели сняты. | focus | — |
| 0 | 200 | Панель уходит вправо: translate 0 → 100 %. | translate | --ease |
| 0 | 200 | Затемнение: opacity → 0. | opacity | ease |
| 200 | 0 | Узлы удаляются, inert со страницы снят. | — | — |

- **Фокус:** На кнопку-источник в момент начала закрытия.

- **Reduced motion:** Мгновенно.

- **Соседи:** Затемнение и панель уходят одновременно; страница остаётся как была.

### Фокус-ловушка (`trap`, origin: proposal)

- **Триггер:** Tab / Shift+Tab при открытой панели

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Список фокусируемых: поля, «Отмена», «Сохранить», «Развернуть», «Закрыть»; порядок DOM. | — | — |
| 2700 | 0 | С последнего элемента Tab возвращает фокус на первый, Shift+Tab — с первого на последний. | focus | — |
| 0 | 0 | Страница под панелью inert: мышь и клавиатура до неё не доходят. | — | — |

- **Фокус:** Не выходит за панель. Исключение — язычок агента [TODO] если он остаётся вне ловушки, решение по aria-modal нужно принять.

- **Reduced motion:** Не зависит от анимации.

- **Соседи:** Dialog и Popover, открытые поверх панели, забирают ловушку на себя; после их закрытия она возвращается панели.

## Как использовать

Импорт: в ките — `import { SHEET_NEXT_SIZE, SHEET_SIZE_LABEL, Sheet, SheetPanel } from "@/ui"`, в приложении — `import { SHEET_NEXT_SIZE, SHEET_SIZE_LABEL, Sheet, SheetPanel } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { Sheet, SheetPanel } from "@/ui"`. Панель справа с крестиком и тремя режимами ширины: `panel` (430 px), `wide` (760 px), `full` (весь экран).

| Пропс | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `open` | `boolean` | обязателен | Показана ли панель (уход 200 мс) |
| `onOpenChange` | `(open) => void` | нет | Просьба закрыть: Esc, крест, затемнение |
| `title` / `description` | `ReactNode` | — | Заголовок (он же `aria-labelledby`) и строка под ним |
| `size` / `defaultSize` | `"panel" \| "wide" \| "full"` | `"panel"` | Управляемый и неуправляемый режим |
| `onSizeChange` | `(size) => void` | нет | Кнопка «развернуть» идёт по кругу panel → wide → full → panel |
| `resizable` | `boolean` | `true` | Показывать кнопку смены режима |
| `footer` | `ReactNode` | нет | Подвал: две кнопки в сетке 1 : 1 |
| `busy` | `boolean` | нет | Идёт сохранение: Esc и затемнение не закрывают |
| `container` | `HTMLElement \| null` | `document.body` | Куда вставлять панель |
| `closeLabel` | `string` | `"Закрыть"` | Подпись крестика |
| `sizeButtonProps`, `closeButtonProps` | атрибуты `button` | нет | Дополнительные атрибуты кнопок шапки |

Остальные атрибуты `aside`, `className`, `ref` — на панель. `SheetPanel` — панель без затемнения и поведения.

```tsx
<Sheet open={open} onOpenChange={setOpen} title="Груз MSKU4821907"
  description="ООО «Дальснаб» · Нинбо → Владивосток"
  footer={<><Button variant="outline" onClick={() => setOpen(false)}>Отмена</Button><Button>Сохранить</Button></>}>
  …
</Sheet>
```

Поведение то же, что у `Dialog` (`useModal`): `inert` под панелью, ловушка Tab, Esc только верхнему слою, возврат фокуса. Фокус при открытии: первое поле формы, иначе сама панель (`tabIndex={-1}`). Подпись кнопки размера меняется по шагу: «Расширить», «На весь экран», «Свернуть в панель».

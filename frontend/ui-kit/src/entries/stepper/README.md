# Stepper

Шаги процесса: в строку, с подписями снизу, вертикальный и рабочий мастер. Шаг пройден, текущий, с ошибкой, впереди или недоступен.

Stepper показывает, где объект в последовательном процессе и сколько осталось: статус расхождения («Новый → В работе → Сверка → Решено»), ход груза («Заявка → Таможня → Выдача»), мастер подключения программы. Порядок важен. Если шаги можно проходить в любом порядке или это просто представления одного объекта, нужны вкладки.

- **id:** `stepper`
- **Группа:** Навигация (`navigation`)
- **CSS-префикс:** `ds-stp`
- **Origin хореографии:** mockup (3), proposal (1)

## Когда использовать / не использовать

### Использовать

- Шаги идут строго по порядку: 3–6 штук, названия — короткие существительные («Сверка»).
- Один текущий шаг; при ошибке именно этот шаг красный, а остальные не меняются.
- В мастере возвращаться можно, перепрыгивать вперёд — нет.
- Вертикальный вид — когда у шагов есть время и комментарии; детали только у текущего.
- «Далее» блокируется, пока шаг не готов, а подпись объясняет почему.

### Не использовать

- Stepper как навигация между равноправными разделами: это Tabs.
- Больше 7 шагов в строку: подписи не поместятся; берите вертикальный.
- Цвет без галочки и «!»: статус должен читаться без цвета.
- Пропуск шагов без пояснения: если шаг не нужен, его убирают из списка.
- Прогресс в процентах вместо шагов: для этого Progress.

## Анатомия

1. **Список шагов (ol)** — Упорядоченный список с aria-label. Раскладка зависит от вида: строка, колонки с подписями, вертикальная колонка.
2. **Кружок** — 24 px: номер (11 px, 700), галочка у пройденного, «!» у ошибки. Заливка primary — пройден; кольцо 2 px primary с ореолом 4 px — текущий; заливка danger — ошибка; кольцо --border — впереди.
3. **Подпись** — Название шага 12 px, 600: у пройденного и текущего --text, у остальных --text-3. Под ним необязательная дата или пояснение (11 px, 400).
4. **Линия-соединитель** — 2 px, радиус 2: --divider, у пройденных primary. Между кружками; в вертикальном — под кружком.
5. **Содержимое шага** (необязательная) — Только вертикальный вид: у текущего и ошибочного шага под подписью плашка на --surface-muted (кому и что нужно сделать).

## Варианты

- **Компактный (в строку)** (`inline`): Кружок, подпись и линия по горизонтали, всё в одну строку. Когда: заголовки и панели: статус расхождения рядом с названием. Не больше 4–5 шагов.
- **Горизонтальный (подписи снизу)** (`below`): Колонки равной ширины, подпись и дата под кружком, линия между центрами кружков. Когда: ход груза, длинные процессы, мастер: подписи не вытесняют друг друга.
- **Вертикальный** (`vertical`): Кружки столбцом, линия уходит вниз. У текущего шага есть содержимое: кому и что делать. Когда: ход одного объекта с комментариями и временем; боковые панели.
- **Рабочий мастер** (`wizard`): Горизонтальный stepper + область шага + «Назад / Далее». Клик по пройденному шагу возвращает; «Далее» заблокирован, пока шаг не готов (на «Проверке» — пока идёт прогресс). Когда: подключение программ, импорт, всё, что нельзя сделать в один экран. Попробуйте: он живой.

## Доступность

- **ol + aria-current="step"** (`aria`): Упорядоченный список с aria-label; текущий и ошибочный шаг получают aria-current="step". К подписи каждого шага добавлено скрытое слово статуса («Сверка, текущий», «…, пройден»), потому что галочка и цвет скринридеру не видны.
- **Кнопки-шаги** (`aria`): Кликабельные шаги — button; будущие — disabled (не aria-disabled на ссылке). Кружок aria-hidden.
- **aria-live у области мастера** (`aria`): Область шага — aria-live="polite": смена шага и прогресс объявляются без перехвата фокуса. [TODO] в макете live-области нет.
- **Tab, Enter, Space** (`key`): Идут по кликабельным шагам и кнопкам мастера. Стрелок нет: это не tablist.
- **Куда идёт фокус** (`focus`): «Далее»/«Назад» остаются на месте при смене шага. Если «Назад» стал disabled на первом шаге, фокус переходит на «Далее» (иначе теряется). Клик по пройденному шагу оставляет фокус на нём.
- **Контраст** (`contrast`): Номер текущего --link-strong на --surface 7,2:1; галочка navy на teal 7,4:1; «!» белый на danger 4,9:1; подпись --text-3 4,9:1. Кольцо кружка --border 1,7:1 дополнено номером и подписью.
- **prefers-reduced-motion** (`motion`): Смена статуса кружка и заполнение линии — без перехода.

## Хореография

### Переход к следующему шагу (`advance`, origin: mockup)

- **Триггер:** процесс дошёл до следующего шага (или «Далее» в мастере)

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 200 | Текущий кружок заполняется primary: фон, цвет и кольцо меняются, на нём появляется галочка вместо номера. | background, box-shadow, color | ease |
| 0 | 200 | Линия после него заполняется primary. | background | ease |
| 0 | 200 | Следующий кружок получает кольцо и ореол текущего; подпись уходит от --text-3 к --text. | box-shadow, color | ease |
| 0 | 0 | Номер сменяется галочкой мгновенно, без перекрёстного перехода. | content | — |

- **Фокус:** Остаётся на кнопке «Далее» (мастер) или не затрагивается (индикатор статуса).

- **Reduced motion:** Кружки и линия меняют цвет мгновенно.

- **Соседи:** Подписи не сдвигаются: ширина колонок равна, раскладка стабильна. [TODO] в макете DOM перерисовывается целиком, поэтому переход в нём не виден; в ui-kit элементы должны сохраняться.

### Возврат к пройденному шагу (`back`, origin: mockup)

- **Триггер:** клик по пройденному шагу мастера

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: кольцо кружка темнеет (у пройденного — заливка primary −9 %). | box-shadow, background | — |
| 600 | 0 | Нажатие: кружок сжимается до 94 %. | scale | — |
| 750 | 200 | Выбранный шаг снова становится current, шаги после него — todo, их линии теряют заливку. | background, box-shadow | ease |
| 750 | 0 | Область шага заменяется содержимым выбранного (без перехода); остановленный прогресс сбрасывается. | content | — |

- **Фокус:** Остаётся на нажатом шаге; клавиатурный возврат — Enter/Space на шаге.

- **Reduced motion:** Мгновенная смена цвета, без сжатия.

- **Соседи:** Размеры не меняются; кнопка «Назад» отключается на первом шаге, фокус при этом уходит на «Далее».

### Вертикальный ход (`vertical`, origin: mockup)

- **Триггер:** статус процесса продвинулся

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 200 | Кружок и участок линии под ним заливаются primary. | background | ease |
| 0 | 0 | Содержимое (плашка) уходит у завершённого шага и появляется у нового текущего: высота меняется скачком. [TODO] предложение: анимировать как Accordion (grid 0fr→1fr, 250 мс). | height | — |
| 0 | 0 | Подпись следующего шага из --text-3 становится --text. | color | — |

- **Фокус:** Не затрагивается: вертикальный stepper чаще бывает индикатором.

- **Reduced motion:** Цвета меняются мгновенно.

- **Соседи:** Ниже идущие шаги сдвигаются вместе с плашкой содержимого.

### Шаг мастера целиком (`wizard`, origin: proposal)

- **Триггер:** «Далее» в мастере

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Проверка готовности шага: пока «Далее» disabled, шаг не завершён (на «Проверке» — пока полоса не дойдёт до 100 %). | disabled | — |
| 0 | 200 | Stepper продвигается (см. «Переход к следующему шагу»). | background, box-shadow | ease |
| 100 | 0 | Область шага заменяется новым содержимым; aria-live озвучивает заголовок. | content | — |
| 100 | 125 | [TODO] предложение: затухание содержимого 125 мс вместо мгновенной замены. | opacity | ease |

- **Фокус:** Остаётся на «Далее»; на первом шаге «Назад» блокируется, фокус уходит на «Далее»; закрытие мастера возвращает фокус на кнопку, открывшую его.

- **Reduced motion:** Всё без переходов; содержимое заменяется мгновенно.

- **Соседи:** Размер области шага зафиксирован (min-height 118 px), чтобы кнопки внизу не прыгали при смене содержимого.

## Примеры

### Статус расхождения в панели (`status`)

```tsx
<Stepper variant="inline" current={2} steps={[{ title: "Новый" }, { title: "В работе" }, { title: "Сверка" }, { title: "Решено" }]} />
```

### Ход груза (`cargo`)

```tsx
<Stepper variant="below" current={2} steps={[{ title: "Заявка", hint: "09 ноя" }, …]} />
```

### Мастер подключения (`wizard`)

```tsx
<Stepper variant="below" current={step} clickable lockAhead onStepClick={setStep} aria-label="Шаги подключения"
  steps={[{ title: "Программа" }, { title: "Доступ" }, { title: "Проверка" }, { title: "Готово" }]} />
```

## Как использовать

<!-- manual:start -->
Компонент: `Stepper`. Типы: `StepperProps`, `StepperStep`, `StepperVariant`, `StepperStatus`.

```tsx
import { Stepper } from "@/ui";
```

Пропсы `Stepper` (плюс атрибуты `<ol>`, `ref`):

| Проп          | Тип                                  | По умолчанию        | Описание                                                                               |
| ------------- | ------------------------------------ | ------------------- | -------------------------------------------------------------------------------------- |
| `steps`       | `StepperStep[]`                      | обязателен          | Шаги: `title`, `hint`, `detail` (только у вертикального), атрибуты `<li>`, `data-*`.   |
| `current`     | `number`                             | `0`                 | Индекс текущего шага; меньше нуля: все впереди, больше длины: все пройдены.            |
| `error`       | `number`                             | нет                 | Индекс шага с ошибкой (красный, `!`).                                                  |
| `variant`     | `"inline" \| "below" \| "vertical"`  | `"inline"`          | Подпись рядом, под значком или вертикальная лента с подробностями.                     |
| `clickable`   | `boolean`                            | нет                 | Шаги становятся кнопками (у вертикального варианта не действует).                          |
| `lockAhead`   | `boolean`                            | нет                 | Будущие шаги недоступны, пройденные доступны.                                          |
| `onStepClick` | `(index: number) => void`            | нет                 | Клик по доступному шагу; текущий не кликается.                                         |
| `aria-label`  | `string`                             | «Шаги процесса»     | Название списка.                                                                       |

```tsx
<Stepper
  current={2}
  steps={[{ title: "Новый" }, { title: "В работе" }, { title: "Сверка" }, { title: "Решено" }]}
/>

<Stepper variant="below" current={2} steps={[{ title: "Заявка", hint: "09 ноя" }, …]} />

<Stepper
  variant="below" clickable lockAhead current={step} onStepClick={setStep}
  aria-label="Шаги подключения"
  steps={[{ title: "Программа" }, { title: "Доступ" }, { title: "Проверка" }, { title: "Готово" }]}
/>
```

Доступность:

- Упорядоченный список; у текущего и ошибочного шага `aria-current="step"`; статус каждого шага читается скрытым текстом («, пройден», «, текущий», «, впереди», «, ошибка»). Номер и галочка скрыты.
- Заблокированные шаги — настоящий `disabled`. Вид inline в контейнере уже 520 px оставляет подпись только у текущего шага (container query).
- Мастер из нескольких экранов собирайте поверх `Stepper` самостоятельно: следите за фокусом при «Назад» и `aria-live` у тела шага.

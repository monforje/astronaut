# Sidebar

Сворачиваемая боковая панель разделов: группы, пункты со счётчиками, активный пункт, узкий rail-режим 56 px с подсказками.

Сайдбар — главная навигация продукта: «Грузы», «Расхождения», «Настройки». Группы с заголовками делят разделы по смыслу и сворачиваются. Панель можно сузить до рельса (rail) на 56 px, чтобы вернуть ширину таблицам: тогда каждая группа превращается в значок с подсказкой, а клик по нему разворачивает панель обратно. Цвет панели нейтральный графит; navy есть только в логотипе, акцент — выбранный пункт.

- **id:** `sidebar`
- **Группа:** Навигация (`navigation`)
- **CSS-префикс:** `ds-side`
- **Origin хореографии:** mockup (3)

## Когда использовать / не использовать

### Использовать

- Группы по смыслу работы («Экран», «Документы»), 3–7 пунктов в группе.
- Подписи как в крошках и в заголовках страниц; значок один на пункт.
- Активный пункт один; у группы с активным пунктом в rail подсвечен значок.
- Счётчик — только если число помогает решить, куда идти; срочные выделяйте тоном err.
- В rail каждая группа получает подсказку; клик по значку разворачивает панель.

### Не использовать

- Левая акцентная полоска у активного пункта: акцент — подложка и кольцо.
- Цветные значки и цветные подписи пунктов: панель нейтральная, navy — только логотип.
- Вложенные подменю в сайдбаре: максимум два уровня (группа → пункт).
- Прятать пункты, которых нет у пользователя, в разных местах по-разному: либо disabled, либо нет.
- Автоматически сворачивать в rail на любом экране: размер выбирает человек.

## Анатомия

1. **Контейнер** — aside > nav aria-label «Разделы». Ширина 248 px (--w-side), в rail 56 (--w-rail), переход 300 мс. Фон --surface, справа линия --divider. Липкий под топбаром, высота — остаток экрана.
2. **Бренд** — Ячейка высотой 56 px (= топбар): логотип с названием; в rail остаётся только знак. Справа кнопка «Свернуть панель» (видна при наведении на панель). В оболочке бренд лежит в своей ячейке слева от топбара.
3. **Заголовок группы** — Кнопка 28 px, 600, --text-2: подпись, шеврон (при наведении и у свёрнутой), в rail — значок группы. aria-expanded.
4. **Пункт** — Ссылка 32 px, радиус 8, значок 16 px --text-3, подпись 500, зазор 10. Активный: подложка --selected с кольцом --border-selected, 600, значок --link, aria-current="page".
5. **Счётчик / метка** (необязательная) — Число справа, 12 px, --text-3, tabular-nums. Для срочного — тон err (--err-text, 600) или точка 8 px; [TODO] предложение, в макете только нейтральный счётчик.
6. **Кромка (edge)** (необязательная) — Невидимая полоса 8 px у правого края в rail: клик разворачивает, при наведении показывает линию 2 px --focus.
7. **Подсказка rail** (необязательная) — Справа от значка группы: имя группы (и сочетание клавиш у кнопки). Только в rail.
8. **Низ панели** (необязательная) — «Справка»: пункт без группы; в rail скрыт.

## Варианты

- **Развёрнутый** (`expanded`): 248 px: значки и подписи пунктов, заголовки групп, счётчики. Основной режим. Когда: по умолчанию, на экранах шире 1280 px и при навигации по большому числу разделов.
- **Rail · 56 px** (`rail`): Остались значки групп; подписи и пункты скрыты. Группа с активным пунктом подсвечена selected-подложкой, значок --link. Подсказка справа. Когда: таблицы и широкие экраны данных; выбор запоминается (localStorage, ключ ast-rail) и переживает перезагрузку.
- **С свёрнутой группой** (`closed`): Шеврон повёрнут на −90° и виден всегда, пункты группы скрыты. Когда: редко нужные группы; состояние хранится на сессию. [TODO] макет не сохраняет свёрнутость между сессиями.

## Состояния

### Применимые

- **Item · default** (`default`): Подпись --text-2, 500, значок --text-3, без подложки.
- **Item · hover** (`hover`): Слой 4 % (--layer-1), подпись --text. У заголовка группы тот же слой и виден шеврон.
- **Item · active** (`active`): Слой 7 % (--layer-1p), пока пункт нажат.
- **Item · focus** (`focus`): Кольцо 2 px --focus внутри пункта (offset −2): панель с overflow его не обрезает.
- **Current (активный)** (`selected`, `current`): aria-current="page": подложка --selected, кольцо --border-selected, 600, значок --link.
- **Disabled** (`disabled`): Раздел недоступен по тарифу или правам: --text-ph, не фокусируется, подсказка с причиной [TODO] предложение; в макете нет.
- **Loading** (`loading`): Счётчик ещё считается: пульсирующая капсула 20×12 на месте числа. Сам пункт активен. [TODO] предложение.
- **Error / внимание** (`error`): Счётчик в тоне err (--err-text, 600) или красная точка 8 px: раздел требует решения. Цвет пункта не меняется. [TODO] предложение.
- **Rail · подсказка** (`other`, `rail-tip`): Подсказка справа от значка группы, без задержки; шрифт 12 px, 600.

### Не применимы (с причиной)

- **Empty** (`empty`): Группа без доступных пунктов не показывается вовсе (ни заголовок, ни значок в rail). Целиком пустой сайдбар — признак ошибки прав, а не состояние компонента.

## Доступность

- **nav aria-label="Разделы"** (`aria`): Ориентир навигации. Текущий пункт — aria-current="page". Заголовки групп — кнопки с aria-expanded; у rail-кнопки и кромки aria-label «Развернуть панель».
- **inert у скрытого** (`aria`): Пункты свёрнутой группы и все пункты в rail получают inert: невидимые ссылки не берут фокус. [TODO] в макете скрыто только высотой, пункты остаются в порядке Tab; исправлено в словаре.
- **Подсказка rail** (`aria`): role="tooltip", у кнопки у группы есть aria-label — скринридер читает имя и без подсказки. Подсказка не единственный носитель названия.
- **Tab, Enter** (`key`): Идут по кнопке бренда, заголовкам и пунктам. Enter на заголовке сворачивает группу (в rail — разворачивает панель).
- **Ctrl + \** (`key`): Сворачивает и разворачивает панель из любого места страницы (есть в макете).
- **↑ / ↓ по пунктам** (`key`): [TODO] предложение: стрелки внутри группы. В макете только Tab.
- **Куда идёт фокус** (`focus`): При сворачивании в rail остаётся на кнопке-триггере (меняется только её aria-label). При клике по значку группы в rail панель разворачивается, фокус остаётся на этой группе. Пункты свёрнутых групп из Tab выходят.
- **Контраст** (`contrast`): --text-2 на --surface 8,2:1; --text-3 значков 4,9:1; активный --text на подложке selected ≈ 13:1, значок --link на selected ≈ 4,6:1. Счётчик err: --err-text 5,5:1.
- **prefers-reduced-motion** (`motion`): Ширина панели, прозрачность подписей, поворот шевронов и высота групп меняются мгновенно.

| 600 | 300 | Отступ между группами 14 → 2 px. | padding-top | --glide |
| 600 | 200 | Низ («Справка») гаснет, затем скрывается visibility. | opacity, visibility | --dur |
| 600 | 0 | aria-label триггера «Свернуть панель» → «Развернуть панель», значок кнопки меняется; пункты получают inert. | aria-label, inert | — |
| 1700 | 125 | Наведение на значок группы: справа подсказка с названием группы (появление 125 мс: opacity 0→1, scale .96→1). | opacity, scale | --ease |
| 2700 | 0 | Уход указателя убирает подсказку мгновенно. | — | — |
| 3000 | 300 | Разворачивание идёт теми же шагами в обратную сторону за те же 300 мс; пункты снова доступны. | width, opacity, grid-template-rows | --glide |

- **Фокус:** На кнопке-триггере (меняется только aria-label). При клике по значку группы или кромке в rail панель разворачивается, фокус остаётся на нажатом элементе.

- **Reduced motion:** Панель переключается между 248 и 56 px мгновенно; прозрачности и высоты меняются без переходов.

- **Соседи:** Контент справа не сдвигается отдельно: колонка оболочки auto просто становится уже, и страница перестраивается каждый кадр. Таблицы получают ширину сразу; крошки и поиск в топбаре остаются на месте. Выбор запоминается (ключ ast-rail).

## Как использовать

<!-- manual:start -->
Компонент: `Sidebar`. Типы: `SidebarProps`, `SidebarGroup`, `SidebarItem`, `SidebarToggleProps`.

```tsx
import { Sidebar } from "@/ui";
```

Пропсы `Sidebar` (плюс атрибуты `<aside>`, `ref`):

| Проп                                                | Тип                           | По умолчанию | Описание                                                                                     |
| --------------------------------------------------- | ----------------------------- | ------------ | -------------------------------------------------------------------------------------------- |
| `groups`                                            | `SidebarGroup[]`              | обязателен   | Группы: `id`, `title`, `icon`, `items`.                                                      |
| `footerItems`                                       | `SidebarItem[]`               | нет          | Нижние пункты (Справка); в rail скрываются.                                                  |
| `brand` / `brandMark`                               | `ReactNode`                   | нет          | Знак с названием (развёрнуто) и только знак (rail).                                          |
| `rail` / `defaultRail` / `onRailChange`             | `boolean` / `(rail) => void`  | `false`      | Узкая панель 56 px: управляется родителем или хранится внутри.                               |
| `active` / `defaultActive` / `onActiveChange`       | `string` / `(id) => void`     | нет          | Активный пункт: `aria-current="page"`.                                                       |
| `closedGroups` / `defaultClosedGroups` / `onClosedGroupsChange` | `string[]`        | `[]`         | Свёрнутые группы.                                                                            |
| `storageKey`                                        | `string`                      | нет          | Ключ `localStorage`: `{ rail, closed }` читается при старте и пишется при изменении.         |
| `tooltipFor`                                        | `string`                      | нет          | Принудительно показать подсказку у группы в rail (для обучающих экранов).                    |
| `navLabel`                                          | `string`                      | «Разделы»    | Название навигации.                                                                          |
| `toggleProps`                                       | атрибуты `<button>`           | нет          | Атрибуты кнопки сворачивания.                                                                |

`SidebarItem`: `id`, `label`, `icon`, `href` (нет: якорь `#id`, переход отменяется), `count` (число или `"loading"`), `tone="err"` (красное число), `dot` (точка внимания), `disabled`, `onClick`, атрибуты `<a>`. `SidebarGroup` кроме полей принимает атрибуты `<section>`.

```tsx
<Sidebar
  rail={rail}
  onRailChange={setRail}
  active="inbox"
  brand={<Logo />}
  brandMark={<LogoMark />}
  groups={[
    {
      id: "layouts", title: "Макеты", icon: <GridIcon />,
      items: [
        { id: "dash", label: "Дашборд", icon: <ChartIcon />, href: "/dash" },
        { id: "inbox", label: "Расхождения", icon: <WarnIcon />, href: "/inbox", count: 8, tone: "err" },
      ],
    },
  ]}
  footerItems={[{ id: "help", label: "Справка", icon: <HelpIcon /> }]}
/>

<Sidebar defaultRail storageKey="astronaut:sidebar" groups={groups} />
```

Доступность:

- `<aside>` с `<nav aria-label>`; активный пункт `aria-current="page"`; недоступный `aria-disabled` и `tabIndex=-1`; счётчики и точки подписаны («загрузка», «требует внимания»), значки скрыты.
- Группа — кнопка с `aria-expanded`; свёрнутые группы и все группы в rail `inert`. Клик по группе в rail разворачивает панель. Кнопка в шапке и кромка у правого края возвращают развёрнутый вид.
- `Ctrl+\` при фокусе внутри панели переключает rail (общего глобального слушателя нет, чтобы несколько панелей на странице не конфликтовали). В rail подсказка у группы показывается по наведению и фокусу.
- Для роутера передайте `href` и `onClick` с `preventDefault()`; смену активного пункта сообщает `onActiveChange`.

# AgentPanel / Chat

Панель агента в стиле ChatGPT и Gemini: приветствие и подсказки, переписка, поле ввода с кнопкой «Отправить / Остановить», стриминг ответа. Живёт внутри Sheet.

AgentPanel — основное рабочее место с агентом. Пустая панель приветствует и предлагает четыре вопроса; вопрос запускает ответ, который сначала «думает», потом выводится словами с курсором; под ответом — карточка с действиями и оценка. Агент может ошибаться, а изменения делает только после подтверждения: об этом напоминает строка под полем. Панель открывается язычком (AgentTab) в Sheet трёх режимов.

- **id:** `agent-panel`
- **Группа:** Окна и панели (`overlays`)
- **CSS-префикс:** `ds-agent-panel`
- **Origin хореографии:** mockup (4), proposal (1)

## Когда использовать / не использовать

### Использовать

- Приветствие с четырьмя подсказками в новом чате; подсказка отправляется одним нажатием.
- Пока агент отвечает, кнопка отправки — «Остановить»; пользователь всегда может прервать.
- Изменения данных — только после подтверждения: карточка с кнопкой, не молчаливая правка.
- Строка «Агент может ошибаться» под полем всегда на месте.
- Источники: «Проверил 128 грузов · 3 источника» раскрывает шаги, чтобы ответу можно было доверять.

### Не использовать

- Блокировать поле ввода на время ответа: пользователь может писать следующее, но отправка ждёт.
- Убирать «Остановить» из длинных ответов.
- Выводить ответ целиком сразу после долгой паузы: стриминг показывает, что работа идёт.
- Автоматически выполнять действия по тексту ответа без карточки подтверждения.
- Анимации агента вне brand/animated: знак берётся готовый, а мигание курсора и градиент строки — единственные движения в панели.

## Анатомия

1. **Шапка** — История чатов (в full — боковая колонка), выбор режима «Агент: Быстрый / Точный», новый чат, развернуть и закрыть (крест у Sheet).
2. **Приветствие** — Знак агента 56 px, «Чем помочь, Ирина?», пояснение и подсказки; пока нет переписки.
3. **Подсказки** (необязательная) — Четыре карточки с иконкой, вопросом и пояснением; в panel — в одну колонку, в wide/full — в две.
4. **Реплика пользователя** — Справа, пузырь surface-muted радиуса 18, не шире 82 %; при наведении или фокусе слева внизу «Копировать» и «Изменить».
5. **Ответ агента** — Слева знак sm и тело: строка «думает» или «Проверил 128 грузов · 3 источника» (раскрывает шаги), текст, карточка действия, ряд «Копировать · Хорошо · Плохо · Заново».
6. **Курсор стриминга** — Прямоугольник 7 × 14 px после последнего слова, мигает 1 с (steps(2)); пока ответ пишется.
7. **Поле ввода** — Скругление 24, textarea растёт до 160 px, внизу «+», чипы режимов («Сверка», «Поиск по документам») и круглая кнопка «Отправить» ↔ «Остановить».
8. **Предупреждение** — Под полем 11 px --text-3: «Агент может ошибаться. Проверяйте важные данные. Изменения — только после вашего подтверждения».

## Варианты

- **Приветствие** (`empty`): Знак, «Чем помочь, Ирина?», четыре подсказки. Нажатие на подсказку сразу отправляет вопрос. Когда: новый чат, переписки ещё нет.
- **Переписка** (`chat`): Вопрос и ответ с проверенными шагами, карточкой «Исправить в 1С» и оценкой. Когда: агент ответил.
- **Идёт ответ** (`streaming`): Часть текста выведена, на конце курсор; кнопка превращена в «Остановить». Когда: агент пишет ответ.
- **Во весь экран** (`full`): Слева история чатов 272 px, колонка переписки до 760 px по центру, подсказки в две колонки. Когда: режим full у Sheet: длинная работа с агентом.
- **Живая панель** (`live`): Выберите подсказку или напишите свой вопрос: «думает», стриминг, карточка, оценка. «Остановить» прерывает вывод. Когда: посмотреть руками.

## Состояния

### Применимые

- **Default · приветствие** (`default`): Пустая панель: подсказки, поле пусто, «Отправить» отключена.
- **Hover** (`hover`): Подсказка: слой 4 % и кольцо --text-3; поле ввода — кольцо --text-3.
- **Active** (`active`): Нажатая подсказка и кнопка отправки: слой 7 % / 15 %.
- **Focus** (`focus`): Поле ввода: кольцо --focus 1px и ореол 3 px --selected; кнопки — 2 px.
- **Disabled «Отправить»** (`disabled`): Поле пусто — кнопка отключена своими цветами (primary-off). Когда есть текст, она активна.
- **Loading · думает** (`loading`): Строка «Анализирую грузы…» с бегущим градиентом, кнопка — «Остановить».
- **Стриминг** (`other`, `streaming`): Слова, курсор на конце, «Остановить».
- **Остановлено** (`other`, `stopped`): Написанное остаётся, курсора и действий нет. [TODO] маркер «Ответ остановлен» в макете отсутствует.
- **Error** (`error`): Плашка err на месте ответа с «Повторить»; вопрос сохранён. [TODO] в макете ошибки агента нет, предложено словарём.

### Не применимы (с причиной)

- **Empty** (`empty`): Это приветствие (Default): пустая переписка показывает подсказки, а не пустое место.

## Доступность

- **Переписка как log** (`aria`): Колонка сообщений — role="log" с aria-label «Переписка»; текст ответа в aria-live="polite". Стриминг по словам объявляется скринридером урывками: [TODO] предложить объявлять ответ целиком по окончании, а во время вывода — «Агент отвечает».
- **Кнопка «Отправить / Остановить»** (`aria`): Одна кнопка меняет иконку и aria-label («Отправить» ↔ «Остановить»); отключена, пока поле пусто и нет ответа в процессе. Фокус не теряется при смене.
- **Enter, Shift+Enter, Esc** (`key`): Enter отправляет, Shift+Enter — перенос строки. Esc внутри панели закрывает Sheet [TODO] во время стриминга Esc сначала предлагается остановить, потом закрывать.
- **Ctrl J** (`key`): Открывает и закрывает панель из любого места, см. AgentTab.
- **Куда идёт фокус** (`focus`): При открытии панели — в поле «Спросите агента». После отправки и после ответа фокус остаётся в поле. «Новый чат» возвращает фокус в поле. При закрытии — на язычок.
- **Оценка и копирование** (`aria`): «Хороший/Плохой ответ» — кнопки-переключатели (aria-pressed), одна из двух. «Копировать» на 1,2 с меняет значок на ✓ (объявите «Скопировано» в aria-live).
- **Контраст** (`contrast`): Текст ответа --text на surface 16,5:1; пояснения --text-3 4,9:1. Бегущая строка «Анализирую грузы…» (градиент text-3 → text → text-3) в крайних точках 4,9:1. Подсказка в поле --text-ph 3,2:1 — ниже 4,5, но не несёт единственный смысл [TODO] общее замечание из Fields.
- **prefers-reduced-motion** (`motion`): Строка «думает» без градиента и без бега; курсор без мигания; раскладка и смена режимов мгновенные. Стриминг по словам остаётся: это содержание, а не украшение (альтернатива: выводить ответ сразу).

- **Reduced motion:** Строка «думает» без бега и градиента, курсор без мигания; вывод по словам остаётся или заменяется на мгновенный [TODO].

- **Соседи:** Колонка растёт вниз и прокручивается; шапка и поле остаются на месте. Sheet своего размера не меняет.

- **Reduced motion:** Без бега градиента.

- **Соседи:** Колонка немного меняет высоту; прокрутка остаётся внизу.

## Примеры

### Новый чат (`greeting`)

```tsx
const [messages, setMessages] = useState<AgentMessage[]>([]);
const [value, setValue] = useState("");

const ask = (question: string) => {
  const id = messages.length + 1;
  setMessages((list) => [...list, { id, question, phase: "thinking" }]);
  setValue("");
  streamAnswer(id, question);
};

<AgentPanel
  messages={messages}
  value={value}
  onValueChange={setValue}
  greeting="Чем помочь, Ирина?"
  suggestions={SUGGESTIONS}
  onAsk={ask}
  onSend={() => ask(value)}
  onStop={stop}
/>
```

### Ответ агента (`chat`)

```tsx
const [messages, setMessages] = useState<AgentMessage[]>([
  {
    id: 1,
    question,
    phase: "done",
    answer,
    summary: "Проверил 128 грузов · 3 источника",
    attachment: <CargoCard />,
  },
]);

<AgentPanel messages={messages} value={value} onValueChange={setValue} onSend={() => ask(value)} />
```

## Как использовать

Импорт: в ките — `import { AgentPanel } from "@/ui"`, в приложении — `import { AgentPanel } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { AgentPanel } from "@/ui"`. Компонент — оболочка чата: шапка, история, переписка, поле ввода. Данные и обработчики приходят пропсами, стриминг показывается из `messages`.

| Пропс | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `messages` | `AgentMessage[]` | обязателен | `{ id, question, phase, answer?, summary?, steps?, stepsOpen?, attachment?, feedback?, thinkingText? }` |
| `AgentMessage.phase` | `"thinking" \| "streaming" \| "done" \| "stopped" \| "error"` | — | Мерцающая подпись / печать с курсором / готов / остановлен / ошибка с повтором |
| `size` | `"panel" \| "wide" \| "full"` | `"panel"` | Режим; в `full` слева появляется история чатов |
| `suggestions` | `{ title, hint?, icon? }[]` | `[]` | Карточки-подсказки пустого чата |
| `chats` | `{ id, title, group?, current? }[]` | `[]` | История чатов по группам |
| `chips` | `string[]` | `[]` | Переключатели режимов у поля («Сверка») |
| `greeting`, `intro`, `disclaimer` | `ReactNode` | «Чем помочь?» | Тексты пустого состояния и подпись внизу |
| `mode`, `modeLabel` | `string` | нет | Кнопка режима агента в шапке |
| `value` / `defaultValue` / `onValueChange` | `string` | `""` | Текст в поле: управляемый и неуправляемый |
| `busy` | `boolean` | по фазам | Идёт ответ: кнопка отправки превращается в «Остановить» |
| `onSend(text)` | `(string) => void` | нет | Enter или кнопка; пустой текст не отправляется; Shift+Enter — перенос |
| `onStop`, `onAsk(text)`, `onSelectChat(id)`, `onNewChat`, `onClose`, `onResize`, `onAttach` | функции | нет | События шапки, подсказок, истории |
| `onToggleSteps(id)`, `onFeedback(id, "up" \| "down")`, `onRegenerate(id)`, `onCopy(id)`, `onEdit(id, q)` | функции | нет | События сообщений |
| `follow` | `boolean` | нет | Всегда прокручивать к последнему сообщению (во время ответа делается само) |
| `slotProps` | `{ composer?, sendButton?, copyReplyButton?, suggestion?(i) }` | нет | Дополнительные атрибуты частей |

Остальные атрибуты `section`, `className`, `ref` — на корень; панель заполняет контейнер по ширине и высоте.

```tsx
<AgentPanel
  messages={messages} suggestions={SUGGESTIONS} greeting="Чем помочь, Ирина?"
  onSend={ask} onAsk={ask} onStop={stop} onRegenerate={retry} onFeedback={rate}
/>
```

Доступность: корень `section` «Агент», переписка `role="log"`, текст ответа в `aria-live="polite"`, кнопки-значки подписаны, оценки с `aria-pressed`, ошибка читается как `alert`.

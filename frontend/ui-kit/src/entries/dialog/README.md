# Dialog

Модальное окно с решением: шапка, середина, подвал. Без крестика: выход только кнопками, «нет» слева, «да» справа, ширина 50/50.

Dialog останавливает работу, чтобы получить решение: подтвердить действие, принять расхождение, заполнить короткую форму. Он перекрывает страницу затемнением и забирает фокус. Крестика нет намеренно: у закрытия должен быть явный смысл («Нет», «Отмена», «Отклонить»). Информация без решения — Alert или Toast; просмотр и правка карточки — Sheet.

- **id:** `dialog`
- **Группа:** Окна и панели (`overlays`)
- **CSS-префикс:** `ds-dialog`
- **Origin хореографии:** mockup (5)

## Когда использовать / не использовать

### Использовать

- Заголовок — вопрос или решение: «Сверить документы?», «Отправить груз в архив?».
- Кнопки называют исход: «Да, сверить», «В архив», «Принять», а не «ОК».
- «Нет» всегда слева, «да» — справа; на destructive повесьте красную кнопку «да» и опишите, как вернуть.
- Esc равен левой кнопке («нет»); оно же закрытие без последствий.
- Не больше двух кнопок; три выбора — это Sheet или страница.

### Не использовать

- Крестик в шапке: у закрытия должен быть явный исход.
- Окно поверх окна: если нужен выбор внутри формы, используйте Select/Popover (они выше по z-index).
- Dialog для сообщения без решения: это Alert или Toast.
- Закрытие по клику на затемнение: решение потеряется незаметно (в макете клик не закрывает).
- Длинная форма: от шести полей берите Sheet.

## Анатомия

1. **Затемнение** — Слой на весь экран, цвет --overlay (45 % тёмный, в тёмной теме 62 %), z-index 800, по центру окно с отступом 16 px. Клик по затемнению окно не закрывает.
2. **Окно** — Фон --surface, кольцо 1px --border, тень --shadow-dialog, радиус --r-panel (14). Ширина 400 / 520 / 720, не шире экрана; высота до 100dvh − 32.
3. **Шапка** — Минимум 64 px, отступы 16 × 24, заголовок 18 px, 700; снизу линия --divider. Креста нет.
4. **Середина** — Прокручивается сама (тонкая полоса), отступы 24, интервал 16, текст --text-2. Шапка и подвал остаются на месте.
5. **Плашка ошибки** (необязательная) — Alert err между серединой и подвалом; появляется при неудачной попытке.
6. **Подвал** — Минимум 64 px, отступы 16 × 24, линия сверху. Две кнопки равной ширины: «нет» (outline) слева, «да» (primary или destructive) справа.

## Варианты

- **Подтверждение · sm 400** (`confirm`): Короткий вопрос и пояснение: «Сверить документы?» «Нет» — «Да, сверить». Когда: действие дорогое по времени или необратимое наполовину: запуск сверки, отправка.
- **Принять / Отклонить · md 520** (`decision`): Вопрос с данными решения (сводка «было/стало»); кнопки называют исход, а не «Да/Нет». Когда: решение по объекту: принять расхождение, подписать, отправить.
- **Опасное действие · sm** (`danger`): «Да» становится destructive и называет действие («В архив»), текст говорит, как вернуть. Когда: архивирование, удаление, отключение: последствия трудно откатить.
- **Форма · md 520** (`form`): Поля в середине; «да» отключено, пока форма невалидна; ошибка отправки — плашкой над подвалом. Когда: создание объекта из 2–5 полей; больше — Sheet.
- **Длинное содержимое · lg 720** (`long`): Середина прокручивается, шапка и подвал на месте. Одна кнопка — справа, не уже половины. Когда: журнал, список, текст для чтения; решение не нужно — тогда лучше Sheet.
- **Живой** (`live`): Все пять окон в рамке: фокус-ловушка, Esc = «нет», выполнение с Spinner, ошибка формы при первой попытке. Когда: проверить поведение руками и клавиатурой.

## Состояния

### Применимые

- **Default** (`default`): Окно открыто, фокус на «да» (в форме — на первом поле).
- **Hover кнопки** (`hover`): Слой поверх кнопки: 8 % у primary, 6 % у outline. Окно и затемнение не реагируют.
- **Active кнопки** (`active`): Слой плотнее hover: 15 % у primary, 9 % у outline.
- **Focus** (`focus`): Кольцо 2 px --focus на кнопке «да» при открытии; Tab ходит по кругу внутри окна.
- **Disabled «да»** (`disabled`): Форма невалидна: «Создать» отключено своими цветами (не прозрачностью); подсказка у поля объясняет, что исправить.
- **Loading** (`loading`): Нажатое «да» с Spinner, «нет» отключена, Esc не работает; окно закроется само, когда операция закончится.
- **Error** (`error`): Плашка err между серединой и подвалом; данные формы сохранены, кнопки снова доступны.

### Не применимы (с причиной)

- **Empty** (`empty`): Нет. Окно без содержимого не открывают; пустой список внутри — пустое состояние в середине.

## Доступность

- **role=dialog и alertdialog** (`aria`): Окно — role="dialog", aria-modal="true", aria-labelledby на заголовок (в макете aria-labelledby нет — добавлено). Для опасного действия предложено role="alertdialog" [TODO]: макет везде ставит dialog.
- **Фокус-ловушка** (`focus`): Tab и Shift+Tab ходят по кругу внутри окна (кнопки, поля); страница под ним недоступна (inert). Окно имеет tabindex=-1, чтобы принять фокус, если фокусируемых элементов нет.
- **Куда идёт фокус при открытии** (`focus`): На главную кнопку («да», у destructive — тоже на красную; [TODO] предложение: безопасную «нет», чтобы Enter не удалял), в форме — на первое поле.
- **Куда фокус возвращается при закрытии** (`focus`): На элемент, открывший окно (запомнен до открытия), в момент начала закрытия. Если он исчез (строку удалили), — на заголовок страницы [TODO].
- **Esc** (`key`): Esc = левая кнопка («нет»), пока нет операции; во время выполнения — игнорируется. Открытый поверх Popover закрывается первым: Esc принадлежит верхнему слою.
- **Enter** (`key`): Нажимает кнопку в фокусе. В форме Enter в поле отправляет форму [TODO] макет не обрабатывает.
- **Контраст** (`contrast`): Текст --text на surface 16,5:1 (тёмная 16,4:1), пояснение --text-2 8,2:1 (11,3:1). Затемнение 45 % на белом даёт границу 3,0:1 между окном и фоном.
- **prefers-reduced-motion** (`motion`): Появление и уход без масштаба и сдвига; затемнение включается мгновенно.

## Хореография

### Открытие (`open`, origin: mockup)

- **Триггер:** нажатие на кнопку, открывающую окно

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Кнопка-источник: hover, затем active, фокус остаётся на ней до открытия. | background | ease |
| 0 | 0 | Запоминается элемент в фокусе. Затемнение и окно вставляются в body (z-index 800); страница под ними получает inert. | — | — |
| 0 | 200 | Затемнение: opacity 0 → 1. | opacity | ease |
| 0 | 300 | Окно: opacity 0 → 1, scale .96 → 1, сдвиг вниз 8 px → 0. | opacity, scale, translate | --ease |
| 0 | 0 | Фокус уходит на главную кнопку (в форме — на первое поле). | focus | — |

- **Фокус:** С кнопки-источника на «да» (в форме — на поле). Дальше Tab ходит по кругу внутри окна.

- **Reduced motion:** Затемнение и окно появляются мгновенно, без масштаба и сдвига.

- **Соседи:** Страница остаётся на месте и не прокручивается [TODO] блокировка прокрутки в макете не сделана. Нижний слой (Sheet тоже 800) остаётся под окном: выше в DOM — выше на экране.

### Закрытие (`close`, origin: mockup)

- **Триггер:** кнопка «нет» / «да» после выполнения / Esc

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Окно снимается со стека, фокус сразу возвращается на кнопку-источник. | focus | — |
| 0 | 200 | Затемнение: opacity 1 → 0. | opacity | ease |
| 0 | 200 | Окно: opacity → 0, scale → .98, сдвиг вниз 4 px. | opacity, scale, translate | ease |
| 200 | 0 | Узлы удаляются из DOM, inert со страницы снят. | — | — |

- **Фокус:** На кнопку, открывшую окно — сразу, не после анимации.

- **Reduced motion:** Мгновенно.

- **Соседи:** Слои под окном (страница, поповеры) возвращаются без анимации.

### «Да» с выполнением (`loading`, origin: mockup)

- **Триггер:** нажатие на «да»

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Слой hover/active у «да». | background | ease |
| 0 | 0 | «Да» получает Spinner и aria-busy, pointer-events отключены; «нет» блокируется; Esc перестаёт работать. | — | — |
| 900 | 0 | Операция закончилась (в макете 0,9 с для подтверждения, 0,7 с для остальных): запускается закрытие. | — | — |

- **Фокус:** Остаётся на «да»: кнопка не disabled, а aria-busy. После закрытия — на источник.

- **Reduced motion:** Spinner замедляется до 3 с на оборот; остальное без переходов.

- **Соседи:** Размер окна не меняется: подпись «Да, сверить» остаётся, добавляется только Spinner.

### Ошибка формы и повтор (`error`, origin: mockup)

- **Триггер:** «Создать» вернула ошибку

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | «Создать» → Spinner, подпись «Создаём»; «Отмена» отключена. | — | — |
| 900 | 0 | Ответ с ошибкой: Spinner уходит, кнопки доступны, между серединой и подвалом появляется плашка err «Не удалось создать груз» с действием «Повторить». Данные формы сохранены. | — | — |
| 900 | 0 | Окно растёт на высоту плашки; середина при необходимости прокручивается. | height | — |
| 1800 | 900 | Повтор: те же 0,9 с с Spinner; на успех окно закрывается. | — | — |

- **Фокус:** Кнопка «Создать» была отключена на время выполнения и потеряла фокус [TODO]: вернуть его на «Создать» или на плашку ошибки.

- **Reduced motion:** Без переходов.

- **Соседи:** Подвал остаётся на месте внизу окна, середина сжимается.

### Слои: список поверх окна (`layers`, origin: mockup)

- **Триггер:** открыт Select/Popover внутри Dialog

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 300 | Dialog z-index 800 над страницей. | z-index | — |
| 1100 | 125 | Popover z-index 900 появляется поверх окна: pop .125 с. | opacity, scale, translate | --ease |
| 2500 | 0 | Esc: закрывается только поповер (Esc принадлежит верхнему слою), окно остаётся. | — | — |
| 3500 | 200 | Второй Esc: закрывается окно (как «нет»). | opacity, scale | ease |

- **Фокус:** Фокус уходит в поповер, при его закрытии возвращается на поле в окне; при закрытии окна — на источник.

- **Reduced motion:** Появление поповера мгновенное.

- **Соседи:** Слои: Dialog 800 < Popover 900 < Tooltip 1000 < Loader 1100 < Toast 1200 (язычок и пузырь агента 810 — над Dialog/Sheet 800, но под Popover).

## Как использовать

Импорт: в ките — `import { Dialog, DialogPanel } from "@/ui"`, в приложении — `import { Dialog, DialogPanel } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { Dialog, DialogPanel } from "@/ui"`. Окно без крестика: «нет» слева, «да» справа, по 50 %.

| Пропс | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `open` | `boolean` | обязателен | Показано ли окно (уход анимируется 200 мс) |
| `onOpenChange` | `(open) => void` | нет | Просьба закрыть: Esc |
| `title` | `ReactNode` | обязателен | Заголовок, он же `aria-labelledby` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Ширина 400 / 520 / 720 px |
| `footer` | `ReactNode` | нет | Кнопки подвала: две `Button` делят ширину поровну |
| `error` | `ReactNode` | нет | Плашка ошибки между телом и подвалом (`Alert`) |
| `flush` | `boolean` | нет | Тело без боковых отступов и зазоров (списки, журналы) |
| `role` | `"dialog" \| "alertdialog"` | `"dialog"` | `alertdialog` для опасного действия |
| `busy` | `boolean` | нет | Идёт операция: Esc игнорируется, `aria-busy` |
| `container` | `HTMLElement \| null` | `document.body` | Куда вставлять окно; не `body` — без блокировки прокрутки |

Остальные атрибуты, `className`, `ref` — на окно. `DialogPanel` — само окно без затемнения и поведения (для превью и своих оболочек).

```tsx
<Dialog open={open} onOpenChange={setOpen} size="sm" title="Сверить документы?"
  footer={<><Button variant="outline" onClick={() => setOpen(false)}>Нет</Button>
            <Button loading={busy} onClick={run}>Да, сверить</Button></>}>
  Сравним вес, код ТН ВЭД и номера по 128 грузам.
</Dialog>
```

Поведение в компоненте: страница под окном получает `inert`, прокрутка `body` блокируется; фокус уходит на `[data-autofocus]`, иначе на первое поле, иначе на главную кнопку; Tab и Shift+Tab ходят по кругу; Esc закрывает только верхний слой (поверх окна `Popover` и вложенный `Dialog`); при закрытии фокус сразу возвращается на кнопку-источник. Хуки `useModal`, `useLayer`, `usePresence` и `trapTab`, `getFocusable` экспортируются для своих окон.

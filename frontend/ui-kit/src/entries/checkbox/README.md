# Checkbox

Флажок для выбора нескольких вариантов, с неполным состоянием для групп и карточками-флажками.

Checkbox отвечает «да / нет» в форме или выбирает несколько пунктов из списка. Значение применяется после отправки формы, а не сразу. Для настройки, которая действует сразу, берите Switch; для одного варианта из нескольких Radio.

- **id:** `checkbox`
- **Группа:** Поля (`fields`)
- **CSS-префикс:** `ds-check`
- **Origin хореографии:** mockup (2), proposal (1)

## Когда использовать / не использовать

### Использовать

- Несколько независимых вариантов в форме, значения применяются после отправки.
- Группа с «выбрать все» из пяти и более пунктов.
- Подпись всегда рядом и нажимается: вся строка — label.
- Пояснение мелким текстом — когда подписи недостаточно.
- Карточки-флажки, если у каждого варианта есть описание.

### Не использовать

- Настройка, которая действует сразу: это Switch.
- Один вариант из нескольких: это Radio или ToggleGroup.
- Флажок без подписи (кроме строки таблицы с aria-label).
- Неполное состояние у одиночного флажка: оно только у родителя группы.
- Отрицательные формулировки: «Не отправлять уведомления» запутывает.

## Анатомия

1. **Пункт** — Строка из флажка и подписи, зазор 10. Нажимается вся строка (label), не только квадрат.
2. **Флажок** — 16×16 px, рамка 1,5px, радиус 4. Выбран: заливка --primary и галочка 8×4; неполный: тире 8×2. Выравнен по первой строке подписи (отступ сверху 2px).
3. **Подпись и пояснение** (необязательная) — Подпись 13 px; пояснение 11 px --text-3 в строку ниже. При ошибке пояснение — текст ошибки, --err-text.

## Варианты

- **Один флажок** (`single`): Флажок с подписью. Пояснение и ошибка — под подписью. Когда: согласие, «запомнить», один параметр формы.
- **Группа с «выбрать все»** (`group`): Родитель отражает вложенные: пусто, неполный, выбрано всё. Вложенные сдвинуты на 26 px. Когда: список документов, колонок, получателей, где часто нужно взять все сразу.
- **Карточки-флажки** (`cards`): Каждый вариант в карточке с заголовком и пояснением. Выбранная получает подложку --selected и кольцо --border-selected. Когда: несколько каналов или тарифных опций, где вариантам нужно описание.
- **С ошибкой** (`error`): Рамка --danger и текст ошибки под подписью. Когда: обязательное подтверждение, которое не поставили при отправке.

## Состояния

### Применимые

- **Обычный** (`default`): Рамка 1,5px --text-3, фон --field.
- **Hover** (`hover`): Рамка темнеет до --text.
- **Focus** (`focus`): Кольцо 2px --focus с отступом 2px, только от клавиатуры. У карточки кольцо вокруг всей карточки.
- **Выбран** (`selected`, `checked`): Заливка и рамка --primary, галочка --on-primary 8×4.
- **Неполный** (`other`, `indeterminate`): Тире 8×2 вместо галочки. Состояние только у родителя группы, ставится через свойство indeterminate.
- **Ошибка** (`error`): aria-invalid=true: рамка --danger; у выбранного заливка --danger. Текст ошибки — под подписью, --err-text.
- **Disabled** (`disabled`): Фон --tone, рамка --divider; подпись --text-ph.
- **Disabled выбранный** (`disabled`, `disabled-checked`): Фон --tone, метка --text-ph. [TODO] в макете метка navy на сером (в тёмной теме не видна); здесь как у Radio, подтвердить.

### Не применимы (с причиной)

- **Active** (`active`): Отдельного вида нет: нажатие сразу меняет значение. [TODO] решить, нужен ли слой на время нажатия.
- **Loading** (`loading`): Нет: флажок в форме не ходит на сервер. Если выбор применяется сразу и долго, нужен Switch с оптимистичным обновлением. [TODO] подтвердить.
- **Empty** (`empty`): Нет: флажок всегда в одном из состояний «пусто / выбрано / неполный». «Пустой» — это обычный.

## Доступность

- **Нативный checkbox** (`aria`): <input type=checkbox> с label. Для неполного состояния ставится свойство indeterminate (aria-checked=mixed браузер выставит сам); атрибутом оно не задаётся.
- **Space** (`key`): Переключает флажок. Tab и Shift+Tab ходят по флажкам; стрелки не нужны (это не группа выбора).
- **Ошибка** (`aria`): aria-invalid="true" на input и aria-describedby на элемент с текстом ошибки; одного цвета рамки недостаточно.
- **Группа** (`aria`): Контейнер role="group" с aria-label или fieldset/legend; у родителя «выбрать все» собственное имя.
- **Кольцо** (`focus`): 2px --focus, отступ 2px (3,65:1 на белом, 9,34:1 в тёмной). [TODO] в макете у настоящего :focus-visible отступ 0 (общее правило), у принудительного is-focus 2px; здесь везде 2px.
- **Рамка и заливка** (`contrast`): Рамка --text-3 на --field: 4,9:1 (светлая), 8,1:1 (тёмная). Галочка navy на teal 7,4:1. Рамка ошибки --danger на белом 4,9:1. Disabled-рамка --divider: вне нормы для недоступных.
- **Подпись и пояснение** (`contrast`): Подпись --text 16,5:1; пояснение --text-3 4,9:1 (светлая) и 7,6:1 (тёмная); текст ошибки --err-text 5,5:1 и 7,8:1.
- **prefers-reduced-motion** (`motion`): Переходы цвета флажка и карточки отключаются.

## Хореография

### Установка флажка (`check`, origin: mockup)

- **Триггер:** клик по флажку или подписи

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение: рамка --text-3 → --text. | border-color | ease |
| 700 | 125 | Клик: заливка и рамка идут к --primary. | background, border-color | ease |
| 700 | 0 | Галочка (псевдоэлемент ::after) появляется сразу, без прорисовки: в макете у неё нет перехода. Снятие флажка — обратный порядок: заливка уходит за 125 мс, галочка исчезает сразу. | content | — |

- **Фокус:** Остаётся на флажке. Клик по подписи ставит фокус на input.

- **Reduced motion:** Переход цвета отключён; заливка и галочка появляются мгновенно.

- **Соседи:** Размер флажка не меняется, соседние пункты не затрагиваются.

### «Выбрать все» и неполное состояние (`group`, origin: mockup)

- **Триггер:** клик по вложенному пункту или по родителю

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Клик по вложенному: его флажок заливается; родитель получает indeterminate (тире) и счётчик «Выбрано N из M» обновляется текстом. | background, border-color | ease |
| 800 | 125 | Выбраны все вложенные: родитель переходит из тире в галочку. | background, border-color | ease |
| 1600 | 125 | Клик по родителю: выбираются или снимаются все вложенные одним действием; из неполного состояния клик выбирает все. | background, border-color | ease |

- **Фокус:** Остаётся на нажатом флажке; Tab идёт по пунктам по порядку, родитель первый.

- **Reduced motion:** Переходы цвета отключены, значки меняются мгновенно.

- **Соседи:** Строка счётчика меняет только текст, высота остаётся. Список вложенных не сворачивается и не двигается.

### Ошибка обязательного флажка (`error`, origin: proposal)

- **Триггер:** попытка отправить форму без обязательного флажка

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Рамка идёт к --danger, aria-invalid=true. | border-color | ease |
| 0 | 0 | Под подписью появляется текст ошибки --err-text (без анимации высоты: место под пояснение зарезервировано). | — | — |
| 1200 | 125 | Флажок поставлен: рамка и заливка уходят к --primary, ошибка исчезает. | background, border-color | ease |

- **Фокус:** При отправке фокус переходит к первому полю с ошибкой; для флажка это сам флажок. Текст ошибки связан через aria-describedby. [TODO] в макете сценария отправки нет.

- **Reduced motion:** Рамка меняет цвет мгновенно.

- **Соседи:** Если текст ошибки добавляется без резерва места, форма ниже сдвигается на строку; решение (резерв или сдвиг) нужно подтвердить.

## Примеры

### Параметры сверки (`options`)

```tsx
<Checkbox checked={weight} onCheckedChange={setWeight} hint="Накладная, декларация и инвойс">Сверять вес</Checkbox>
```

### Выбрать все документы (`all`)

```tsx
<CheckboxGroup label="Документы для сверки" value={docs} onValueChange={setDocs} selectAll>…</CheckboxGroup>
```

## Как использовать

Импорт: в ките — `import { Checkbox, CheckboxGroup } from "@/ui"`, в приложении — `import { Checkbox, CheckboxGroup } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компоненты `Checkbox` (`<input type="checkbox">`) и `CheckboxGroup` (`<div role="group">`). Типы: `CheckboxProps`, `CheckboxVariant`, `CheckboxGroupProps`.

```tsx
import { Checkbox, CheckboxGroup } from "@/ui";
```

Пропсы `Checkbox` (плюс атрибуты `<input>`: `name`, `value`, `disabled`, `aria-*`, `ref` — всё попадает на `input`):

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `children` | `ReactNode` | нет | Подпись. С подписью или `hint` флажок оборачивается в `<label>`, `className` попадает на неё; без них нужен `aria-label`. |
| `hint` | `ReactNode` | нет | Пояснение под подписью; при `invalid` красное, связано через `aria-describedby`. |
| `variant` | `"plain" \| "card"` | `"plain"` | `card` — карточка-флажок с заголовком `<b>`. |
| `checked` / `defaultChecked` | `boolean` | `false` | Управляемое и начальное значение. |
| `onCheckedChange` | `(checked: boolean) => void` | нет | Вызывается с новым значением; нативный `onChange` тоже работает. |
| `indeterminate` | `boolean` | нет | Неполное состояние (тире); выставляется свойством DOM, снимается первым кликом. |
| `invalid` | `boolean` | нет | `aria-invalid`, рамка `--danger`. |

Пропсы `CheckboxGroup` (плюс атрибуты `<div>`):

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `label` | `string` | — | Название группы (`aria-label`, заголовок при `selectAll`). |
| `value` / `defaultValue` | `string[]` | `[]` | Выбранные значения (`value` у вложенных `Checkbox`). |
| `onValueChange` | `(value: string[]) => void` | нет | Новый набор выбранных. |
| `selectAll` | `boolean` | нет | Родительский флажок «выбрать все» с неполным состоянием и счётчиком. Считает прямых детей `Checkbox` с `value`; недоступные пропускает. |
| `selectAllLabel` | `string` | `"Выбрать все"` | `aria-label` родительского флажка. |

```tsx
<Checkbox checked={weight} onCheckedChange={setWeight} hint="Накладная, декларация и инвойс">
  Сверять вес
</Checkbox>

<Checkbox invalid hint="Нужно подтвердить, чтобы отправить">Я подтверждаю данные декларации</Checkbox>

<CheckboxGroup label="Документы для сверки" value={docs} onValueChange={setDocs} selectAll>
  <Checkbox value="waybill">Накладная</Checkbox>
  <Checkbox value="declaration">Декларация</Checkbox>
</CheckboxGroup>
```

Доступность:

- Нативный checkbox: Space переключает, Tab ходит по флажкам.
- Ошибка — `aria-invalid="true"` и `aria-describedby` на текст; одного цвета рамки мало.
- Группа — `role="group"` с `aria-label`; у родителя «выбрать все» своё имя.
- Переходы цвета отключаются при `prefers-reduced-motion`.

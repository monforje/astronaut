# Card

Поверхность для группы связанного содержимого: заголовок, значение или текст, подвал с кнопками. Пять видов, два размера, кликабельная и выбранная.

Карточка собирает один смысл: плитку KPI, расхождение, раздел. Граница — кольцо 1px поверх содержимого, поэтому она видна по бокам в обеих темах. Тон выражается значком в заголовке, а не цветной полосой слева. Две кнопки в подвале всегда делят ширину пополам.

- **id:** `card`
- **Группа:** Данные (`data`)
- **CSS-префикс:** `ds-card`
- **Origin хореографии:** mockup (3), proposal (2)

## Когда использовать / не использовать

### Использовать

- Граница — кольцо ::after на всю длину: видно по бокам в светлой и тёмной теме.
- Тон — значок заголовка (ok, warn, err); заливку тоном даёт только solid.
- Две кнопки в карточке: 50/50 по ширине, главная слева. Одна — по размеру содержимого.
- Числа и ID в Onest с tabular-nums.
- Кликабельная — вся карточка, без вложенных кнопок.
- Filled — для плиток внутри карточки, где кольцо дало бы двойную рамку.

### Не использовать

- Цветная полоса слева или сверху как акцент.
- Моноширинный шрифт у цифр и номеров контейнеров.
- Кнопки в кликабельной карточке: два действия на одну область.
- Больше одной solid-карточки на экран.
- Тень вместо кольца: тема тёмная, тень не видна.
- Прозрачность для disabled: свои цвета (--surface-muted, --text-ph).

## Анатомия

1. **Контейнер** — Поле 24 (16 в sm), радиус 14 (10 в sm), gap 16 (12). Кольцо рисует ::after со z-index 3, поверх фона и потомков.
2. **Заголовок** (необязательная) — Значок 16 цветом тона, название 15/700 (13 в sm), справа действия. Тон значка: ok · warn · err.
3. **Действие в шапке** (необязательная) — Ghost-кнопка 24 «⋯» или Delta (в KPI).
4. **Значение** (необязательная) — 30/700 (22 в sm), Onest tabular-nums; не Fira Code.
5. **Подвал** (необязательная) — Линия --divider сверху, отступ 12. Одна кнопка — по размеру; две — 50/50, главная слева.

## Варианты

- **Outline** (`outline`): Основная карточка: кольцо 1px, без тени, поле 24, радиус 14. Когда: по умолчанию: блоки страницы, плитки, панели.
- **Elevated** (`elevated`): Кольцо и лёгкая тень --shadow-panel. Когда: плавающие блоки поверх подложки.
- **Filled** (`filled`): Подложка --surface-muted без кольца. Когда: плитки внутри другой карточки (например KPI в Sparkline-блоке).
- **Ghost** (`ghost`): Без подложки и кольца: только раскладка карточки. Когда: группировка внутри карточки или на странице.
- **Solid** (`solid`): Заливка --primary, текст navy. Одна на экран, как главная кнопка. Когда: один главный итог страницы: «5 из 6 программ подключено».
- **Кликабельная** (`link`): Вся карточка — переход: курсор pointer, tabindex 0, значок «›» справа. Есть hover, active, focus. Когда: переход в раздел или объект без отдельной кнопки.
- **Выбрана** (`selected`): Подложка --selected, кольцо --border-selected, значок-галочка. Когда: выбор одного из нескольких: тариф, шаблон.
- **Без полей (flush)** (`flush`): Padding 0, overflow clip; шапка 44 + тело 14. Для таблиц, списков и графиков. Когда: DataTable, список, график: содержимое доходит до кромки, кольцо остаётся поверх.
- **KPI-карточка** (`kpi`): Sm: значок, подпись (500, text-2), Delta справа; число 22/700; Sparkline 34; пояснение. Hover — подъём на 1 px. Когда: сводка в начале экрана: 4 плитки в ряд.
- **С двумя кнопками** (`two-buttons`): Подвал: главная и вторая 50/50 по ширине, главная слева. Тон err у значка заголовка. Когда: решение по объекту: «Исправить» и «Позже».

## Состояния

### Применимые

- **Default** (`default`): Кольцо 1px --border, фон --surface.
- **Hover** (`hover`): Слой ink 4 % и кольцо темнее (--text-3). Только у кликабельной.
- **Active** (`active`): Слой 7 % и сдвиг вниз на 1 px.
- **Focus** (`focus`): Контур 2px --focus с отступом 2px: кольцо карточки остаётся видно.
- **Selected** (`selected`): Подложка --selected и кольцо --border-selected; значок-галочка. aria-current.
- **Disabled** (`disabled`): Предложение: фон --surface-muted, текст --text-ph, без hover; свои цвета, не прозрачность. В макете не показано. [TODO]
- **Loading** (`loading`): Сохраняется оболочка и кнопки подвала; содержимое — Skeleton тех же размеров.
- **Empty** (`empty`): Предложение: заголовок остаётся, в теле одна строка «Данных пока нет» и действие. [TODO] тексты.
- **Error** (`error`): Тон err значка заголовка: «Тон значка: ошибка». Заливки тоном нет, только solid.

## Доступность

- **Кликабельная карточка** (`aria`): Переход — настоящая ссылка внутри карточки с растянутой областью клика либо role="link" на контейнере; в демо role="link", tabindex=0. Название — из заголовка (aria-label, если заголовка нет).
- **Enter** (`key`): Активирует кликабельную карточку. Space у ссылки не работает; для карточки-выбора (aria-current) допустим Space.
- **aria-current / aria-disabled** (`aria`): Выбранная — aria-current=true; недоступная — aria-disabled=true и выходит из Tab.
- **Контур 2px с отступом 2px** (`focus`): Контур вне кольца: кольцо 1px остаётся читаемым. Цвет --focus: светлая #00968f, тёмная teal.
- **Кольцо** (`contrast`): --border на --surface: светлая 1,6:1, тёмная 2,5:1 — ниже 3:1 для границы компонента. Граница выручает за счёт того, что карточка ещё и отличается фоном от --page. [TODO] решить: поднять --border или принять как есть (в макете «контраст линий поднят» уже сделан).
- **Solid** (`contrast`): Navy на teal ≈ 8,9:1. Приглушённая подпись (navy 75 %) ≈ 4,3:1 — ниже 4,5:1 для 13px. [TODO] использовать полный navy для подписей solid-карточки.
- **prefers-reduced-motion** (`motion`): Сдвиг на 1px при active, подъём KPI и переходы слоёв отключаются; волна Skeleton гаснет.

## Хореография

### Наведение и нажатие кликабельной карточки (`hover-press`, origin: mockup)

- **Триггер:** указатель входит и нажимает; Enter на фокусе

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Hover: фон темнеет на 4 %, кольцо переходит от --border к --text-3. | background, box-shadow (::after) | ease |
| 1000 | 125 | Нажатие: фон 7 %. | background | ease |
| 1000 | 200 | Карточка опускается на 1 px. | translate | ease |
| 1300 | 200 | Отпускание: возврат в hover, затем действие (переход). | translate, background | ease |
| 2100 | 125 | Указатель ушёл: слой и кольцо возвращаются. | background, box-shadow | ease |

- **Фокус:** Фокус клавиатурой даёт контур 2px --focus с отступом 2px; кольцо карточки остаётся. Enter ведёт себя как клик.

- **Reduced motion:** Переходы 125 мс и сдвиг 1px отключаются: слои меняются мгновенно, сдвига нет.

- **Соседи:** Сдвиг 1px — собственный (translate), соседи не двигаются: место в сетке не меняется.

### Выбор карточки (`select`, origin: proposal)

- **Триггер:** клик или Enter / Space по карточке-варианту

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Фон и кольцо идут к --selected и --border-selected, как у выбранной строки таблицы. | background, box-shadow | ease |
| 0 | 0 | Значок заменяется галочкой, aria-current=true. У предыдущей выбранной карточки обратный переход. | icon | — |

- **Фокус:** Фокус остаётся на карточке.

- **Reduced motion:** Цвета меняются мгновенно.

- **Соседи:** Размеры не меняются: рамка одинаковой толщины, содержимое не прыгает.

### KPI: заглушка → данные (`kpi-load`, origin: proposal)

- **Триггер:** данные плитки пришли

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 1300 | Skeleton с теми же габаритами: подпись, число, график, пояснение. Волна 1,4 с. | translate (::after) | ease-in-out |
| 1300 | 200 | Содержимое проявляется на месте заглушки, без сдвига высоты. | opacity | ease |
| 1300 | 700 | Sparkline рисуется слева направо (см. Chart). | stroke-dashoffset | --ease |

- **Фокус:** Фокус не теряется: у KPI-плитки интерактивных элементов нет.

- **Reduced motion:** Волна выключена (статичная заглушка), данные появляются без проявления.

- **Соседи:** Размеры плитки заданы заранее: соседние плитки не прыгают.

### Подъём KPI-плитки (`kpi-hover`, origin: mockup)

- **Триггер:** указатель над KPI-плиткой

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 200 | Плитка поднимается на 1 px. | translate | ease |
| 1200 | 200 | Указатель ушёл: возврат на место. | translate | ease |

- **Фокус:** У плитки нет фокуса. Если она кликабельная, действуют правила кликабельной карточки.

- **Reduced motion:** Подъём отключён.

- **Соседи:** translate не меняет раскладку: соседние плитки на месте.

### Две кнопки в подвале (`two-buttons`, origin: mockup)

- **Триггер:** наведение и нажатие на кнопку подвала

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Hover главной кнопки: слой по правилам Button. Ширина обеих кнопок равна, ничего не меняется. | background (кнопки) | ease |
| 800 | 125 | Нажатие: слой active. | background (кнопки) | ease |

- **Фокус:** Tab идёт слева направо: главная, вторая. Контур 2px у кнопки, не у карточки.

- **Reduced motion:** Переходы слоя кнопок отключаются.

- **Соседи:** Карточка не реагирует: она не кликабельная; у кликабельной карточки кнопки внутри не ставят.

## Как использовать

Импорт: в ките — `import { Card, CardBar, CardBody, CardFooter, CardHeader, KpiCard } from "@/ui"`, в приложении — `import { Card, CardBar, CardBody, CardFooter, CardHeader, KpiCard } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компоненты: `Card` (контейнер), части `CardHeader`, `CardFooter`, `CardBar` (плашка заголовка для карточки без полей), `CardBody`, и готовая плитка `KpiCard` (внутри `Delta` и `Sparkline` из `Chart`). Типы: `CardProps`, `CardVariant`, `CardTone`, `CardElement`, `CardHeaderProps`, `CardFooterProps`, `CardBarProps`, `KpiCardProps`.

```tsx
import { Card, CardHeader, CardFooter, KpiCard } from "@/ui";
```

Пропсы `Card` (плюс атрибуты `<div>`: `aria-*`, `data-*`, `onClick`, `ref`, `className`):

| Проп          | Тип                                                          | По умолчанию | Описание                                                                                   |
| ------------- | ------------------------------------------------------------ | ------------ | ------------------------------------------------------------------------------------------ |
| `as`          | `"div" \| "article" \| "section"`                            | `"div"`      | Тег корня.                                                                                 |
| `variant`     | `"outline" \| "elevated" \| "filled" \| "ghost" \| "solid"`  | `"outline"`  | Вид.                                                                                       |
| `size`        | `"md" \| "sm"`                                               | `"md"`       | `sm` — поле 16 и радиус карточки (плитки, решения).                                        |
| `flush`       | `boolean`                                                    | нет          | Без полей, содержимое доходит до кромки (таблицы, графики).                                |
| `interactive` | `boolean`                                                    | нет          | Кликабельная: `role="link"`, `tabindex=0`, Enter вызывает `onClick`; hover и active слои.  |
| `selected`    | `boolean`                                                    | нет          | Выбранная: `aria-current="true"`, фон и кольцо выбора.                                     |
| `disabled`    | `boolean`                                                    | нет          | `aria-disabled`, выходит из Tab, не реагирует на клик.                                     |
| `kpi`         | `boolean`                                                    | нет          | При наведении поднимается на 1 px.                                                         |
| `tone`        | `"ok" \| "warn" \| "err"`                                    | нет          | Цвет значка в заголовке.                                                                   |

`CardHeader`: `icon: ReactNode` (скрыт от скринридера), `muted`, `action: ReactNode` (кнопка или Delta справа). `CardFooter`: `two` (две кнопки 50/50). `CardBar`: `sub` (серое пояснение).

`KpiCard`: `label`, `value`, `icon`, `delta` + `deltaTone` (`good` по умолчанию) + `deltaDir`, `data` (числа для Sparkline), `sparkColor`, `note`, `tone`.

```tsx
<Card size="sm" tone="err">
  <CardHeader icon={<Icon name="warn" />}>Расхождение по весу</CardHeader>
  <p>Вес в декларации меньше веса по накладной на 180 кг.</p>
  <CardFooter two>
    <Button size="sm">Исправить</Button>
    <Button size="sm" variant="outline">Позже</Button>
  </CardFooter>
</Card>

<Card interactive size="sm" aria-label="Открыть раздел «Грузы»" onClick={openCargo}>…</Card>

<KpiCard icon={<Icon name="box" />} label="Грузов за месяц" value="412"
  delta="+8,4%" deltaDir="up" data={weekly} note="к октябрю: 380" />
```

Доступность:

- Кликабельная карточка — `role="link"` на контейнере (лучше — настоящая ссылка внутри); название из заголовка или `aria-label`. Активируется Enter, на вложенных контролах Enter не перехватывается.
- `selected` даёт `aria-current`, `disabled` — `aria-disabled` и убирает из Tab.
- Фокусное кольцо — по `:focus-visible`. Принудительных состояний (`force`) у компонента нет.

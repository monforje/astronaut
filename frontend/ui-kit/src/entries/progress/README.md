# Progress

Линейный прогресс: полоса с подписью и значением. Тона, неопределённый режим, круговой и сегментный вид, строка загрузки файла и кнопка-прогресс.

Прогресс отвечает «сколько уже». Он нужен, когда у операции есть длина: сверка 128 грузов, загрузка файлов, лимит запросов. Если длины нет — Spinner или неопределённая полоса. Полоса всегда с подписью и числом: цвет и длина смысл не передают.

- **id:** `progress`
- **Группа:** Обратная связь (`feedback`)
- **CSS-префикс:** `ds-progress`
- **Origin хореографии:** mockup (1), proposal (2)

## Когда использовать / не использовать

### Использовать

- Подпись и число всегда рядом с полосой: «58 из 79», а не только длина.
- Тон по смыслу: info для фона, warn при 80–95 %, err при исчерпании.
- Для известной малой серии шагов берите сегменты, для хода работы — линейную полосу.
- После 100 % замените полосу результатом: тост «Файлы загружены».
- Неопределённую полосу переведите в обычную, как только появится размер работы.

### Не использовать

- Полоса без числа и подписи: цвет и длина не читаются скринридером.
- Фальшивый прогресс, который не связан с работой: лучше Spinner.
- Прогресс назад: если значение уменьшилось, перезапустите полосу, а не анимируйте откат.
- Больше двух полос с полосками на экране: они отвлекают.
- Красная полоса без объяснения: рядом пишут, что случилось.

## Анатомия

1. **Подпись** — Слева над полосой, --text-2, 12 px: что считаем («Позиции с ценой»).
2. **Значение** — Справа, 600, цифры табличные: «58 из 79», «91%». У неопределённой — «неопределённо» или статус.
3. **Трек** — Фон полосы --tone (слой 7 %), радиус pill. Высота 4 (sm) / 8 (md) / 12 px (lg).
4. **Заливка** — Цвет тона, радиус как у трека, ширина = значение; растёт за 0,35 с.
5. **Полоски** (необязательная) — Диагональные полоски на заливке, бегущие вправо: «работа идёт»; для долгих процессов.

## Варианты

- **Линейный** (`linear`): Подпись, значение и полоса 8 px. Когда: известно, сколько сделано: позиции, документы, шаги.
- **Тоны** (`tones`): primary по умолчанию; info — фоновый процесс; warn — лимит близко; err — лимит исчерпан; idle — не активен. Когда: вместе с числом: цвет усиливает смысл, но не заменяет его.
- **Неопределённый** (`indeterminate`): Отрезок 38 % едет слева направо за 1,3 с, значение «неопределённо». Когда: размер работы неизвестен: «Идёт синхронизация…».
- **С полосками** (`striped`): Заливка с бегущими диагональными полосками, 1 с на период. Когда: долгая операция с известным процентом: сверка, импорт.
- **Круговой** (`circle`): Кольцо 56 px, число в центре. Когда: сводка на карточке: квота, готовность.
- **Сегменты** (`segments`): Равные отрезки по 6 px: шаги внутри списка. Ошибочный шаг — красный. Когда: известное малое число этапов (3–6): документы, таможня, оплата.
- **Файл загружается** (`file`): Строка файла: тип, имя, статус и тонкая полоса sm. Когда: список загрузок: у каждого файла свой процент.
- **Кнопка-прогресс** (`button`): Кнопка, внутри которой растёт заливка; подпись «Сверяем · 34%». [TODO] в макете нет, предложено словарём. Когда: одна операция запущена с этой кнопки и важно видеть её ход на месте.

## Состояния

### Применимые

- **Идёт** (`default`): Значение между 0 и 100, заливка цвета тона.
- **Неопределённый** (`loading`): Размер неизвестен: aria-valuenow нет, отрезок едет.
- **0 %** (`empty`): Операция запущена, ничего не сделано: пустой трек. Не скрывайте полосу.
- **100 %** (`selected`, `done`): Полная полоса. Через секунду её заменяют итогом (тост, значок), оставлять 100 % не нужно.
- **Ошибка** (`error`): Тон err: заливка красная, значение остановилось. Рядом — причина и «Повторить».
- **Кнопка · hover** (`hover`, `button-hover`): Слой 6 % поверх фона кнопки; у кнопки в работе hover отключён (aria-busy).
- **Кнопка · focus** (`focus`, `button-focus`): Кольцо 2 px --focus.
- **Кнопка · active** (`active`, `button-active`): Слой 9 %.

### Не применимы (с причиной)

- **Полоса · hover** (`hover`): Полоса не интерактивна. Для нажимаемого вида — кнопка-прогресс.
- **Disabled** (`disabled`): Нет. «Не активен» выражает тон idle (серая заливка).

## Доступность

- **role=progressbar** (`aria`): Трек: role="progressbar", aria-valuemin 0, aria-valuemax 100, aria-valuenow, aria-label из подписи. Для неопределённой aria-valuenow не ставят.
- **aria-valuetext** (`aria`): Человеческая фраза: «58 из 79», «выполняется». Скринридер читает её вместо процента.
- **Обновления** (`aria`): Не объявляйте каждый процент. Итог («Сверка завершена») отдайте в aria-live=polite области; у кнопки-прогресса обновляйте aria-label не чаще раза в пять секунд [TODO] подтвердить частоту.
- **Клавиатура** (`key`): Полоса не фокусируется. Кнопка-прогресс — обычная кнопка: Enter и Space запускают, во время работы нажатие игнорируется (aria-busy, не disabled).
- **Заливка на треке (3:1 для графики)** (`contrast`): Светлая тема: teal на треке 1,6:1 и orange 1,9:1 — ниже 3:1; danger 3,7:1; info 4,5:1; idle 4,3:1. Тёмная: все выше 5:1. - **prefers-reduced-motion** (`motion`): Рост заливки и полоски отключаются; неопределённый отрезок стоит на месте и не едет (смысл «идёт» передаёт подпись).

## Хореография

### Ход операции (`run`, origin: mockup)

- **Триггер:** приходит новое значение от процесса

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 350 | Ширина заливки идёт к новому значению, значение справа меняется сразу. | width | --ease |
| 0 | 1000 | Полоски (если включены) бегут вправо непрерывно, период 40 px за 1 с. | background-position | linear |
| 4100 | 350 | 100 %: полоски останавливаются, значение «100%». [TODO] макет это не оговаривает: предложено через секунду заменить полосу итогом. | — | — |

- **Фокус:** Не затрагивается: полоса не фокусируется.

- **Reduced motion:** Заливка встаёт мгновенно, полоски стоят.

- **Соседи:** Высота полосы фиксирована, соседний текст не прыгает. Ширина значения табличная, число не дёргает подпись.

### Неопределённая → определённая (`indeterminate`, origin: proposal)

- **Триггер:** размер работы неизвестен, затем стал известен

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 1300 | Отрезок 38 % едет с −100 % до 270 % своей ширины и по кругу. | translate | ease-in-out |
| 2800 | 0 | Размер известен: бегущий отрезок заменяется обычной заливкой, aria-valuenow появляется. | width | --ease |
| 3600 | 350 | Заливка растёт до 100 %. | width | --ease |

- **Фокус:** Не затрагивается.

- **Reduced motion:** Отрезок стоит на месте, значение «неопределённо» остаётся в подписи.

- **Соседи:** Подпись и значение не двигаются.

### Кнопка-прогресс (`button`, origin: proposal)

- **Триггер:** нажатие «Сверить документы»

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Кнопка получает aria-busy, слева — Spinner 10 px, подпись «Сверяем · 3%», hover отключён. | — | — |
| 600 | 350 | Заливка внутри кнопки растёт слева направо вместе со значением. | width (::before) | --ease |
| 2500 | 125 | 100 %: кнопка заливается primary, спиннер уходит, слева ✓, подпись «Сверено». | background, color | ease |

- **Фокус:** Фокус остаётся на кнопке (aria-busy, не disabled). После завершения остаётся там же.

- **Reduced motion:** Заливка и смена цвета мгновенные.

- **Соседи:** Ширина кнопки фиксирована (min-width 168 px), смена подписи не двигает соседей.

## Как использовать

Импорт: в ките — `import { Progress, ProgressCircle, ProgressSegments, ProgressButton } from "@/ui"`, в приложении — `import { Progress, ProgressCircle, ProgressSegments, ProgressButton } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { Progress, ProgressCircle, ProgressSegments, ProgressButton } from "@/ui"`.

| Компонент и пропс | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `Progress.label` | `string` | обязателен | Подпись слева и `aria-label` полосы |
| `Progress.value` | `number` | `0` | 0-100, значение зажимается |
| `Progress.valueText` | `string` | `"N%"` | Текст справа и `aria-valuetext` («58 из 79») |
| `Progress.tone` | `"primary" \| "info" \| "warn" \| "err" \| "idle"` | `"primary"` | Цвет заливки |
| `Progress.size` | `"sm" \| "md" \| "lg"` | `"md"` | Толщина |
| `Progress.indeterminate` | `boolean` | нет | Бегущая полоса, без `aria-valuenow` |
| `Progress.striped` | `boolean` | нет | Движущиеся полоски: идёт обработка |
| `Progress.bare` | `boolean` | нет | Без шапки, только полоса (в строках списков) |
| `ProgressCircle` | `value`, `label`, `tone` (`primary`/`info`/`warn`) | — | Кольцо с процентом в центре |
| `ProgressSegments` | `total`, `value`, `error?`, `label` | — | Дискретные шаги; `error` — номер шага с ошибкой |
| `ProgressButton` | `value`, `status` (`running`/`done`/`err`), `children` | — | Кнопка-заливка: в `running` клик гасится, `aria-busy` |

Остальные атрибуты уходят на корневой элемент; `ref` — обычный проп.

```tsx
<Progress label="Сверено документов" value={91} size="lg" />
<Progress label="Лимит запросов к 1С" value={86} tone="warn" valueText="86 из 100" />
<ProgressButton status="running" value={34}>Сверяем · 34%</ProgressButton>
```

Доступность: каждая полоса — `role="progressbar"` с `aria-valuemin/max/now`, у неопределённой нет `aria-valuenow`, а `aria-valuetext` — «выполняется». Текст рядом с полосой не дублируйте вторым `aria-live`. Кнопка в `running` не `disabled`: фокус остаётся на ней.

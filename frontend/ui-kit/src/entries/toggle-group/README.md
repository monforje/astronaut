# ToggleGroup

Сегментированный выбор одного варианта из нескольких. Плашка под выбранным пунктом переезжает при смене.

ToggleGroup меняет вид или фильтр одной строкой: «Список / Таблица / Дерево», «День / Неделя / Месяц», «Все / Сверено / Расхождения». Выбор применяется сразу и всегда один. Для двух независимых флажков берите Toggle, для длинного списка (больше пяти) Select.

- **id:** `toggle-group`
- **Группа:** Действия (`actions`)
- **CSS-префикс:** `ds-tgroup`
- **Origin хореографии:** mockup (1), proposal (1)

## Когда использовать / не использовать

### Использовать

- Один вариант из двух-пяти, когда все видны сразу и выбор применяется сразу.
- Короткие подписи, одно слово: «Список», «Неделя».
- Всегда выбран ровно один пункт; значение по умолчанию задавайте явно.
- Недоступный вариант оставляйте в ряду (disabled), а не прячьте.
- block — когда группа лежит в узкой панели.

### Не использовать

- Несколько вариантов одновременно: это ряд Toggle или Checkbox.
- Длинный список или длинные подписи: это Select.
- Переход между страницами: это Tabs, у вкладок другая семантика и индикатор.
- Выбор, который нужно подтвердить кнопкой: в форме берите Radio.
- Больше пяти пунктов в ряд: трек не помещается, горизонтального скролла у него нет.

## Анатомия

1. **Трек** — Подложка --surface-muted, радиус 8, кольцо 1px --divider, внутренний отступ 2px, зазор между пунктами 2px. Строчный по ширине содержимого или block на всю ширину.
2. **Плашка (thumb)** — Абсолютный слой под выбранным пунктом: --surface, тень --shadow-panel, кольцо --border, радиус 6. Положение и ширина задаются translate и width, и анимируются.
3. **Пункт** — Кнопка role=radio высотой 26 px (22 в sm), padding 0 12, подпись 600, 12 px. Выбранный — --text, остальные — --text-2.
4. **Значок** (необязательная) — 14 px перед подписью, зазор 6; необязателен.

## Варианты

- **По содержимому** (`md`): Ширина по подписям, высота пункта 26 px. Основной вид. Когда: переключатель вида над списком; два-четыре коротких слова.
- **Компактный** (`sm`): Высота пункта 22 px, padding 0 8, подпись 11 px. Когда: заголовок карточки или график: «День / Неделя / Месяц».
- **На всю ширину** (`block`): Трек растягивается, пункты делят ширину поровну. Когда: фильтр статусов над таблицей на всю ширину панели, мобильный вид.
- **Со значками** (`icons`): Значок 14 px слева от подписи; недоступный вариант остаётся в ряду. Когда: режимы показа: список, плитки, карта.

## Состояния

### Применимые

- **Пункт не выбран** (`default`): aria-checked=false. Текст --text-2 на фоне трека --surface-muted.
- **Hover** (`hover`): У невыбранного пункта текст темнеет до --text. У выбранного ничего не меняется.
- **Active** (`active`): Слой --layer-1p на невыбранном пункте, пока кнопка нажата. На выбранном слоя нет.
- **Focus** (`focus`): Кольцо 2px --focus вплотную вокруг пункта (outline-offset 0), только от клавиатуры.
- **Выбран** (`selected`): aria-checked=true. Под пунктом плашка --surface с тенью --shadow-panel и кольцом --border; текст --text.
- **Disabled-пункт** (`disabled`): Недоступен один вариант, остальные работают. Текст --text-ph, плашка на него не переезжает.

### Не применимы (с причиной)

- **Loading** (`loading`): Нет в макете. Переключение мгновенно и локально; если вид грузится с сервера, Skeleton ставят на контент, а группа остаётся доступной.
- **Error** (`error`): Нет: выбрать «неправильный» сегмент нельзя. Ошибку выбора показывает поле формы, а не группа.
- **Empty** (`empty`): Нет: всегда выбран один пункт, пустой группы не бывает. Значение по умолчанию обязательно.

## Доступность

- **radiogroup + radio** (`aria`): Трек — role="radiogroup" с aria-label («Вид», «Период»); пункт — <button role="radio" aria-checked>. Вкладками (tablist) группа не является.
- **Tab** (`key`): Входит в группу одним остановом на выбранном пункте; остальные tabindex=-1. [TODO] в макете tabindex не расставлен: каждый пункт отдельная остановка Tab.
- **← → ↑ ↓** (`key`): Предложение: переключают выбор и фокус, пропуская disabled, замыкаясь по краям. Home и End — на первый и последний.
- **Кольцо** (`focus`): 2px --focus вплотную вокруг пункта (3,65:1 на белом, 9,34:1 в тёмной).
- **Текст пунктов** (`contrast`): --text-2 на --surface-muted: 7,1:1 (светлая), 9,7:1 (тёмная); выбранный --text на --surface: 16,5:1 и 16,4:1. Недоступный --text-ph — вне нормы WCAG для disabled.
- **Плашка** (`contrast`): Плашка отличается от трека не цветом, а тенью и кольцом: фон --surface и --surface-muted дают 1,1:1 в светлой. Выбранный пункт ещё и темнее по тексту (16,5:1 против 7,1:1). [TODO] проверить различимость в тёмной теме.
- **prefers-reduced-motion** (`motion`): Плашка переезжает мгновенно, цвет текста меняется без перехода.

## Хореография

### Смена выбора: плашка переезжает (`slide`, origin: mockup)

- **Триггер:** клик или тап по другому пункту

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Наведение на невыбранный пункт: текст --text-2 → --text. | color | ease |
| 700 | 125 | Нажатие: слой --layer-1p на нажатом пункте. | background | ease |
| 850 | 200 | Плашка едет к новому пункту; одновременно меняется её ширина под подпись. | translate, width | var(--ease) = cubic-bezier(.6,0,.05,.95) |
| 850 | 125 | aria-checked переходит на новый пункт: у прежнего текст --text → --text-2, у нового --text-2 → --text. | color | ease |

- **Фокус:** Остаётся на нажатом пункте (клик по кнопке). Фокус не едет вместе с плашкой, плашка едет за выбором.

- **Reduced motion:** Переход плашки и цвета отключён: плашка появляется под новым пунктом сразу.

- **Соседи:** Пункты не двигаются: трек не меняет размера, меняется только положение плашки. Первая расстановка плашки при показе идёт без перехода (иначе она «выезжает» с нуля).

### Стрелки и фокус (`keys`, origin: proposal)

- **Триггер:** Tab в группу, затем ← → ↑ ↓

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Tab: фокус на выбранном пункте (единственная остановка Tab, у остальных tabindex=-1). Кольцо 2px --focus. | outline | — |
| 900 | 200 | → или ↓: выбор и фокус на следующем доступном пункте; плашка едет. Disabled-пункты пропускаются. | translate, width | var(--ease) |
| 1700 | 200 | На последнем пункте → замыкается на первый; ← на первом уходит на последний. | translate, width | var(--ease) |

- **Фокус:** Roving tabindex: фокус всегда на выбранном пункте и едет вместе с выбором. Space и Enter ничего не меняют (выбор уже сделан стрелкой). [TODO] подтвердить: в макете стрелки не обработаны, только клик.

- **Reduced motion:** Плашка перескакивает без перехода, кольцо фокуса остаётся.

- **Соседи:** Стрелки не должны прокручивать страницу: у обработчика preventDefault.

## Примеры

### Вид списка грузов (`view`)

```tsx
<ToggleGroup value={view} onValueChange={setView} aria-label="Показ">
  <ToggleGroup.Item value="list" icon="list">Список</ToggleGroup.Item>
  <ToggleGroup.Item value="grid" icon="grid">Плитки</ToggleGroup.Item>
  <ToggleGroup.Item value="map" disabled>Карта</ToggleGroup.Item>
</ToggleGroup>
```

### Фильтр статусов на всю ширину (`status`)

```tsx
<ToggleGroup block value={status} onValueChange={setStatus} aria-label="Статус">…</ToggleGroup>
```

## Как использовать

Импорт: в ките — `import { ToggleGroup, ToggleGroupItem } from "@/ui"`, в приложении — `import { ToggleGroup, ToggleGroupItem } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Компоненты `ToggleGroup` (`<div role="radiogroup">`) и `ToggleGroup.Item` (он же `ToggleGroupItem`, `<button role="radio">`). Типы: `ToggleGroupProps`, `ToggleGroupItemProps`, `ToggleGroupSize`.

```tsx
import { ToggleGroup } from "@/ui";
```

Пропсы `ToggleGroup` (плюс атрибуты `<div>`: `aria-label`, `data-*`, `ref`):

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `value` | `string` | нет | Управляемый выбор. |
| `defaultValue` | `string` | первый доступный пункт | Начальный выбор без управления (пункты ищутся среди прямых детей). |
| `onValueChange` | `(value: string) => void` | нет | Вызывается при смене выбора (не при клике по выбранному). |
| `size` | `"md" \| "sm"` | `"md"` | Высота пункта 28 px или 24 px. |
| `block` | `boolean` | нет | Группа на всю ширину, пункты поровну. |

Пропсы `ToggleGroup.Item` (плюс атрибуты `<button>`):

| Проп | Тип | Описание |
| --- | --- | --- |
| `value` | `string` | Значение пункта (обязательно). |
| `icon` | `ReactNode` | Значок перед подписью (скрыт от скринридера). |
| `disabled` | `boolean` | Пункт виден, но не выбирается; стрелки его пропускают. |

```tsx
<ToggleGroup aria-label="Показ" value={view} onValueChange={setView}>
  <ToggleGroup.Item value="list" icon={<ListIcon />}>Список</ToggleGroup.Item>
  <ToggleGroup.Item value="grid" icon={<GridIcon />}>Плитки</ToggleGroup.Item>
  <ToggleGroup.Item value="map" disabled>Карта</ToggleGroup.Item>
</ToggleGroup>

<ToggleGroup block aria-label="Статус" defaultValue="all">…</ToggleGroup>
```

Доступность:

- Группа — `role="radiogroup"` с обязательным `aria-label`; пункты — `role="radio"` с `aria-checked`. Вкладками (tablist) группа не является.
- Roving tabindex: в Tab входит один останов на выбранном пункте.
- Стрелки (← → ↑ ↓) сразу выбирают соседний доступный пункт и переносят на него фокус, замыкаясь по краям; Home и End идут к первому и последнему.
- Плашка под выбранным пунктом едет за выбором; первая расстановка без перехода. При `prefers-reduced-motion` переезд мгновенный.

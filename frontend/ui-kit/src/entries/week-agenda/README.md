# Недельная повестка

Полоса из семи дней с точками событий и список событий выбранного дня: время, название, кто, длительность. Для сегодняшнего дня есть красная линия «Сейчас».

Повестка отвечает на вопрос «что у меня на этой неделе»: сверху видно, в какие дни есть события, ниже — подробности одного дня. Это не календарь для выбора даты (для этого есть Calendar) и не сетка с часами: события идут списком. Недели листать в макете нельзя [TODO] решить, нужны ли стрелки «прошлая / следующая неделя».

- **id:** `week-agenda`
- **Группа:** Время (`time`)
- **CSS-префикс:** `ds-agenda`
- **Origin хореографии:** mockup (2), proposal (1)

## Когда использовать / не использовать

### Использовать

- Неделя с понедельника, число и день недели в каждой кнопке.
- Точки на днях — по числу событий, но не больше семи [TODO] решить предел.
- Тип события — цвет точки и текст «кто» рядом: цвет не единственный носитель.
- Сегодняшний день отмечать цветом дня недели; «Сейчас» — только в нём.
- Свободный день — плашкой с датой, а не пустым местом.

### Не использовать

- Использовать как выбор даты: для даты есть Calendar и DatePicker.
- Красить события красным: красный — только линия «Сейчас».
- Показывать час-сетку: повестка — это список, а не расписание по часам.
- Прятать длительность: «30 мин» помогает планировать.

## Анатомия

1. **Полоса недели** — Семь кнопок-дней в сетке: день недели (10 px капсом), число 18 px, под ними точки событий. Неделя с понедельника.
2. **Точки событий** — По одной точке 4 px --orange на событие. Нет событий — место под точки остаётся пустым.
3. **Событие** — Строка из трёх колонок: время (начало жирным, конец серым), название с цветной точкой и кто, длительность бейджем «30 мин».
4. **Линия «Сейчас»** — Красная точка, подпись «Сейчас 10:15» и линия до края; встаёт перед первым событием, которое ещё не началось. Только у сегодняшнего дня.
5. **Свободный день** — Плашка «Свободный день» с датой, если событий нет.

## Варианты

- **Неделя и повестка** (`live`): Живой: выбирайте день. Сегодня — четверг 12 ноября, у него три события и линия «Сейчас». Когда: главная страница, карточка исполнителя.
- **Свободный день** (`free`): Среда без событий: точек нет, в списке плашка.
- **Другой день** (`other-day`): Пятница: события без линии «Сейчас», она есть только у сегодняшнего дня.

## Состояния

### Применимые

- **День** (`default`): Белая поверхность, рамка --border, число --text.
- **День · hover** (`hover`): Слой 4 % поверх поверхности. У события — подложка цвета события 14 % вместо 8 %.
- **День · active** (`active`): Слой 7 %.
- **День · focus** (`focus`): Кольцо --focus 2 px, отступ 1 px.
- **День · выбран** (`selected`): aria-pressed=true: фон --selected, рамка --border-selected.
- **День · сегодня** (`other`, `today`): День недели окрашивается в --link. Остальное как у обычного дня; можно быть выбранным.
- **День · без событий** (`empty`, `free`): Точек нет, высота остаётся.
- **Событие · hover** (`hover`, `event-hover`): Подложка 14 % цвета события, рамка цвета 24 % от события.
- **Событие · focus** (`focus`, `event-focus`): Событие в Tab (tabindex=0); кольцо --focus 2 px, отступ 1 px.
- **Loading** (`loading`): Предложение: в списке две серые плашки 54 px с мерцанием, точки на днях скрыты.
- **Error** (`error`): Предложение: плашка «Календарь недоступен». Полоса дней остаётся.

### Не применимы (с причиной)

- **Disabled** (`disabled`): Нет: дни и события или доступны, или их нет. Прошедшие события приглушаем прозрачностью 55 % (предложение).

## Доступность

- **Дни как кнопки** (`aria`): Каждый день — button с aria-pressed и aria-label: «Пт, 13 ноября, событий: 2». Сегодняшний добавляет «, сегодня». Полоса — role=group «Дни недели».
- **Список и aria-live** (`aria`): Контейнер списка — aria-live="polite": смена дня озвучивается («Свободный день» или список). Для сложных повесток лучше список <ul> [TODO].
- **Tab / Enter / Space** (`key`): Дни и события — стопы в Tab. Enter и Space выбирают день. [TODO] ← → между днями как в toolbar.
- **Контраст** (`contrast`): Макет красил подпись «Сейчас» в --danger (#d03538, на белом 4,9:1). В словаре --err-text (5,5:1). Точки --orange на белом 2,5:1: смысл дублируется в aria-label.
- **prefers-reduced-motion** (`motion`): Замена списка и переходы фона отключаются.

- **Фокус:** Фокус остаётся на нажатой кнопке дня; список — aria-live=polite, озвучивает «Свободный день» или события.

- **Соседи:** Полоса дней не двигается; высота списка меняется, и всё, что ниже, сдвигается. Для стабильной раскладки резервируйте высоту трёх событий [TODO].

## Как использовать

<!-- manual:start -->
Компоненты: `WeekAgenda` (неделя и список дня), части `WeekAgendaDay` и `WeekAgendaEvent`. Типы: `WeekAgendaProps`, `AgendaEvent`, `AgendaTone`, `WeekAgendaDayProps`, `WeekAgendaEventProps`. Логика дат — `calendar/dates.ts`.

```tsx
import { WeekAgenda } from "@/ui";
```

Пропсы `WeekAgenda` (атрибуты `<section>` — на корень):

| Проп                    | Тип                                  | По умолчанию                      | Описание                                                                                       |
| ----------------------- | ------------------------------------ | --------------------------------- | ---------------------------------------------------------------------------------------------- |
| `events`                | `AgendaEvent[]`                      | обязателен                        | События: `{ id, start: Date, end: Date, title, who?, tone? }`; `tone` — `teal`, `info`, `orange`, `gray`. |
| `week`                  | `Date`                               | неделя `now`                      | Любая дата недели; неделя начинается с понедельника.                                           |
| `value`, `defaultValue` | `Date`                               | сегодня, иначе понедельник        | Выбранный день: управляемый и неуправляемый режимы.                                            |
| `onChange`              | `(date: Date) => void`               | нет                               | Выбор дня.                                                                                     |
| `now`                   | `Date`                               | живые часы (раз в минуту)         | Текущий момент: отметка «сегодня» и линия «Сейчас 10:15» в списке.                             |
| `onEventClick`          | `(event: AgendaEvent) => void`       | нет                               | Клик по событию.                                                                               |
| `label`                 | `string`                             | `"Повестка недели"`               | Подпись секции.                                                                                |
| `loading`               | `boolean`                            | нет                               | `aria-busy`, заглушки вместо списка и точек.                                                   |
| `error`, `errorText`    | `boolean`, `ReactNode`               | нет                               | Заметка «Календарь недоступен» (`role="alert"`).                                               |
| `dayData`, `eventData`  | функции возврата `data-*`            | нет                               | Дополнительные `data-*` на день и на событие.                                                  |

```tsx
<WeekAgenda events={events} value={day} onChange={setDay} onEventClick={openEvent} />

<WeekAgenda events={[]} week={new Date(2026, 10, 9)} now={new Date(2026, 10, 12, 10, 15)} />
```

Для выбранного дня события идут по времени начала; на сегодняшнем дне между прошедшими и будущими стоит линия «Сейчас»; пустой день — «Свободный день».

Доступность:

- Дни — кнопки с `aria-pressed` и подписью «Чт, 12 ноября, событий: 3, сегодня»; список — `aria-live="polite"`, смена дня озвучивается.
- Каждый день и событие — стоп в Tab; `Enter` и `Space` активируют.
- Появление списка и заглушки отключаются при `prefers-reduced-motion`.

# Popover

Плавающая панель у элемента по клику: шапка, содержимое, подвал. Для подробностей статуса, маленьких форм и справки. Закрывается Esc и кликом вне.

Popover показывает то, что не умещается в Tooltip и не стоит окна Dialog: подробности расхождения, фильтр из трёх полей, пояснение термина. Он немодальный: страница остаётся живой, поповер привязан к якорю и исчезает при прокрутке. Решение, без которого нельзя продолжать, — Dialog; список действий — меню; список значений — Select.

- **id:** `popover`
- **Группа:** Окна и панели (`overlays`)
- **CSS-префикс:** `ds-popover`
- **Origin хореографии:** mockup (2)

## Когда использовать / не использовать

### Использовать

- Якорь — кнопка с aria-haspopup="dialog" и aria-expanded.
- В подвале «нет» слева, «да» справа; действие «да» всегда primary.
- Одна панель на экран: открывая новую, закрывайте предыдущую.
- Сводки и ключевые значения — в содержимом, не в шапке.
- Узкая форма: 2–5 полей; больше — Sheet или Dialog.

### Не использовать

- Поповер в поповере.
- Решение, без которого нельзя работать: это Dialog.
- Список из команд: это меню, у него другая клавиатура (стрелки).
- Закрывать при уходе мыши: поповер открыт кликом и закрывается явно.
- Прятать поповер под полем ввода: ставьте сверху, если снизу нет места (в макете разворот автоматический).

## Анатомия

1. **Панель** — Фон --surface, кольцо 1px --border, тень --shadow-pop, радиус --r-popover (12); ширина 280–340 px, не шире окна − 16.
2. **Шапка** — Жирный (700): что это. Отступы 12 14 8.
3. **Содержимое** — Колонка с интервалом 10, цвет --text-2; ключевые числа --text. Форма, список, справка.
4. **Подвал** (необязательная) — Верхняя черта --divider, кнопки sm справа через 6 px: «нет» слева (ghost), «да» справа (primary).
5. **Якорь** — Кнопка-триггер: aria-haspopup=dialog, aria-expanded; когда поповер открыт, кнопка подсвечена слоем.

## Варианты

- **Подробности статуса** (`status`): Шапка, абзац с ключевым значением, сводка «было/стало», два действия. Когда: нужно раскрыть бейдж или значок: что за расхождение и что с ним делать.
- **Фильтр с формой** (`filter`): Поля и флажки, подвал «Сбросить» и «Применить». Когда: короткая форма из 2–5 полей без перехода на другой экран.
- **Справка** (`help`): Шапка, один абзац и ссылка; без подвала. Когда: объяснить термин рядом с полем; для одной фразы хватит Tooltip.
- **Живой** (`live`): Три якоря: клик открывает, повторный клик, Esc и клик вне закрывают. Когда: попробовать руками: клавиатура и мышь.

## Состояния

### Применимые

- **Закрыт** (`default`): Виден только якорь с aria-expanded=false.
- **Hover якоря** (`hover`): Слой на кнопке-якоре; сам поповер от hover не меняется.
- **Active якоря** (`active`): Слой 9 % в момент нажатия.
- **Focus якоря** (`focus`): Кольцо 2 px на якоре; после закрытия Esc фокус возвращается сюда.
- **Открыт** (`selected`, `open`): Якорь с aria-expanded=true, ghost-якорь остаётся залитым слоем. Панель под якорем со смещением 4 px.

### Не применимы (с причиной)

- **Disabled** (`disabled`): Якорь отключают как обычную кнопку; открыть поповер нельзя. Причину говорит Tooltip на обёртке.
- **Loading** (`loading`): В макете нет. Предложение [TODO]: содержимое грузится — внутри Skeleton, высота панели заранее задана.
- **Error** (`error`): В макете нет. Ошибка внутри — Alert err в содержимом.
- **Empty** (`empty`): Пустой поповер не открывают: нет содержимого — нет якоря.

| `--shadow-pop` | 0 6px 20px · 0 1px 3px | Тень (в тёмной 0 8px 24px) |
| `--r-popover` | 12 px | Радиус панели |
| `width` | 280–340 px, ≤ 100vw − 16 | Ширина |
| `padding` | 12 14 8 · 0 14 12 · 10 14 | Шапка · содержимое · подвал |
| `gap` | 10 px (содержимое), 6 px (кнопки) | Интервалы |
| `z-index` | 900 | Выше Dialog и Sheet 800; ниже Tooltip 1000 |
| `offset` | 4 px от якоря, 8 px до края окна | Положение |
| `pop` | 125 мс, --ease | opacity 0→1, scale .96→1, сдвиг −4 px→0 |

## Доступность

- **role=dialog (немодальный)** (`aria`): Панель — role="dialog", aria-label или aria-labelledby на шапку; aria-modal не ставят, страница остаётся доступной. Якорь: aria-haspopup="dialog", aria-expanded, aria-controls (при открытом).
- **Клавиши** (`key`): Enter и Space на якоре открывают и закрывают. Tab идёт по содержимому панели, потом дальше по странице; Esc закрывает и возвращает фокус на якорь.
- **Фокус при открытии и закрытии** (`focus`): [TODO] в макете фокус остаётся на якоре, а содержимое поповера следует за ним в порядке Tab только если DOM поставлен сразу после якоря. Предложение: при открытии фокус на первый интерактивный элемент (или на панель с tabindex=-1, если их нет); при закрытии — на якорь. Ловушки фокуса нет: поповер не модальный.
- **Закрытие** (`aria`): Esc, клик вне, повторный клик по якорю, прокрутка и изменение размера окна. Esc не закрывает поповер, пока открыт Dialog над ним: Esc принадлежит верхнему слою.
- **Текст** (`contrast`): Шапка и числа --text на surface 16,5:1, абзац --text-2 8,2:1. Тёмная: 16,4:1 и 11,3:1. Кольцо границы дополняет тень.
- **prefers-reduced-motion** (`motion`): Появление без масштаба и сдвига, мгновенно.

## Хореография

### Открытие (`open`, origin: mockup)

- **Триггер:** клик по якорю (Enter / Space)

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 125 | Якорь получает hover, затем active (слой поверх фона). | background | ease |
| 800 | 0 | Панель вставляется в body, считается положение: снизу по левому краю якоря (4 px), при нехватке места — сверху; зажимается в окно с отступом 8 px. Якорь aria-expanded=true. | top, left | — |
| 800 | 125 | pop: opacity 0 → 1, scale .96 → 1, сдвиг вниз −4 px → 0. | opacity, scale, translate | --ease |
| 800 | 0 | Слушатели mousedown вне панели (capture) и прокрутки/ресайза. | — | — |

- **Фокус:** [TODO] в макете фокус остаётся на якоре. Предложение: фокус в панель (первый элемент), якорь aria-expanded.

- **Reduced motion:** Без масштаба и сдвига, мгновенно.

- **Соседи:** Перекрывает страницу (z-index 900), её не двигает. Открытие нового поповера закрывает прежний. Tooltip с якоря на время открытия не показывается.

### Закрытие: Esc, клик вне, действие (`close`, origin: mockup)

- **Триггер:** Esc / mousedown вне / кнопка в подвале / прокрутка

| at, мс | dur, мс | Что происходит | prop | easing |
| --- | --- | --- | --- | --- |
| 0 | 0 | Панель удаляется из DOM сразу, без анимации ухода; у якоря aria-expanded=false, слушатели сняты. | — | — |
| 0 | 0 | При Esc и «data-close» фокус возвращается на якорь; при клике вне — туда, куда кликнули; при прокрутке окна — никуда. | focus | — |

- **Фокус:** Esc и кнопки подвала возвращают фокус на якорь. Esc игнорируется, если сверху открыт Dialog.

- **Reduced motion:** Не отличается: ухода нет.

- **Соседи:** Освободившееся место ничем не заполняется: панель была поверх страницы.

## Примеры

### Расхождение по весу (`status`)

```tsx
<Popover
  trigger={<Button variant="outline" size="sm">Расхождение</Button>}
  label="Расхождение по весу"
>
  {({ close }) => (
    <>
      <PopoverHead>Расхождение по весу</PopoverHead>
      <PopoverBody>
        <span>Вес в декларации меньше веса по накладной на <b>180 кг</b>.</span>
        <dl className="ds-popover__diff">
          <dt>Накладная</dt>
          <dd>18 420 кг</dd>
          <dt>Декларация</dt>
          <dd>18 240 кг</dd>
        </dl>
      </PopoverBody>
      <PopoverFoot>
        <Button variant="ghost" size="sm" onClick={close}>Скрыть</Button>
        <Button size="sm" onClick={close}>Исправить в 1С</Button>
      </PopoverFoot>
    </>
  )}
</Popover>
```

### Справка у термина (`help`)

```tsx
<Popover
  trigger={<Button square variant="ghost" aria-label="Справка" icon={<Icon name="help" />} />}
  label="Что значит «Сверено»"
>
  {({ close }) => (
    <>
      <PopoverHead>Что значит «Сверено»</PopoverHead>
      <PopoverBody>
        <span>Вес, код ТН ВЭД и номера совпадают в накладной, декларации и инвойсе.</span>
        <button type="button" className="ds-popover__link" onClick={close}>Как работает сверка ›</button>
      </PopoverBody>
    </>
  )}
</Popover>
```

## Как использовать

Импорт: в ките — `import { Popover, PopoverBody, PopoverFoot, PopoverHead } from "@/ui"`, в приложении — `import { Popover, PopoverBody, PopoverFoot, PopoverHead } from "@astronaut/ui-kit"` (нужен `@astronaut/ui-kit/styles.css`).

<!-- manual:start -->
Импорт: `import { Popover, PopoverHead, PopoverBody, PopoverFoot } from "@/ui"`.

| Пропс | Тип | По умолчанию | Что делает |
| --- | --- | --- | --- |
| `trigger` | элемент-кнопка | обязателен | Якорь: получает `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls`, `onClick` |
| `children` | `ReactNode \| ({ close }) => ReactNode` | обязателен | Содержимое; `close` закрывает и возвращает фокус на якорь |
| `label` | `string` | обязателен | `aria-label` панели |
| `open` / `defaultOpen` | `boolean` | `false` | Управляемый и неуправляемый режимы |
| `onOpenChange` | `(open) => void` | нет | Просьба открыть или закрыть |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Сторона; при нехватке места разворот |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Выравнивание по якорю |
| `focusOnOpen` | `boolean` | `true` | После открытия фокус уходит в первый элемент панели |

Остальные атрибуты `div`, `className`, `ref` — на панель (рисуется в `body`, `z-index: 900`, `position: fixed`, пересчёт при прокрутке и ресайзе). `PopoverHead/Body/Foot` — типовые блоки.

```tsx
<Popover trigger={<Button variant="outline" size="sm">Фильтр</Button>} label="Фильтр грузов">
  {({ close }) => (<>
    <PopoverHead>Фильтр</PopoverHead>
    <PopoverBody>…</PopoverBody>
    <PopoverFoot><Button variant="ghost" onClick={close}>Сбросить</Button><Button onClick={close}>Применить</Button></PopoverFoot>
  </>)}
</Popover>
```

Доступность: Esc закрывает (только верхний слой: поверх `Dialog` нижний поповер Esc не получает) и возвращает фокус на якорь; клик вне панели и прокрутка страницы закрывают, прокрутка внутри панели нет. Утилиты `placeFloating`, `useFloating` экспортируются для своих всплывающих слоёв.

## Общие правила дизайн-системы Astronaut

Источник правил: CLAUDE.md проекта ui-kit, страницы группы «Основа» (Цвета, Типографика, Радиусы и размеры, Слои состояний) и страницы компонентов (Button, Dialog, Card, Avatar). Чего в них нет, помечено `[TODO]`.

### Как читать спецификацию

- Перед правкой компонента читают его README.md (`/entries/<id>.md`): варианты, состояния, анатомия, правила, доступность, токены, хореография и открытые вопросы.
- `[TODO]` в тексте — нерешённый вопрос; `origin: proposal` у сценария хореографии — предложение, не подтверждённое макетом.
- Не выдумывать факты: чего нет в спецификации, помечают `[TODO]`.

### Цвет и токены

- Цвета только ролями из `styles/tokens.css` (`var(--text)`, `var(--surface)`), без HEX. Исключение — шкалы, у которых HEX и есть токен (тона Avatar).
- Контраст текста не ниже 4,5:1 (графика 3:1) в обеих темах: коэффициенты считают, а не оценивают на глаз. Текст на teal и orange всегда navy; `--text-ph` не для текста, который нужно прочитать.
- Состояния (hover, active, selected, disabled) строятся слоями поверх вида: см. страницу «Слои состояний».
- Радиусы, размеры и тени берутся токенами со страницы «Радиусы и размеры».
- Длительности анимаций — токенами `--dur-f`, `--dur`, `--dur-s` или `calc(0.8s * var(--slow, 1))`; у каждого компонента есть блок `prefers-reduced-motion: reduce`.

### Типографика

- Один шрифт интерфейса — Onest; Fira Code только для кода, запросов и логов.
- Цифры, суммы и идентификаторы набираются тем же Onest, без моно, с `tabular-nums` для выравнивания колонок.

### Компоненты

- Нет левых акцентных линий: акцент не рисуют цветной полосой у левого края карточки, алерта или строки.
- Кнопки парой: две кнопки в карточке или панели делят ширину 50/50, главная слева.
- Dialog без крестика: выход только кнопками, «нет» слева, «да» справа.
- Без 3D и градиентов на аватарах.
- Анимации бренда (лоадер, знак) только готовые файлы из `brand/animated`, без своих.
- Состояние компонента — атрибутом (`aria-*`, `data-force`, `data-status`), а не общим классом `.is-*`.
- Классы и `@keyframes` компонента начинаются с его CSS-префикса (`ds-btn`, `ds-badge`), BEM-подобно: `ds-btn--primary`, `ds-btn__spin`.

### Проверка

- `task bun -- run verify`: типы, oxlint, формат и тесты (в том числе актуальность README и llms).
- README.md — единственный Markdown на компонент; часть между `gen:start` и `gen:end` генерируется из doc.tsx командой `task bun -- run docs`, раздел «Как использовать» (между `manual:start` и `manual:end`) пишется руками.

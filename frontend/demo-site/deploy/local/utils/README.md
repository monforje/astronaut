# utils

Обёртки над утилитами. Бинарники скачиваются сами при первом вызове (кроме ao — он лежит в репо).

- ao - локальный CA, сертификаты под домены `ao.toml`, по просьбе — /etc/hosts (вместо mkcert и hostctl)
- prek - pre-commit хуки
- gomplate - шаблоны Dockerfile
- ogen - сервер и клиент по OpenAPI, общий ogen.yml
- sqlc - код репозиториев по SQL-запросам, конфиг собирается сам, task sqlc-new - заготовка репозитория по таблице

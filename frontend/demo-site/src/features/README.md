# features

Действия пользователя — глаголы: войти, создать, архивировать, поделиться. Слайс содержит UI действия
и его мутацию.

```
features/<действие>/
  index.ts                                 только то, что нужно снаружи
  model/use-<действие>/use<Действие>.ts    useMutation, охрана (вошёл? есть права?), обновление кэша, сообщения
  model/<форма>-schema/<форма>Schema.ts    схема valibot для формы (если есть)
  ui/<компонент>/<Компонент>.tsx           (+ .module.css, .test.tsx, index.ts в той же папке)
```

## Правила

- Имя слайса — действие в `kebab-case`: `archive-item`, `auth`, `share-item`.
- Мутация — `useMutation<Результат, ApiError, Вход>`; после успеха кэш обновляется точечно
  (`setItemCache`) или инвалидируется (`invalidate…` из orval); ошибка — текстом `errorMessage(e)`.
- Данные для действия берутся из сущностей, а не повторными запросами.
- Фича не импортирует другую фичу: общее уезжает в `entities`/`shared`, склеивает их страница или виджет.
- Форма — `useForm` из `@mantine/form` со схемой valibot (`schemaResolver(schema, { sync: true })`).
  Валидация на клиенте — для удобства; источник правды — ответ бэкенда (`validation_failed` +
  `fieldError(e, "поле")`).

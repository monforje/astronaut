# shared/config

Конфигурация клиента. Каждый модуль — папка с `index.ts`.

- `env/` — единственное место чтения `import.meta.env`; наружу — объект `env` с типизированными
  полями (`apiBaseUrl`, `apiMock`). Переменные — только с префиксом `VITE_` (попадают в бандл: никаких
  секретов).
- `app/` — имя приложения `APP_NAME` (заголовок вкладки, шапка).
- Справочники статических ресурсов — константы `as const` с выведенными типами.

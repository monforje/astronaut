# shared

Код без предметной области. Делится на **сегменты** (не слайсы), импорт — через `index.ts` сегмента:
`@/shared/api`, `@/shared/config`, `@/shared/lib`, `@/shared/ui`. Внутри сегмента каждый модуль — папка
со своим `index.ts` (`docs/codestyle/codestyle.md`, «Модуль — папка»).

| Сегмент   | Что                                                                                  |
| --------- | ------------------------------------------------------------------------------------ |
| `api/`    | HTTP-клиент `customFetch`, `ApiError`, сгенерированный orval клиент и типы контракта |
| `config/` | окружение (`env`), имя приложения, статические справочники                           |
| `lib/`    | утилиты и хуки общего назначения, тестовые хелперы                                   |
| `ui/`     | тема бренда и составные блоки: состояния пусто/ошибка                                |

Правило: предметное слово в коде — значит, это не `shared`. `shared` не импортирует ни один слой выше.

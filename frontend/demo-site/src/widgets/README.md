# widgets

Крупные самостоятельные блоки, которые вставляют в страницу или раскладку целиком: шапка, подвал,
навигация, таблица с фильтрами.

```
widgets/<блок>/
  index.ts
  ui/<блок>/<Блок>.tsx, <Блок>.module.css, <Блок>.test.tsx, index.ts
```

| Виджет       | Что                                                                                                                                                                                                                                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app-shell/` | `AppFrame` — каркас всех экранов на ките: `AppShell` + `Sidebar` (навигация `model/nav`, rail запоминается в `model/sidebar-store`) + `Topbar` (крошки из `handle.crumb` маршрутов, поиск, `ThemeSwitch`, профиль), меню узкого вида — `Sheet` |

## Когда виджет

- Блок собирает **несколько** фич и сущностей (шапка: поиск + профиль + меню) и повторяется на разных
  страницах или в `app/layout`.
- Блок одной страницы из одной фичи остаётся в странице.

Виджет не делает своих мутаций — он раскладывает фичи. Соседние виджеты друг друга не импортируют.

# pages

Экраны. Один слайс — один маршрут (или семейство близких экранов).

```
pages/<экран>/
  index.ts                             export { ItemsPage } from "./ui/items-page";
  ui/<экран>-page/
    <Экран>Page.tsx                    компонент страницы
    <Экран>Page.module.css
    <Экран>Page.test.tsx               страница целиком через renderApp + mockApi
    index.ts
```

## Правила

- Страница **собирает**: берёт виджеты, фичи и сущности, раскладывает и решает, что показать в
  состояниях загрузки/ошибки/пусто. Своих запросов к API и бизнес-логики нет (сгенерированные хуки
  из страниц не вызываются — проверяет `docs/codestyle/codestyle.test.ts`).
- Заголовок вкладки — `useTitle("…")`; параметры маршрута — `useParams`/`useSearchParams` здесь, ниже
  передаются пропсами.
- Компонент — `<Экран>Page`, режимы — пропсами из `app/routes/routes.tsx` (`<AuthPage mode="login" />`).
- Страницы не импортируют друг друга; общий кусок двух страниц — виджет.

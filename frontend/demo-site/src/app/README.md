# app

Слой приложения: запускается один раз на всё приложение. Не слайсится, но модули — как везде: папка
с `index.ts` (steiger для `app` отключает `public-api` и `no-segmentless-slices`).

| Модуль            | Что                                                                                                                                                                                                                               |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `app/`            | `App` — дерево провайдеров: `ErrorBoundary` → `QueryProvider` → `RouterProvider` + `Toaster` кита                                                                                                                                 |
| `query-provider/` | `QueryProvider`, `createQueryClient`: `staleTime`, повтор только сетевых и 5xx ошибок                                                                                                                                             |
| `error-boundary/` | последний рубеж: ошибка рендера → экран «обновите страницу»                                                                                                                                                                       |
| `routes/`         | таблица маршрутов → страницы из `@/pages/*`; `createRouter`, `createTestRouter` для тестов                                                                                                                                        |
| `layout/`         | общая раскладка: `AppFrame` из `@/widgets/app-shell` (оболочка кита) + `<Outlet />`                                                                                                                                               |
| стили             | своих глобальных стилей нет: `main.tsx` один раз подключает `@astronaut/ui-kit/styles.css` (токены, шрифты, база, компоненты); тему задаёт `data-theme` на `<html>` (`features/theme-switch`, скрипт до отрисовки — `index.html`) |
| `index.ts`        | что `app` отдаёт наружу (`main.tsx` и тесты)                                                                                                                                                                                      |

## Правила

- Новый маршрут — строка в `routes/routes.tsx` (с `handle: { crumb: "Название" }` для крошек) и страница в `pages/`;
  пункт сайдбара — в `widgets/app-shell/model/nav`. Логики в маршрутах нет.
- Новый глобальный провайдер — сюда, своей папкой; провайдер одной фичи — в её слайсе.
- Тема светлая/тёмная — `features/theme-switch`; токены и компоненты — только из `@astronaut/ui-kit`.
- Обновление сессии по 401 включается здесь, когда появляется вход:
  `setSessionRefresh({ url, skip })` из `@/shared/api`.
- Глобальных стилей нет; раскладка компонента — CSS Module рядом с ним.
- Мок-бэкенд запускает `main.tsx` до рендера (`env.apiMock`, `mocks/README.md`).

# shared/lib

Утилиты без предметной области. Каждый модуль — папка с `index.ts`, тест рядом.

| Модуль       | Что                                                                                           |
| ------------ | --------------------------------------------------------------------------------------------- |
| `test-utils` | `renderAstro` для компонентных тестов (`docs/codestyle/testing.md`)                           |
| `reveal`     | `initReveal` — ставит `data-inview` блокам с `data-reveal` при прокрутке; подключает `Layout` |

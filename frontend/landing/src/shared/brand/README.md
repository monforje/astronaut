# shared/brand

Растровые картинки бренда для `astro:assets`: импорт из `@/shared/brand`, вывод через `<Image />` (сжатие,
webp, `width`/`height` против сдвигов вёрстки). Файлы — симлинки на `idea/skelet/brand`, не копии.

| Экспорт            | Файл                     | Где                                                                   |
| ------------------ | ------------------------ | --------------------------------------------------------------------- |
| `astronautConsole` | `astronaut-console.png`  | «Агент»: маскот у пульта протягивает экран с чатом                    |
| `astronautPort`    | `astronaut-port.png`     | Hero: астронавт на контейнере с проверенным документом                |
| `astronautPlug`    | `illustration.png`       | Блок «Демо»: астронавт летит с teal-кабелем и вставляет разъём в порт |
| `docInvoice`       | `doc-invoice.jpg`        | веер «Один контейнер»: инвойс, 120 мест                               |
| `docPackingList`   | `doc-packing-list.jpg`   | веер: упаковочный лист, 118 мест, 18 420 кг                           |
| `docBillOfLading`  | `doc-bill-of-lading.jpg` | веер: коносамент, 118 мест под маркером, 18 920 кг                    |
| `docPreInfo`       | `doc-pre-info.jpg`       | веер: предварительная информация                                      |
| `docDeclaration`   | `doc-declaration.jpg`    | веер: декларация на товары                                            |
| `docWaybill`       | `doc-waybill.jpg`        | веер: ЭТрН № 518, перевозчик не подписал                              |

Документы — листы по сквозному примеру с размытыми реквизитами, не сканы клиентов. Исходник и как
пересобрать — `idea/skelet/brand/documents/documents.html`.

## Фото блоков

`photo("<имя>")` отдаёт место под фото: имя файла, что снять и снимок, если он уже есть. Папка `photos/`
— ссылка на `idea/skelet/brand/photos/` целиком, снимки подхватывает `import.meta.glob`: положили
`trucks.jpg` — фото на сайте, код не трогаем. Выводит `PhotoSlot` (`@/shared/ui`): снимок или заглушка.

| Имя      | Блок                                          | Что в кадре                                      |
| -------- | --------------------------------------------- | ------------------------------------------------ |
| `trucks` | «Почему сейчас»: полоса над колонкой смыслов  | фуры с контейнерами у ворот терминала            |
| `office` | «Системы»: справа от заголовка                | рабочее место экспедитора, 1С на мониторе, папки |
| `ceo`    | «Вопросы»: круг в карточке «Не нашли вопрос?» | тот, кто отвечает в Telegram                     |

Размеры кадра, промпты для генерации и правила съёмки — `idea/skelet/brand/photos/README.md`.

# shared

Код без предметной области. Делится на **сегменты** (не слайсы): `config/`, `lib/`, `ui/`. Импорт — через
`index.ts` сегмента; внутри сегмента каждый модуль — папка со своим `index.ts`
(`docs/codestyle/codestyle.md`, «Модуль — папка»). Сегменты пока пусты.

Правило: предметное слово в коде — значит, это не `shared`. `shared` не импортирует ни один слой выше.

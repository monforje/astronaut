# shared

Код без предметной области. Делится на **сегменты** (не слайсы): `config/`, `lib/`, `ui/`, `brand/` (растровые картинки бренда для `astro:assets`). Импорт — через
`index.ts` сегмента; внутри сегмента каждый модуль — папка со своим `index.ts`
(`docs/codestyle/codestyle.md`, «Модуль — папка»).

Правило: предметное слово в коде — значит, это не `shared`. `shared` не импортирует ни один слой выше.

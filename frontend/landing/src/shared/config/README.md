# shared/config

Конфигурация сайта. Импорт — `@/shared/config`.

| Модуль     | Что                                                                                                                                                                           |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `company/` | имя и строка о компании, город, Telegram и почта; `DEMO_URL` — ссылка всех кнопок «Записаться на демо» (чат @monforje с набранным сообщением, PLAN.md, «Как устроена заявка») |

Чтение `import.meta.env` (только `PUBLIC_*`) появится здесь же отдельным модулем `env/`: больше
нигде в коде его нет.

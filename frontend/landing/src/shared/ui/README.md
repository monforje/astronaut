# shared/ui

UI без предметной области на Astro + Tailwind CSS 4: `.astro`-компоненты без клиентского JS (движение — CSS и SMIL). Цвета и шрифты — только роли из `app/styles/tokens.css`. Каждый модуль — папка с `index.ts`, импорт — `@/shared/ui`. Вид и правила — `DESIGN.md`.

| Компонент   | Что                                                                                                                                |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `Band`      | полоса секции на всю ширину: `<section>` с `id`/`aria-labelledby`, `tone` (`plain`, `surface`, `tint`), у цветной — волнистые края |
| `Blob`      | органическое пятно за иллюстрацией или макетом: форма `shape`, тон `tone`, дышит (SMIL `d`) за `duration` секунд                   |
| `Button`    | ссылка-кнопка: `primary` (оранжевая, одна на экран), `secondary` (navy, шапка), `link`; `magnet` — разметка для магнита            |
| `Heading`   | H2 секции с обязательным `id` для `aria-labelledby`, появляется при прокрутке                                                      |
| `Icon`      | иконки интерфейса 24×24, обводка 2, цвет `currentColor`, размеры `sm`/`md`/`lg`                                                    |
| `Lead`      | лид под H2                                                                                                                         |
| `Mono`      | цифры и коды в тексте; `variant="spark"` — расходящееся значение с оранжевой искрой                                                |
| `PhotoSlot` | фото блока из `photo("<имя>")` (`@/shared/brand`) или заглушка на его месте; заполняет обёртку, форму задаёт место                 |
| `SplitText` | текст по буквам с задержкой — заголовок первого экрана; слова не рвутся, читалка и копирование видят обычный текст                 |
| `SeoHead`   | title, description, canonical, Open Graph, `noindex`                                                                               |
| `JsonLd`    | разметка schema.org в `<script type="application/ld+json">` (`Organization`, `FAQPage`)                                            |

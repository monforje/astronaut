# widgets

Крупные блоки, которые вставляют в страницу целиком (шапка, подвал, секции). Есть: `header` — `SiteHeader` (лого, меню-якоря, «Записаться на демо»), `footer` — `SiteFooter` (строка о компании, город, Telegram, почта, год). Оба вставляет `Layout`.

```
widgets/<блок>/
  index.ts
  ui/<блок>/<Блок>.astro, <Блок>.test.ts, index.ts
```

# entities

Сущности предметной области — существительные. Слайс знает, как сущность показать «глупым»
компонентом и что с ней можно посчитать.

```
entities/<сущность>/
  index.ts                             export { PackageCard } from "./ui/package-card";
  model/<модуль>/<модуль>.ts           типы, константы, чистые функции (+ тест)
  ui/<компонент>/<Компонент>.astro     отображение без действий (+ тест, index.ts)
```

## Правила

- Имя слайса — существительное в единственном числе: `package`, `case`, `faq-item`.
- Данные лендинга (пакеты, вопросы, кейсы) — константы `as const` в `model/`, а не JSON в разметке;
  тексты не выдумываются — недостающее остаётся `[TODO]`.
- UI сущности не навигирует и не отправляет данные: получает всё пропсами.
- Пока предметных блоков нет, слой пуст — слайс заводится вместе с первым потребителем.

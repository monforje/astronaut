# features

Действия пользователя — глаголы: оставить заявку, подписаться, переключить язык. Слайс содержит UI
действия и его логику.

```
features/<действие>/
  index.ts                            только то, что нужно снаружи
  model/<модуль>/<модуль>.ts          схема валидации, чистая логика (+ тест)
  ui/<компонент>/<Компонент>.astro    разметка; интерактивное — `<script>` или остров (+ тест, index.ts)
```

| Слайс          | Что                                                                                                                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `request-demo` | `DemoButton` — каждая «Записаться на демо» (ссылка `DEMO_URL`: чат в Telegram с набранным сообщением). У `primary` — стрелка и магнит: `initMagnet` из `model/magnet` в обычном `<script>`, только с мышью и без reduced motion |

## Правила

- Имя слайса — действие в `kebab-case`: `request-demo`, `subscribe`.
- Статичную разметку делает `.astro`; клиентский JS — только там, где без него нельзя: маленький
  `<script>` с логикой в `model/` под тестом или остров `client:*`. Любой скрипт обосновывается:
  лендинг должен оставаться быстрым и видимым без JS.
- Фича не импортирует другую фичу: общее уезжает в `entities`/`shared`, склеивает их страница или виджет.
- Отправка заявки потребует бэкенда или внешнего сервиса — решение сначала в `idea/skelet/decisions.md`.

# features

Действия пользователя — глаголы: оставить заявку, подписаться, переключить язык. Слайс содержит UI
действия и его логику.

```
features/<действие>/
  index.ts                            только то, что нужно снаружи
  model/<модуль>/<модуль>.ts          схема валидации, чистая логика (+ тест)
  ui/<компонент>/<Компонент>.astro    разметка; интерактивное — остров на клиенте (+ тест, index.ts)
```

## Правила

- Имя слайса — действие в `kebab-case`: `request-demo`, `subscribe`.
- Статичную разметку делает `.astro`; клиентский JS (отправка формы) — только там, где без него нельзя,
  острова `client:*`. Любой остров обосновывается: лендинг должен оставаться быстрым без JS.
- Фича не импортирует другую фичу: общее уезжает в `entities`/`shared`, склеивает их страница или виджет.
- Отправка заявки потребует бэкенда или внешнего сервиса — решение сначала в `idea/skelet/decisions.md`.

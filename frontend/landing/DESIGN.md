# DESIGN.md — визуальный стиль лендинга

Правила взяты с первого экрана (шапка, Hero, четыре ценности) и задают стиль для остальных
секций. Палитра и шрифты — из бренда (`idea/skelet/brand/design/README.md`), слова — из
`idea/skelet/brand/messaging/` (голос — `voice.md`). Если этот файл и код расходятся, прав код:
поправьте файл.

## Характер

Светлый, спокойный, уверенный. Крупный жирный заголовок, много воздуха, мягкие органические
пятна на фоне, плоская иллюстрация с navy-обводкой. Оранжевый — редкая «искра», только для
главного действия. Без градиентов, теней, стекла и карточек в рамках. Космос сдержанно: маскот и
пара звёздочек на иллюстрации, не фон из звёзд.

## Цвет

Компоненты берут цвета только ролями из `src/app/styles/tokens.css` (утилиты `bg-bg`,
`text-muted`, `bg-spark`…). HEX в разметке и новые цвета не вводим: если нужен оттенок —
`color-mix` от фирменных цветов в `tokens.css`.

| Роль                | Утилита                       | Откуда              | Где                                         |
| ------------------- | ----------------------------- | ------------------- | ------------------------------------------- |
| Фон                 | `bg-bg`                       | white `#FDFDFD`     | страница                                    |
| Подложка            | `bg-surface` / `fill-surface` | off-white `#F4ECE0` | пятна за иллюстрацией, блобы иконок         |
| Текст               | `text-text`                   | navy `#041A31`      | заголовки, основной текст, текст на кнопках |
| Второй текст        | `text-muted`                  | navy 70%            | подзаголовки, описания                      |
| Линия               | `border-line`                 | navy 15%            | разделители (пока не используются)          |
| Акцент              | `bg-accent`                   | teal `#00C4C0`      | подчёркивание ссылок, детали в иконках      |
| Акцент-текст, фокус | `text-accent-strong`          | teal 55% + navy     | hover пунктов меню, кольцо фокуса           |
| Искра               | `bg-spark`                    | orange `#F88030`    | только главная кнопка                       |

- Пропорция на экране ≈ 60 / 25 / 10 / 5: белый и off-white, navy, teal, orange.
- **Текст на teal и orange — navy, не белый** (белый на оранжевом 2,6:1 — не читается).
- Teal как цвет текста на белом не ставим — для этого `accent-strong`.
- Тема одна, светлая. Тёмной нет.

## Шрифт

Onest для всего, JetBrains Mono — только коды, ID, цифры, которые надо выравнивать.

| Что                  | Классы                                                                                                                                    |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| H1 первого экрана    | `font-extrabold leading-[0.95] tracking-tight`, растёт `text-5xl → sm:6xl → lg:7xl → xl:[5.5rem] → 2xl:[6.5rem]`; каждая строка — `block` |
| Подзаголовок (лид)   | `text-lg md:text-xl 2xl:text-2xl text-muted`, ширина `max-w-xl 2xl:max-w-2xl`                                                             |
| H3 карточки ценности | `text-xl leading-tight font-bold text-balance`                                                                                            |
| Текст под H3         | базовый размер, `text-muted`                                                                                                              |
| Логотип-надпись      | `font-extrabold tracking-tight`, `text-xl → md:4xl → xl:[2.75rem]`                                                                        |
| Меню                 | `text-base xl:text-lg font-medium`                                                                                                        |
| Кнопки               | `font-semibold`                                                                                                                           |

- Заголовки короткие, 2–5 слов; переносим вручную через `block`, а не полагаемся на ширину.
- Перед тире — неразрывный пробел (` —`), чтобы тире не уезжало в начало строки.

## Сетка и отступы

- Ширина всех секций — утилита `page-container` (`global.css`): до `110rem`, поля
  `1rem → md:2rem → xl:4rem`. Шапка, Hero и блоки стоят по одной вертикали. Свои `max-w-7xl` не
  заводим.
- Большие экраны не оставляем пустыми: на `xl`/`2xl` растут шрифты, кнопки и логотип.
- Hero: `lg:grid-cols-[1fr_1.1fr]`, текст слева, иллюстрация справа и чуть шире. Заголовок может
  заходить на колонку иллюстрации (`lg:-mr-56`) — это намеренно, текст лежит поверх (`z-10`).
- Ряд ценностей: `grid gap-10 sm:grid-cols-2 lg:grid-cols-4 lg:gap-8`.
- Вертикальный ритм секций: `pb-16 lg:pb-24`; внутри — `mt-5` (иконка → заголовок),
  `mt-2` (заголовок → текст), `mt-6 lg:mt-8` (блоки первого экрана).
- Якорные секции — с `scroll-mt-8`.

## Формы

- **Органические пятна** вместо прямоугольных плашек: SVG-`path` с `fill-surface`,
  `preserveAspectRatio="none"`, `absolute -z-10`, у секции `relative isolate`. На мобильном пятно
  внизу под иллюстрацией, на `lg` — справа на половину ширины и уходит под шапку.
- Скругления: кнопки — `rounded-full` (пилюля); ссылки и логотип — `rounded`/`rounded-lg`
  только ради кольца фокуса.
- Рамок, теней и карточек нет: ценность = иконка + заголовок + текст на фоне страницы.

## Иллюстрации и иконки

Один язык для маскота и иконок: плоская заливка, толстая navy-обводка со скруглёнными концами,
белые/off-white тела, teal — «живая» деталь (галочка, кабель, вода), orange — только искры
внимания. Без градиентов и объёма.

- Иконки — `idea/skelet/brand/icons/<имя>.svg`, на сайте `/brand/icons/<имя>.svg`. Сетка 96×96,
  обводка 4 (navy `#041A31`), off-white блоб уже внутри SVG, teal-кружок с белой галочкой или
  стрелками как акцент. Новые иконки рисуем по тем же правилам и показываем в `icons/preview.html`.
- Иконка в разметке: `size-24 -ml-2` (блоб шире рисунка — сдвиг выравнивает рисунок по тексту).
- Иллюстрации — `astro:assets` `<Image>` с `widths`/`sizes`; на первом экране `loading="eager"`
  и `fetchpriority="high"`.
- Декоративное — `alt=""` и `aria-hidden="true"`, смысл несёт текст рядом.

## Компоненты

**Кнопка** (`@/shared/ui` → `Button`) — всегда `<a>`, на лендинге все действия — переходы.

| Вариант   | Вид                                                                                    | Когда                             |
| --------- | -------------------------------------------------------------------------------------- | --------------------------------- |
| `primary` | оранжевая пилюля, navy текст, hover `bg-spark/85`                                      | **одна на экран**: главный призыв |
| `link`    | navy текст с teal-подчёркиванием 3px; по hover navy-полоса прокатывается слева направо | второе действие рядом с primary   |

Размеры: `md` — шапка, `lg` — первый экран и крупные призывы. У `link` та же высота, что у
`primary` того же размера, чтобы они стояли в ряд. Стрелка в primary сдвигается на hover
(`group-hover:translate-x-1`).

**Шапка** — логотип (маскот + «Astronaut»), меню якорями (с `lg`), справа `Button md`
«Оставить заявку». Без фона и линии снизу, лежит на странице.

**Фокус** везде одинаковый: `focus-visible:outline-2 focus-visible:outline-offset-4
focus-visible:outline-accent-strong`.

## Движение

- Появление только у текста первого экрана: `motion-safe:animate-rise` (0,7 с, снизу вверх,
  мягкое торможение), строки по очереди с задержками `0 / 120 / 260 / 400 мс`.
- Иллюстрации и остальные секции не анимируются.
- Hover — короткие переходы цвета и сдвига (`transition-colors`, `duration-300`), без
  масштабирования и прыжков.
- Всё движение — только через `motion-safe:` / с `motion-reduce:transition-none`; плавная
  прокрутка к якорям — только без `prefers-reduced-motion`.

## Доступность

- Ссылка «К содержимому» первой в `<body>`.
- Каждая секция — `aria-labelledby` на свой заголовок. Если заголовок не нужен визуально —
  `sr-only` (как «Что делает Astronaut» у ценностей).
- Контраст текста ≥ 4,5:1, акцентов и фокуса ≥ 3:1 — поэтому navy на цветных заливках и
  `accent-strong` для акцент-текста.

## Новая секция — чек-лист

1. `page-container`, `aria-labelledby`, отступ `pb-16 lg:pb-24`.

5. Иконки/картинки — из `brand/`, в общем стиле, декоративные с `alt=""`.
6. Анимация — только если это первый экран; всё под `motion-safe`.

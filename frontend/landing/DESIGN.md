# DESIGN.md — визуальный стиль лендинга

Правила взяты со страницы, собранной по [PLAN.md](PLAN.md). Палитра и шрифты — из бренда
(`idea/skelet/brand/design/README.md`), слова — из `idea/skelet/brand/messaging/` (голос — `voice.md`).
Если этот файл и код расходятся, прав код: поправьте файл.

## Характер

Светлый, свежий, живой. Крупный жирный заголовок, много воздуха, полосы секций с волнистыми краями и
дышащие органические пятна, плоская иллюстрация с navy-обводкой. Продукт показан, а не описан:
веер документов, табло дат со связками, маршрут контейнера с сообщениями системы, чат с агентом,
схема подключений — всё на одном сквозном примере (MSKU1234567, Ромашка, 120 мест против 118).
Карточки белые, скруглённые, с мягкой navy-тенью: это куски интерфейса продукта, а не рамки ради
рамок. Оранжевый — редкая «искра»: главная кнопка и расходящаяся цифра. Без градиентов и стекла.
Космос сдержанно: маскот и пара звёздочек у иллюстрации, не фон из звёзд. Землю дают фото: фуры у
терминала, рабочее место экспедитора, портрет того, кто отвечает, — по одному снимку там, где блок
держался на одном тексте.

`bg-spark`…). HEX в разметке и новые цвета не вводим: если нужен оттенок — `color-mix` от фирменных
цветов в `tokens.css`. 03.11.2026 палитра бренда стала на несколько тонов светлее (было мутно и
грустно); перекраска SVG и PNG бренда — `idea/skelet/brand/design/recolor.py`, таблица — в

- Основа экрана — белый, off-white и мята; navy — текст; teal — живые детали; оранжевый — искра.

  искра на значении, которое не сходится; на одном экране с оранжевой кнопкой искр нет.
- **Текст на teal и orange — navy, не белый.** Белый — только на navy.
- Teal как цвет текста на белом не ставим — для этого `accent-strong`.
- Тема одна, светлая. Тёмной нет.

## Шрифт

Onest для всего, Fira Code — только цифры, коды, номера и даты (`Mono`, табло, номера шагов).
03.11.2026 весь набор и интервалы стали примерно на 20–25 % мельче: страница читалась крупно. Тогда
же моноширинный JetBrains Mono заменили на Fira Code (файл и `@font-face` — в бренде,
`design/tokens.css`). Лигатуры Fira Code в цифрах и кодах не срабатывают, отключать их не нужно.

| Что                     | Классы / компонент                                                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| H1 первого экрана       | `font-extrabold leading-[0.98] tracking-tight`, `text-[2.5rem] → sm:5xl → lg:[3.5rem] → xl:[4rem] → 2xl:[4.75rem]`                 |
| H2 секции               | `Heading`: `font-extrabold leading-[1.05] tracking-tight`, `text-[1.875rem] → sm:4xl → lg:[2.5rem] → xl:[2.75rem] → 2xl:[3.25rem]` |
| Лид под H2              | `Lead`: `text-base md:text-lg text-muted`, `max-w-xl 2xl:max-w-2xl`, отступ `mt-4 lg:mt-5`                                         |
| H3 карточек             | `text-lg lg:text-xl leading-tight font-bold text-balance`                                                                          |
| H3 шагов пути           | `text-base lg:text-lg leading-tight font-bold`                                                                                     |
| Текст карточек и шагов  | `text-[0.9375rem]` (15 px), `text-muted`                                                                                           |
| Сцены, правила, записка | `text-[0.9375rem] lg:text-base`, navy; следствие — `text-muted`                                                                    |
| Строка-вывод            | `text-lg lg:text-xl font-bold leading-snug text-balance`                                                                           |
| Даты на табло           | Fira Code `font-semibold`, `text-[1.625rem] → lg:[1.875rem] → 2xl:[2.25rem]`                                                       |
| Цифры и коды в тексте   | `Mono`: Fira Code `font-medium text-[0.9em]`, пробел между разрядами поджат (`word-spacing:-0.3em`)                                |
| Логотип-надпись         | `font-extrabold tracking-tight`, `text-lg → md:2xl → xl:[1.75rem]`; маскот `h-8 → md:h-10 → xl:h-11`                               |
| Меню                    | `text-[0.9375rem] font-medium`                                                                                                     |
| Кнопки                  | `font-semibold`, размеры — в «Компонентах»                                                                                         |

- Заголовки короткие, 2–5 слов; переносим вручную через `block`, а не полагаемся на ширину.
- Перед тире — неразрывный пробел (` —`), чтобы тире не уезжало в начало строки; короткое «не»
  привязываем к следующему слову (`не&nbsp;продолжаем`).
- В `Mono` единицы и разряды остаются внутри (`18 420 кг`, `2,7 %`), знак «№» — снаружи, в Onest:
  в моно он сжат. «ООО» моно не набираем — читается как «000».
- **Пробелы и Astro.** Astro сжимает HTML и выбрасывает перенос строки между текстом и тегом. Если
  текст и тег стоят на разных строках, между ними нужен `{" "}`, иначе читалка и поисковик получат
  «118.Узнали». То же между блоками, которые читалка прочтёт подряд (дата и тема на табло). Prettier
  ставит `{" "}` сам, когда сам переносит строку; тест `HomePage` ловит склейки.

## Сетка и отступы

- Ширина контента — утилита `page-container` (`global.css`): до `96rem`, поля
  `1rem → md:2rem → xl:3rem`. Шапка, Hero и блоки стоят по одной вертикали. Свои `max-w-7xl` не
  заводим. Края широкого экрана занимают полосы секций и волны (`Band`), а не растянутый текст.
- **Экран = такт.** Секция помещается в экран ноутбука: 1366×768 и 1536×864. На 1024×768 допустимо
  чуть выше экрана — это планшет. Не влезает — сначала ужимаем интервалы и текст, а не кегль
  заголовков.
- Ритм полос (`Band`): внутри `py-12 lg:py-16`, у цветной ещё `2xl:py-20`; цветная полоса держит
  снаружи `my-10 lg:my-14` — место под её волны. H2 → лид `mt-4 lg:mt-5`, лид → содержимое
  `mt-8 lg:mt-12`, ряды карточек `gap-3–gap-4`, на `lg` до `gap-8`.
- Якоря — `id` секции из PLAN.md, отступ при прокрутке `scroll-mt-12` (в `Band`).
- Hero: `lg:grid-cols-[1fr_1fr]`, текст слева, иллюстрация справа. Заголовок заходит на колонку
  иллюстрации (`lg:-mr-24`) — это намеренно, текст лежит поверх (`z-10`).
- Композиции чередуют стороны: Hero — иллюстрация справа, «Один контейнер» — веер справа,
  «Почему сейчас» — даты слева, описания справа и фото над ними, «Агент» — чат справа, «Системы» —
  фото справа от заголовка, «Демо» — иллюстрация справа у края экрана.
- Фото стоят в колонке и кончаются там же, где карточки под ними. К краю экрана прижимается только
  картинка, обрезанная по краю самим рисунком: порт в иллюстрации «Демо». Фото «Систем» сначала тоже
  уходило к краю, но на широком экране выглядело отрезанным — вылет убрали.
- Картинка, обрезанная по краю (порт в иллюстрации «Демо»), прижимается к краю экрана: отрицательный
  отступ на `--bleed` = поле `page-container` плюс половина остатка экрана за его `96rem`. Вылет
  считаем в переменной (`[--bleed:calc(...)]`, затем `w-[calc(100%_+_var(--bleed))]`). Одно выражение
  с процентом и `min()` внутри `calc` нельзя: Lightning CSS (и в dev, и при сборке) на нём
  зацикливается и съедает 10+ ГБ памяти (CLAUDE.md).
- Пятна Hero и чата намеренно уходят за правый край экрана; `<main>` режет их по горизонтали
  (`overflow-x-clip`), поэтому страница не ездит вбок. Не `overflow-hidden`: он создал бы контейнер
  прокрутки и сломал `sticky` (карточка «Не нашли свой вопрос?»).

## Полосы, пятна, карточки

- **Полоса секции** (`Band`, `@/shared/ui`) — вся ширина экрана, внутри `page-container`. Тон:
  `plain` (белая), `surface` (off-white), `tint` (мята). У цветной сверху и снизу волна того же цвета
  (`viewBox 0 0 1440 80`, высота `h-8 lg:h-12`), сверху и снизу разной формы. Волна неподвижная:
  перетекающий край мельтешил при прокрутке, анимацию убрали. Цветные полосы чередуются с белыми —
  блоки не склеены, переход виден:

  | Секция          | Тон       |     | Секция          | Тон       |
  | --------------- | --------- | --- | --------------- | --------- |
  | Hero, три слова | белый     |     | Системы         | `surface` |
  | Один контейнер  | `surface` |     | Чего не обещаем | `plain`   |
  | Почему сейчас   | `plain`   |     | Как начать      | `tint`    |
  | Путь контейнера | `tint`    |     | Вопросы         | `plain`   |
  | Агент           | `plain`   |     | Демо            | `surface` |

- **Пятно** (`Blob`, `@/shared/ui`) — органическая форма за иллюстрацией или макетом: формы `hero`,
  `chat`, `note`, `contact`, `spot`, тон `surface`/`tint`/`bg`, своя длительность `duration` (18–30 с),
  чтобы пятна дышали вразнобой. Кладём в обёртку `absolute … -z-10`, у родителя `relative isolate`;
  SVG растягивается на обёртку (`preserveAspectRatio="none"`). На узком экране пятно под записку
  вытянулось бы в линзу — там записка — скруглённая off-white карточка, пятно с `lg`.
- Пятна дышат через SMIL (`<animate attributeName="d">`): CSS-анимация `d` в Safari не работает. У
  всех форм одна структура команд пути — иначе морфинг не интерполируется. Новые формы генерируем тем
  же способом (три кадра на форму).
- **Карточка** — белая, `rounded-2xl`, тень `shadow-card` (navy, не серая); кольцо `ring-1 ring-line`
  — у карточек на белом фоне, на мятной полосе только тень. Поднятая или открытая — `shadow-lift`.
  Плашка иконки внутри — `rounded-xl bg-tint text-accent-strong`, `size-8 → size-11`. Не каждый блок —
  карточки: сцены боли, записка, лиды, «три слова» лежат на фоне. Ряд одинаковых карточек «иконка +
  заголовок + текст» с рамкой и подъёмом на hover не ставим: так выглядит сгенерированный шаблон.
- Скругления: кнопки — `rounded-full`; карточки и фото-полосы — `rounded-2xl`; окно чата и подложки — `rounded-3xl` / `rounded-[2rem]`; плашки иконок —
  `rounded-xl`; аватар — `rounded-full`; листы документов — `rounded-[3px]`, как бумага; ссылки —
  `rounded` только ради кольца фокуса.
- Пунктир (`outline-dashed`, не `border` — не сдвигает содержимое) — «только если»: этап
  «Расширение».

## Компоненты

**Кнопка** (`@/shared/ui` → `Button`) — всегда `<a>`, на лендинге все действия — переходы.

| Вариант     | Вид                                                                                    | Когда                                                             |
| ----------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `primary`   | оранжевая пилюля, navy текст, оранжевая тень снизу, hover `bg-spark/90`                | **одна на экран**: главный призыв (первый экран, Демо)            |
| `secondary` | navy пилюля, белый текст, hover `bg-text/85`                                           | тот же призыв рядом с `primary`: кнопка шапки                     |
| `link`      | navy текст с teal-подчёркиванием 3px; по hover navy-полоса прокатывается слева направо | второе действие («Как это работает», «Покажем этот путь на демо») |

Размеры: `md` — `px-4 py-2 text-sm lg:px-5 lg:py-2.5` (шапка); `lg` — `px-6 py-3.5
text-[0.9375rem] 2xl:px-7 2xl:text-base`. У `link` та же высота, что у `primary` того же размера.

**«Записаться на демо»** — только через `DemoButton` (`@/features/request-demo`): ссылка
`DEMO_URL`, у `primary` стрелка и магнит (кнопка тянется к курсору). Шапка — `variant="secondary"
size="md"`, без магнита.

**Шапка** — логотип (маскот + «Astronaut», маскот по hover чуть поворачивается), меню якорями на
такты (с `lg`) с teal-подчёркиванием, растущим слева; справа `DemoButton secondary`. Без фона и
линии снизу.

**Цифра с искрой** (`Mono variant="spark"`) — `<mark>` с моноширинным значением, под ним
оранжевый маркер `bg-spark/35`, у правого верхнего угла три штриха `stroke-spark`. Только для
значения, которое не сходится с другими документами (118 мест, 18 920 кг); совпадающее рядом —
простой `Mono`.

**Три слова** (`pages/home/ui/features`) — одна мятная подложка `rounded-[2rem]` на ряд (на
телефоне — своя у каждого), на ней три куска интерфейса: карточка груза «из PDF», ход сверки
документов, монитор обменов. Куски — белые панели `rounded-2xl` с `shadow-card`, текст `text-xs`,
строки проявляются по очереди. Заголовок и текст — под подложкой на фоне, без рамок и hover. Искры
нет: экран общий с главной кнопкой.

**Веер документов** (`pages/home/ui/docs-stack`, «Один контейнер») — внизу navy-плашка контейнера
MSKU1234567, над ней веером листы-«фото» из `@/shared/brand`: четыре задних (упаковочный лист,
предварительная информация, ЭТрН, декларация) и два передних — инвойс и коносамент. Мелкий шрифт
листов не прочесть, поэтому над ними лупы: белый круг с navy-кольцом 3px и ручкой, внутри крупно
`120 CTNS` и `118 PACKAGES` (118 — с искрой). Лупы — отдельным слоем с геометрией своего листа,
поверх всех листов. Весь веер скрыт от читалки — сцена есть текстом рядом.

**Табло дат** («Почему сейчас») — строка = карточка даты (плашка иконки, дата моноширинным, тема
мелко) → связка → off-white карточка «что это значит». Связка: teal-линия от карточки к описанию и
узел-кружок с teal-кольцом; узлы соединены вертикальной линией, как вехи. Цифры для глаза, дата
словами — `sr-only` в `<time datetime>`. Шапка секции стоит на той же сетке, что строки: заголовок
слева, над колонкой смыслов — фото-полоса `h-36 → 2xl:h-44` (фуры у ворот терминала), низ фото и
заголовка на одной линии.

**Место под фото** (`PhotoSlot`, `@/shared/ui`) — снимок из `photo("<имя>")` или заглушка на его
месте. Лежит поверх обёртки (`absolute inset-0`); размер и форму задаёт обёртка в секции: `relative
overflow-hidden rounded-2xl` с высотой или `aspect-*`. Поэтому пришедшее позже фото не сдвигает
вёрстку и не растягивает строку сетки. Аватар — круг `size-14` с белым кольцом `ring-2` и
`shadow-card`.

**Сообщение системы** (`pages/home/ui/system-message`) — так продукт говорит с менеджером: что
случилось и что сделать. Белая карточка-уведомление (`rounded-2xl`, `shadow-card`) на мятной полосе:
без рамки и без реакции на наведение — это не кнопка.

- Шапка `source` — `text-xs lg:text-[0.8125rem] font-medium text-muted`: какая проверка прислала
  сообщение. Времени нет: это были бы придуманные цифры.
- Слева точка статуса `size-2.5`: teal-круг (`status="ok"`) — сверено, система справилась сама;
  кольцо `border-2 border-accent-strong` с расходящимся teal-пульсом (`status="action"`) — нужно
  действие человека.
- Текст navy; цифры — `Mono`, расхождение — `Mono variant="spark"`, что сделать — `<strong>`. Для
  читалки впереди скрытое «Сообщение системы:».

**Маршрут** (только путь контейнера — подпись сердца страницы) — кружки-номера `size-10 lg:size-11`,
белые с teal-обводкой 2px и номером `text-accent-strong`, между ними тонкая линия `w-0.5 bg-accent/45`.
Шаг и его сообщение стоят в одной строке сетки, выносок к карточкам нет. Номер для глаза, порядок
читалке даёт `<ol>`. На мобильном сообщение под шагом.

**Макет чата** (агент) — окно в духе ChatGPT, Gemini и Claude, чтобы ИИ-чат узнавался сразу: белое
окно `rounded-3xl shadow-lift` на пятне `chat`, сверху «Агент Astronaut ⌄»; ваш вопрос справа в
off-white пузыре `rounded-3xl`; ответ агента без пузыря, слева аватар-маскот в кружке; под ответом
«Применить» (navy пилюля) и «Отклонить» (пилюля с кольцом) и строка действий (копировать, нравится,
не нравится, повторить); внизу поле «Что нужно сделать?» `rounded-[1.75rem]` с «+» и круглой navy
кнопкой отправки со стрелкой вверх. Кнопки, поле и действия только для вида: это `<span>`, скрыты от
читалки. Подписи «Вы:» и «Агент:» — `sr-only`. Под чатом — три правила карточками с иконками (щит,
галочка, процессор). Слева под лидом — маскот у пульта (`astronaut-console.png`, `max-w-[25rem]` на
`lg`) на пятне `spot`: протягивает экран с чатом человеку, а не жмёт кнопку сам.

**Схема подключений** (системы) — navy метка «Astronaut» с маскотом, от неё teal-кабель 3px с
отводом к каждой системе; системы — белые плашки `rounded-lg ring-line shadow-card`, текстом, без
чужих логотипов. На `lg` кабель горизонтальный, плашки в `grid-cols-8` под отводами двух длин через
один; на мобильном кабель идёт вниз, системы столбиком. Две ценности под схемой — карточки с иконками
интерфейса (обмен, люди). Справа от заголовка и лида — фото рабочего места экспедитора: высоту
задаёт колонка текста, правый край — по краю колонки, как у схемы и карточек.

**Записка** («Чего мы не обещаем») — чего не обещаем — с ✕ в белом кружке, что делаем — с ✓ в
teal-кружке, ниже абзац о команде с жирным обязательством.

**Этапы** («Как начать») — четыре карточки: плашка иконки и моноширинный номер `text-accent-strong`,
заголовок, текст. На `lg` между карточками — белый кружок с шевроном. Этап «только если» —
пунктирная рамка (`outline-dashed`). Кружков-номеров и маршрута нет: они принадлежат пути.

**Вопросы** — нативный `<details>` карточками: вопрос `text-base lg:text-lg font-semibold`, справа плюс

выезжает. Маркер браузера скрыт. Рядом (на `lg` — под заголовком и липкая, на телефоне — после
вопросов) off-white карточка «Не нашли свой вопрос?» со ссылками Telegram и почта; слева от её
заголовка — круглое фото того, кто отвечает в Telegram.

**Демо** — полоса `surface`, за иллюстрацией белое пятно `contact`, `DemoButton` с магнитом,
подпись про Telegram, почта с иконкой.

**Подвал** — маскот `h-9` и строка о компании, справа город, Telegram, почта и год, у каждого своя
иконка `Icon`; ссылки подчёркнуты teal. Линии сверху нет: подвал отделяет волна полосы «Демо».

## Движение

Правила: две-три осмысленные анимации на секцию, одна главная сцена на странице, контент виден и без
анимации, `prefers-reduced-motion` уважаем, проверяем на слабом телефоне (DevTools, замедление CPU
4–6×). Анимируем только `transform`/`translate`/`scale`/`opacity`, не размеры и не отступы.
Торможение — `--ease-out-expo` (`cubic-bezier(0.16, 1, 0.3, 1)`), входы 0,5–1 с, очередь 70–140 мс.

- **Главная сцена — путь контейнера:** шаги выходят по очереди, маршрут прорисовывается сверху вниз,
  у точек «нужно действие» расходится пульс.
- **Первый экран:** H1 по буквам (`SplitText`: буква выезжает снизу из размытия, 32 мс на букву,
  вторая строка через 300 мс), подзаголовок и кнопки следом (`animate-rise`, 700 и 850 мс),
  две звёздочки мерцают. Иллюстрации (первый экран, «Демо») неподвижны: парение убрали.
- **Появление при прокрутке:** `data-reveal` — сам элемент, `data-reveal="group"` — дети по очереди
  (`--i` — номер ребёнка). `data-inview` ставит `initReveal` (`@/shared/lib/reveal`) один раз, когда
  блок на 15 % в окне. Пока JS не отработал (нет класса `.js` на `<html>`), всё видно.
- **Сцены секций** (на `data-inview`): строки в кусках интерфейса «трёх слов» проявляются по
  очереди; веер документов раскрывается из стопки, лупы проявляются следом; цифры дат выезжают по
  одной, как на табло, связки и узлы прорисовываются; чат проигрывается (вопрос → три точки → ответ
  выходит по словам → кнопки → курсор в поле); по кабелю систем бегут блики (только `lg`); ответ в
  вопросах выезжает при открытии.
- **Фон:** пятна дышат (SMIL, 18–30 с, медленно — не отвлекают). Волны полос стоят.
- **Ответ на наведение:** веер становится шире, маскот в шапке поворачивается, у меню растёт
  подчёркивание, у `link` прокатывается navy-полоса. Информационные карточки (сообщения системы,
  «три слова») на наведение не реагируют: это не кнопки.
- **Магнит** у главной кнопки: тянется к курсору на 30 % расстояния до центра, не дальше 10 px, по
  уходу курсора плавно возвращается. Только при `(hover: hover) and (pointer: fine)` и без
  reduced motion: на телефоне курсора нет.
- **С `prefers-reduced-motion: reduce`:** появления не прячут контент, буквы, веер, лупы, табло и
  чат стоят в конечном виде, пятна неподвижны, магнита нет, прокрутка к якорям без плавности.
  В Tailwind — `motion-safe:` / `motion-reduce:transition-none`, в CSS компонента — медиазапрос
  `no-preference`.

## Клиентский JS

Острова (`client:*`) не используем. На странице два маленьких скрипта без фреймворка, Astro собирает
их в модули и подключает по одному разу:

- `Layout`: строка в `<head>` ставит `.js` на `<html>` (стилям появления можно прятать блоки), в конце
  `<body>` — `initReveal()`.
- `DemoButton`: `initMagnet()` — магнит главной кнопки.

Всё остальное движение — CSS и SMIL.

## Доступность

- Ссылка «К содержимому» первой в `<body>`.
- Каждая секция — `aria-labelledby` на свой заголовок. Если заголовок не нужен визуально —
  `sr-only` (как «Что делает Astronaut» у трёх слов).
- Контраст текста ≥ 4,5:1, акцентов и фокуса ≥ 3:1 — поэтому navy на цветных заливках и
  `accent-strong` для акцент-текста и номеров.
- То, что видно глазу, но мешает слуху (веер, цифры табло, связки, номера на маршруте и этапах,
  кнопки макета чата, «печатает», заглушки), скрыто `aria-hidden`; читалка получает то же словами.
- Движение — см. «Движение»: без JS и с reduced motion страница видна целиком.

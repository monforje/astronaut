# Astronaut

Платформа интеграции данных для логистических и транспортных компаний: связывает 1С, CRM, кабинеты линий и терминалов, операторов ЭПД, таможенное ПО и другие системы, наводит порядок в справочниках (MDM/НСИ), открывает данные другим сервисам и даёт AI-агента, который делает всё это по просьбе.

Отраслевые функции: карточка груза, сверка документов (инвойс, коносамент, ДТ, ЭТрН), электронные перевозочные документы, статус груза. Начинаем с **Владивостока**: с экспедиторов на пакете «Старт», крупных компаний и терминалов берём на «Корпоративный».

# Astronaut

Платформа интеграции данных для среднего бизнеса: связывает 1С, CRM, сайт, базы и госсистемы, наводит порядок в справочниках (MDM/НСИ), открывает данные другим сервисам и даёт AI-агента, который делает всё это по просьбе.

Первый отраслевой пакет — **логистика Владивостока**: карточка груза, сверка документов (инвойс, коносамент, ДТ, ЭТрН), электронные перевозочные документы, статус груза.

# Призывы к действию (CTA)

> [← Слова бренда](README.md) · [Голос](voice.md) · [Девизы](slogans.md) · [Фразы](phrases.md)

Правило: один главный призыв на экран или письмо. Глагол + конкретный результат. Формат пилота и цена ещё не решены ([questions.md](../../questions.md#решить-нам)), поэтому «бесплатно» и сроки — только после решения.

## Сайт

| Место | Главный CTA | Второй |
|---|---|---|
| Первый экран | **Проверить мои документы** | Как это работает |
| Блок «Сверка документов» | **Пришлите один комплект — покажем расхождения** | Посмотреть пример |
| Блок «Обмены» | **Проверить мои обмены с 1С** | Какие системы подключаем |
| Блок «AI-агент» | **Попросить агента** (демо) | Как защищены данные |
| Корпоративный пакет | **Обсудить пилот** | Запросить требования к установке |
| Терминалы и порты | **Обсудить API для ваших клиентов** | — |
| Подвал | **Написать нам** | Telegram-канал |

## Письмо и сообщение

- «Найдёте 20 минут на этой неделе? Покажу на примере одного контейнера.»
- «Пришлите один комплект документов по любой сделке — вернём список расхождений.»
- «Можно я задам вам 5 вопросов о том, как у вас устроены документы? Это займёт 15 минут.»
- «Удобнее созвониться или встретиться у вас в офисе?»

Тема письма:
- «Расхождения в документах по контейнерам»
- «ЭТрН отклоняют? Короткий вопрос»
- «Обмены с 1С: узнаёте о сбое сразу?»

## Презентация

- Последний слайд: **«Начнём с одного вашего потока документов»** + контакт.
- Слайд о пилоте: **«Один поток, реальные данные, понятный результат»**.

## Telegram

- «Покажите нам свой самый запутанный комплект документов — разберём в посте (без названий).»
- «Напишите, какие обмены у вас падают чаще всего.»

## Кнопки в продукте

| Действие | Текст кнопки |
|---|---|
| Подключить систему | Подключить 1С / Подключить систему |
| Сверка | Сверить документы |
| Отправка ЭПД | Отправить на подпись |
| Расхождение | Показать расхождения / Отметить как норму |
| Задача человеку | Взять в работу / Решено |
| Поток | Тестовый запуск / Выкатить |
| Агент | Спросить агента |
| Подтверждение действия агента | Применить / Отклонить |
| Перезапуск | Повторить отправку |

Поле ввода агента: **«Что нужно сделать?»** Подсказки под ним: «Сверь документы по контейнеру», «Почему упал обмен с 1С?», «Найди дубли контрагентов».

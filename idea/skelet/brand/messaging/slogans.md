# Девизы и слоганы

## Основной

> **Груз один — данные одни.**

Почему этот: говорит о главной боли (одни и те же данные расходятся в десятке документов) словами логиста, короткий, запоминается, не обещает непроверенных цифр.

С дескриптором: **Astronaut. Платформа данных для логистики. Груз один — данные одни.**

## Запасные

| Слоган | Где хорош |
|---|---|
| **Один раз внесли — везде одинаково.** | Сайт, объяснение карточки груза |
| **Проверено до таможни.** | Сверка документов, баннеры |
| **Расхождение видно до отправки, а не на таможне.** | Подзаголовок на сайте, письмо |
| **Обмены, которые не ломаются молча.** | Мониторинг интеграций, разговор с ИТ и 1С-никами |
| **Ваши системы знают о грузе одно и то же.** | Платформа целиком, корпоративный пакет |
| **API для ваших клиентов вместо ещё одного кабинета.** | Терминалы, порты, крупные экспедиторы |
| **Попросите — агент сделает.** | AI-агент |
| **Каждое сообщение — на своей траектории.** | Бренд-метафора (точка на орбите в логотипе), сдержанно: презентации, мерч |

## По пакетам

| Пакет | Девиз |
|---|---|
| Старт | **Документы без расхождений. Запуск за недели, не за месяцы.** *(срок подтвердить на пилоте)* |
| Корпоративный | **Все системы и все клиенты — на одних данных.** |

## Внутренний девиз команды

> **Сначала проверь на реальном документе.**

Напоминание себе: не строить и не обещать то, что не прогнали на настоящем комплекте документов клиента.

## Не используем

- «Логистика будущего», «цифровая логистика нового поколения» — пусто.
- «Космическая скорость обработки» — космос как шутка обесценивает надёжность.
- «Ноль ошибок в документах» — неправда и непроверяемо.

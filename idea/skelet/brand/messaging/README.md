## Правила использования

- **Не обещаем непроверенное.** Пока не было разговоров с клиентами, никаких цифр экономии, «единственные на рынке», «сократим ошибки на 80 %». Когда появятся данные пилота, обновим фразы с цифрами.
- **Одна боль на первый контакт.** На сайте и в первом письме ведём с одного предложения, остальное — «и это только начало».
- **Разные пакеты — разные слова.** Для «Старта» говорим про документы и скорость запуска, для «Корпоративного» — про интеграции, API и надёжность.
- Логотипы и графика лежат рядом, в [`brand/`](../).

# Из чего собран продукт

Дата: 2026-11-01. Черновик. Итоговый продукт для логистических компаний собирается из блоков. Каждый блок решает свою задачу, а позже может продаваться отдельно как продукт или услуга.

- Подробно, что делает каждый слой: `layers.md`.
- Логистика по шагам и документам: `logistics-flow.md`.
- Боли D1–D16 взяты из `../audience/pains.md`, предложения А/Б/В — из `../audience/fit.md`.

## Слои

```
 5. Услуги             внедрение · сопровождение · обучение · партнёры
 3. Логистика          документы · трекинг · портал и API · финансы сделки · архив
 2. Смысл данных       MDM/НСИ (золотая запись) · качество и проверка
 1. Движение данных    FROM / TO (коннекторы) · BY (способы строить) · доступ к данным для сервисов
 0. Надёжность         отказоустойчивый рантайм · наблюдаемость
 ─────────────────────────────────────────────────────────────────
 4. AI-агент           сквозной: работает во всех слоях, с доступом ко всей платформе
```

## Предлагаемый срез MVP

1. Шина, коннекторы MVP и базовая наблюдаемость.
2. Витрина в Postgres и Data API.
3. Золотая запись контрагентов и грузов с проверкой по ЕГРЮЛ и ГосЛогу.
4. Документы: сборка из карточек, сверка, отправка через оператора ЭПД (шаги 1, 2, 3, 6, 8а из `logistics-flow.md`).
5. Трекинг на 1–2 источниках с уведомлениями в Telegram.
6. AI-агент, который собирает потоки и золотые записи по просьбе, и распознавание инвойсов.

Этот срез закрывает предложение «А» целиком и показывает «Б» на демо.

- **цену одного контейнера через API для партнёра.** Наша цена — цена API плюс 100 ₽ маржи (решение 2026-11-04). Рабочая цифра 250 ₽ посчитана на худший случай, если API стоит как розница (150 ₽). До ответа цену клиентам не называем;

- как часто обновляются данные и есть ли вебхуки;
- дадут ли тестовый доступ.

## Письмо CargoTime

**Тема:** API отслеживания для экспедиторов

Здравствуйте!

Мы делаем Astronaut, программу для экспедиторов Владивостока: карточка груза, сверка документов, электронные накладные. Хотим показывать клиентам экспедитора, где их контейнер, и брать события моря и ЖД у вас через API, а не подключаться к каждой линии самим.

Подскажите, пожалуйста, условия:

1. Сколько стоит отслеживание одного контейнера через API, если данные мы показываем своим клиентам внутри нашей программы? Есть ли условия для партнёров?
2. Видите ли вы события на терминалах Владивостока (ВМТП, ВСК и другие) или только линию и ЖД?
3. Как часто обновляются данные и есть ли вебхуки о новых событиях?
4. Можно ли получить тестовый доступ, чтобы проверить API на нескольких наших контейнерах?

Первые клиенты — экспедиторы морского импорта из Китая через Владивосток.

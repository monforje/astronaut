# Словарь и база знаний

> [← Карта папки](../README.md) · [Термины](terms.md)

Термины, понятия и объяснения, которые всплывают в разговоре. Отсюда потом берём формулировки для продукта, продаж и документации.

## Как ведём

- Короткий термин — строка в [terms.md](terms.md), по алфавиту в своём разделе.
- Если понятию нужно развёрнутое объяснение (схема, примеры, сравнение), ему отдельный файл в этой папке, а в [terms.md](terms.md) ссылка на него.
- Формулировка простая, чтобы её можно было сказать клиенту. Технические детали — ниже, отдельным абзацем.

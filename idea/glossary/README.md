# Словарь и база знаний

Термины, понятия и объяснения, которые всплывают в разговоре. Отсюда потом берём формулировки для продукта, продаж и документации.

## Как ведём

- Короткий термин — строка в `terms.md` (по алфавиту).
- Если понятие требует развёрнутого объяснения (схема, примеры, сравнение), ему отдельный файл в этой папке, а в `terms.md` ссылка на него.
- Формулировка простая, чтобы её можно было сказать клиенту. Технические детали идут ниже, отдельным абзацем.

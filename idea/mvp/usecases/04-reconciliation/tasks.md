Только визуал и моки. Правила в [business-logic.md](business-logic.md).

## Экраны и компоненты

- [ ] Зона загрузки с прогрессом по файлу, статусы «загружен / распознаётся / готов / не прочитан»
- [ ] Таблица строк груза с пометками «проверьте»
- [ ] Просмотр документа рядом со строками (подсветка места, откуда взято число)
- [ ] Карточка результата сверки: «сошлось» / «расхождений N» / «нормальные различия N»
- [ ] Разбор расхождения: два документа рядом, три действия, поле комментария
- [ ] Список «Мои задачи» и статус «назначено / закрыто»

## Состояния каждого экрана

Пусто · загрузка · ошибка чтения · не хватает документа · всё сошлось · есть расхождения · закрыто.

## Какие фейк-данные нужны

Из [fake-data.md](../fake-data.md): инвойс INV-0418, упаковочный лист PL-0418, расхождения «места 120/118» и «получатель латиницей» (нормальное различие).

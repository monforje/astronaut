# 07. Доставка по России и ЭТрН: как это для клиента

> [← Юзкейсы по шагам](../README.md) · [Фейк-данные](../fake-data.md) · [Как это для клиента](user-view.md) · [Что нужно сделать](tasks.md) · [Бизнес-логика](business-logic.md)

Кто: менеджер ВЭД, подписант. Что получает: заявку перевозчику и ЭТрН из карточки; видно, кто не подписал; причина отклонения понятным языком. **Подпись ставит человек в кабинете оператора ЭПД, не у нас.**

## Шаги

1. В карточке груза менеджер открывает вкладку «Перевозка» и нажимает «Новая заявка перевозчику».
2. Выбирает перевозчика. Система сразу проверяет его по ЕГРЮЛ и реестру ГосЛога и показывает результат.
3. Данные подставляются из карточки: адреса, ИНН, масса, число мест. Менеджер проверяет и нажимает «Подготовить ЭТрН».
4. Система готовит документ и отправляет его через оператора ЭПД на подпись. Менеджер видит статус по каждому титулу: грузоотправитель, перевозчик, грузополучатель.
5. Если титул не подписан дольше срока, приходит напоминание, потом задача менеджеру.
6. Если документ отклонили, менеджер видит причину и поле: «Оператор отклонил: ИНН грузополучателя не совпадает с реестром». Исправляет и отправляет заново с подтверждением.

## Экраны

| Экран | Зачем | Главное действие |
|---|---|---|
| Вкладка «Перевозка» в карточке | Заявки и ЭТрН по грузу | «Новая заявка» |
| Заявка перевозчику | Данные из карточки, проверка перевозчика | «Подготовить ЭТрН» |
| Статус подписания | Кто подписал, кто нет, сколько висит | «Напомнить» |
| Причина отклонения | Что не так и где | «Исправить» |

## Когда что-то не так

| Ситуация | Что видит человек |
|---|---|
| Перевозчика нет в реестре ГосЛога | Красная плашка, кнопка «Подготовить ЭТрН» неактивна `[TODO: блокировать или предупреждать]` |
| У перевозчика другой оператор и документ не дошёл | «Документ отправлен 3 часа назад, получатель не видит» |
| Оператор недоступен | «Оператор сейчас не отвечает. Повторим сами, когда восстановится» |
| Повторная отправка | Всегда с подтверждением, иначе можно создать дубль документа |

## Тексты

Говорим «подписан / не подписан / отклонён». Слово «титул» объясняем при первом показе.

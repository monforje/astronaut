## Правила

| Правило | Источник |
|---|---|
| Заявка и ЭТрН собираются из карточек: адреса, ИНН, масса из одного источника | logistics-flow.md |
| Каждый участник подписывает свой титул КЭП или по МЧД в кабинете своего оператора; ключи мы не храним | logistics-flow.md, layers.md |
| Перевозчика проверяем по ЕГРЮЛ и ГосЛогу при выборе; с 01.03.2027 договор с перевозчиком не из реестра заключать нельзя | logistics-flow.md |
| Карточка ↔ ЭТрН: сверяем грузоотправителя, грузополучателя, адреса, массу брутто, число мест, общее наименование груза | матрица сверки |
| В ЭТрН нет кода ТН ВЭД и построчного перечня: их не сверяем | матрица сверки |
| Таймаут подписания: 2 часа — напомнить, 24 часа — задача менеджеру (пример срабатывания) | layers.md, слой 1 (значения примерные) |
| Отклонённый документ показываем с причиной и полем | logistics-flow.md |
| Повторную отправку ЭПД и ЭТрН — только с подтверждением человека | layers.md, слой 4 |

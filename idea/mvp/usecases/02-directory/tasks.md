# 02. Справочник: что нужно сделать

> [← Юзкейсы по шагам](../README.md) · [Фейк-данные](../fake-data.md) · [Боковое меню](../side-nav.md) · [Как это для клиента](user-view.md) · [Бизнес-логика](business-logic.md)

Только визуал и моки. Правила в [business-logic.md](business-logic.md).

## Экраны и компоненты

- [ ] Список контрагентов: таблица, поиск по названию и ИНН, фильтры «все / дубли / проблемы», метки-плашки статусов
- [ ] Форма «Добавить контрагента»: переключатель «Российская / Иностранная», поле ИНН, блок с данными из реестров
- [ ] Блок «Нашли похожих»: список карточек рядом с формой
- [ ] Карточка контрагента: реквизиты, «откуда пришло» по каждому полю, связанные грузы, история
- [ ] Очередь проверки дублей: пара записей рядом, различия подсвечены, два действия
- [ ] Плашки: ликвидирована, нет в реестре ГосЛога, иностранная

## Состояния каждого экрана

Пусто («Справочник пока пустой, добавьте первого контрагента») · загрузка · реестр не отвечает · ИНН не найден · успех.

## Какие фейк-данные нужны

Из [fake-data.md](../fake-data.md): все контрагенты (Ромашка и её дубли, филиал, иностранный поставщик, два перевозчика, ликвидированная компания).
Чего не хватает: ответы «реестр не отвечает» и «ИНН не найден» (моки ошибок, данные не нужны).

См. [side-nav.md](../side-nav.md). Живёт в: пункт «Справочник»: список, форма, очередь дублей.

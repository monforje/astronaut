## Что нужно показать и уметь

- [ ] Видеть все подключения и их состояние, включая предупреждение «токен истекает через N дней»
- [ ] Добавить подключение пошагово: выбрать тип, ввести параметры, увидеть результат каждой проверки (сеть, логин, права, объекты)
- [ ] Видеть список обменов
- [ ] Собрать обмен: выбрать шаблон или описать словами, что нужно (агент)
- [ ] Видеть схему обмена «откуда → что делаем → куда» и соответствие полей источника и получателя
- [ ] Запустить тест и получить отчёт; выкатить в рабочую среду только после теста и с подтверждением
- [ ] Поменять подключение: параметры, среду, какие объекты брать; повторная проверка после правки
- [ ] Отключить подключение, заранее увидев список обменов, которые остановятся
- [ ] Заменить поле источника в строке соответствия, видя пример значения; после правки появляется новая версия-черновик, выкат возможен только после теста

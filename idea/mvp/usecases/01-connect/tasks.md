## Экраны и компоненты

- [ ] Список подключений с состоянием и плашкой «токен истекает через N дней»
- [ ] Мастер подключения (выбор типа, параметры, проверки с галочками)
- [ ] Список обменов
- [ ] Выбор шаблона и поле «Опишите, что нужно» (агент)
- [ ] Конструктор обмена: схема FROM → шаги → TO, таблица соответствия полей
- [ ] Тестовый запуск с отчётом и кнопка «Выкатить» с подтверждением
- [ ] Настройки подключения: параметры, среда, какие объекты брать, повторная проверка; «Отключить» со списком обменов, которые остановятся
- [ ] Окно выбора поля в таблице соответствия: список полей источника с примером значения; после правки — новая версия-черновик, выкат только после теста

## Состояния каждого экрана

Пусто · проверка идёт · проверка не прошла · успех · тест идёт · тест упал.

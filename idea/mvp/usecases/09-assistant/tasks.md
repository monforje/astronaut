# 09. Помощник: что нужно сделать

> [← Юзкейсы по шагам](../README.md) · [Фейк-данные](../fake-data.md) · [Боковое меню](../side-nav.md) · [Как это для клиента](user-view.md) · [Что нужно сделать](tasks.md) · [Бизнес-логика](business-logic.md)

Только визуал и моки. Ответы помощника в моках заготовлены, настоящей модели нет.

## Экраны и компоненты

- [ ] Боковая панель с чатом, подсказками «что можно сделать» по экрану
- [ ] Экран-чат с историей слева и большим полем ввода
- [ ] Блок «План действий» с кнопками подтверждения
- [ ] Строка быстрого вызова на главном экране
- [ ] Состояние «помощник недоступен»

## Состояния каждого экрана

Пусто (подсказки) · пишет ответ · ответ · требуется подтверждение · применено · ошибка · недоступен.

## Какие фейк-данные нужны

Заготовленные диалоги: «Сверь документы по контейнеру MSKU1234567», «Почему упал обмен с Контуром?», «Где мой контейнер?» (из [story.md](../../../skelet/brand/messaging/story.md)).

## Место в боковом меню

См. [side-nav.md](../side-nav.md). Живёт в: пункт «Помощник» (экран-чат) и боковая панель на любом экране.

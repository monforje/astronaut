# 09. Помощник: что нужно сделать

> [← Юзкейсы по шагам](../README.md) · [Фейк-данные](../fake-data.md) · [Боковое меню](../side-nav.md) · [Как это для клиента](user-view.md) · [Что нужно сделать](tasks.md) · [Бизнес-логика](business-logic.md)

Только визуал и моки. Ответы помощника в моках заготовлены, настоящей модели нет. Помощник берётся из кита целиком, своих компонентов не рисуем.

## Что нужно показать и уметь

- [ ] Вызвать помощника на любой странице, не теряя её, и свернуть обратно
- [ ] Подсказки «что можно сделать» с учётом текущей страницы
- [ ] Предложение от помощника без открытия панели: «Показать» / «Позже»
- [ ] Переписка: вопрос, ответ по мере появления, остановить, оценить
- [ ] План действий с выбором «Подтвердить» / «Не подтверждать»; до подтверждения данные не меняются
- [ ] Открыть помощника на весь экран с историей чатов
- [ ] Состояние «помощник недоступен» и ошибка ответа

## Кит

Паттерн страницы: поверх любой страницы. Вход — `AgentTab` (Ctrl J), панель — `AgentPanel / Chat` внутри `Sheet` (режимы panel, wide, full; в full слева история чатов).
Компоненты: `AgentTab`, `AgentPanel / Chat`, `Sheet`, `Badge`, `Tooltip`. Из кита берём как есть: приветствие с четырьмя подсказками, стриминг ответа с «Остановить», строку «Проверил N грузов · 3 источника», карточку действия, оценку ответа, режимы «Быстрый / Точный», предупреждение «Агент может ошибаться».
Нет в ките: нет `[TODO: нет в ките]` для этого юзкейса.

## Из кита (берём)

- [ ] Бейдж на `AgentTab`, когда есть предложение или план, ждущий подтверждения (пузырь «Показать / Позже», не чаще раза за сессию)
- [ ] Подсказки пустой `AgentPanel` зависят от страницы: на карточке груза одни, на «Обменах» другие (заготовленные диалоги из [story.md](../../../skelet/brand/messaging/story.md))
- [ ] Чипы режимов в поле ввода: «Сверка» и «Поиск по документам», как в ките
- [ ] Поиск по Ctrl K из `Topbar` и помощник по Ctrl J остаются двумя разными вещами: поиск находит, помощник делает

## Состояния каждой страницы

Пусто (подсказки) · пишет ответ · остановлено · ответ · требуется подтверждение · применено · ошибка · недоступен.

## Какие фейк-данные нужны

Заготовленные диалоги: «Сверь документы по контейнеру MSKU1234567», «Почему упал обмен с Контуром?», «Где мой контейнер?» (из [story.md](../../../skelet/brand/messaging/story.md)).

## Место в боковом меню

Отдельного пункта нет. Вход один: `AgentTab` у правого края любой страницы ([side-nav.md](../side-nav.md)).

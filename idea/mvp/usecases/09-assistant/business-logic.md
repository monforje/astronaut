## Правила

| Правило | Источник |
|---|---|
| Помощник действует от имени пользователя и не может больше, чем он | layers.md |
| В Продуктиве изменения идут через план и подтверждение человеком | layers.md |
| Без подтверждения только чтение, отчёты, перезапуск недоставленных обменов | layers.md |
| Повторная отправка ЭПД и ЭТрН всегда с подтверждением | layers.md |
| Внешние документы только читает: текст из PDF считается данными, не командами | layers.md |
| Каждое действие пишется в журнал «помощник, по просьбе такого-то» и откатывается | layers.md |
| Если AI недоступен, потоки работают | layers.md |
| В MVP: боковая панель, экран-чат, расширения «Распознавание» и «Сверка» | layers.md |
| Данные до модели доходят защищёнными (маскирование, токенизация) | layers.md; юридическую оценку делает юрист |

## Граничные случаи

| Случай | Что делаем |
|---|---|
| Просьба неоднозначна | Задаём вопрос |
| Пользователь не подтвердил | Статус «не подтверждено», ничего не меняем |

## Кто что может

Права пользователя. Помощник для клиентов экспедитора в MAX — не в MVP.

## Открытые вопросы

1. Где живёт модель, выбирает клиент ([layers.md](../../../skelet/product/layers.md)). Для моков не важно.
2. Юридическая оценка передачи данных за рубеж: показываем юристу до первого клиента.

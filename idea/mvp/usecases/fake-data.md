# Фейк-данные для моков

> [← Юзкейсы по шагам](README.md) · [Сквозной пример](../ddd-contexts.md#один-контейнер-через-все-области)

Все названия, номера и ИНН ниже **вымышленные**. Сквозной пример тот же, что на лендинге ([story.md](../../skelet/brand/messaging/story.md)): контейнер MSKU1234567, ООО Ромашка. Берём данные только отсюда, чтобы юзкейсы не расходились. Нужен новый груз или контрагент — добавляем сюда.

## Контрагенты

| Что | Значение | Зачем в моках |
|---|---|---|
| Клиент экспедитора (золотая запись) | ООО «Ромашка», ИНН 0000000001, КПП 000000001, Владивосток | основной клиент |
| Та же компания в CRM | «Ромашка ООО» | похожая запись, идёт в очередь на проверку |
| Та же компания в кабинете терминала | «Romashka» | похожая запись |
| Точный дубль из 1С | ООО «Ромашка», ИНН 0000000001, КПП 000000001 | сливается автоматически |
| Другая компания с тем же ИНН, другим КПП | ООО «Ромашка» (филиал), ИНН 0000000001, КПП 000000002 | не дубль: филиал |
| Иностранный поставщик | Shenzhen Example Trading Co., Ltd; 深圳示例贸易有限公司; USCC `000000000000000000` | нет ИНН и записи в ЕГРЮЛ |
| Перевозчик в реестре ГосЛога | ООО «Дальавто», ИНН 0000000002 | зелёная проверка |
| Перевозчик не в реестре | ИП Иванов, ИНН 000000000003 | красная проверка |
| Ликвидированная компания | ООО «Старт-Тест», ИНН 0000000004 | предупреждение «ликвидирована» |

## Документы сквозного примера

| Документ | Что в нём (вымышленно) |
|---|---|
| Заявка | № 518, клиент ООО «Ромашка», контейнер MSKU1234567 |
| Инвойс | INV-0418, Shenzhen Example Trading Co., Ltd → ООО «Ромашка», 3 позиции, валюта USD, 120 мест |
| Упаковочный лист | PL-0418, 120 мест, нетто 16 900 кг, брутто 18 420 кг |
| Драфт коносамента | 118 мест, брутто 18 920 кг, получатель «Romashka Co» (транслитерация названия клиента) |
| ПИ | по коносаменту, 118 мест |
| ДТ | 3 товарные позиции, код ТН ВЭД в третьей позиции не совпадает с платёжкой (для моков сверки ДТ) |
| Заявка перевозчику | ООО «Дальавто», Владивосток → Хабаровск |
| ЭТрН | рейс по заявке 518, титулы: грузоотправитель подписан, перевозчик не подписан 2 часа |

Расхождения для моков: места 120/118; брутто 18 420/18 920 кг (больше допуска); получатель в коносаменте записан латиницей (допустимое различие, не тревога).

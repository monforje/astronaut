## Что нужно показать и уметь

- [ ] Сводка: сколько обменов работает, сколько требует внимания, сколько упало; из неё открывается проблемный обмен
- [ ] Путь сообщения по шагам: где пришло, что сделали, где упало; данные «как пришли» и «как ушли»
- [ ] Причина сбоя человеческим языком
- [ ] «Повторить» для недоставленных и список недоставленных с причиной
- [ ] Журнал действий с поиском
- [ ] Экран «что зависло» для руководителя без технических деталей
- [ ] Настроить уведомления: куда слать (MAX, почта, вебхук)
- [ ] Предупредить заранее, что токен скоро истечёт

Компоненты: `Card`, `ServiceCard`, `Badge`, `DataTable`, `Stepper`, `Tabs`, `Alert`, `Button`, `Toast`, `Progress`, `Sheet`, `Switch`, `Input`, `Select`.

Только визуал и моки. Правила в [business-logic.md](business-logic.md). Использует компоненты юзкейса 04 (загрузка, результат сверки, разбор).

## Экраны и компоненты

- [ ] Вкладка «Документы»: тип «Драфт коносамента» в списке документов
- [ ] Результат сверки с подписью «исправить сейчас бесплатно»
- [ ] Окно «Письмо в линию» с готовым текстом и кнопкой «Скопировать»
- [ ] Напоминание «ждём драфт»

## Состояния каждого экрана

Пусто · драфта нет · загрузка · всё сошлось · есть расхождения · драфт устарел (пришёл коносамент).

## Какие фейк-данные нужны

Из [fake-data.md](../fake-data.md): драфт коносамента (118 мест, брутто 18 920 кг), упаковочный лист (120 мест, 18 420 кг).

## Правила

| Правило | Источник |
|---|---|
| Пакет данных собираем из карточки груза, без повторного набора | logistics-flow.md, шаг 6 |
| Сверка перед подачей: ДТ ↔ инвойс ↔ упаковочный лист ↔ коносамент ↔ ПИ | logistics-flow.md |
| Инвойс ↔ ДТ: стоимость и валюта точно; количество по позициям точно (допустима группировка); наименование по смыслу; отправитель и получатель по Справочнику | матрица сверки, решает декларант |
| Коносамент ↔ ПИ: номер коносамента, контейнер, места, брутто | матрица сверки, решает брокер |
| ДТ ↔ платёжка: код ТН ВЭД и наименование контрагента точно | матрица сверки, решает финансист; в MVP платёжки нет |
| Код ТН ВЭД не подсказываем, решает декларант | logistics-flow.md, расширение «позже» |
| ПИ сверяем, только если получим к ней доступ | logistics-flow.md, шаг 4 |

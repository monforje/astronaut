## Экраны и компоненты

- [ ] Кнопка «Подготовить пакет» в карточке (активна, когда документы сверены)
- [ ] Экран пакета: список включённых данных, выбор брокера, скачать и отправить
- [ ] Загрузка ДТ и экран сверки ДТ с остальными документами
- [ ] Отметка «замечания отправлены брокеру»

## Состояния каждого экрана

Пусто · не готово (не хватает данных) · пакет готов · отправлен · ДТ загружена · есть расхождения · всё сошлось.

## Какие фейк-данные нужны

Из [fake-data.md](../fake-data.md): ДТ с расхождением в позиции 3, инвойс, упаковочный лист, драфт коносамента, ПИ.

## Место в боковом меню

См. [side-nav.md](../side-nav.md). Живёт в: вкладка «Документы» карточки груза (раздел «Пакет для брокера»).

# Акселератор ДВФУ: аудит нашего состояния

Здесь ведём аудит того, где мы находимся на акселераторе ДВФУ: что сделано, что осталось, какие сроки и требования.

## Правило направления

**Информация идёт сюда, но не отсюда.** Ничего из этой папки не переносим в `idea/product/`, `idea/skelet/`, лендинг, демо или посты. Папка — только для учёта состояния на акселераторе.

Если из аудита вырастает решение или вопрос по продукту, его формулируем заново в `idea/skelet/decisions.md` / `idea/questions.md` своими словами, без ссылок на эту папку.

Недостающие данные помечаем `[TODO]`, ничего не выдумываем.

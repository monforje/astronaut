# Акселератор ДВФУ: аудит нашего состояния

Здесь ведём аудит того, где мы находимся на акселераторе ДВФУ: что сделано, что осталось, какие сроки и требования.

## Правило направления

**Информация идёт сюда, но не отсюда.** Ничего из этой папки не переносим в `idea/product/`, `idea/skelet/`, лендинг, демо или посты. Папка — только для учёта состояния на акселераторе.

Если из аудита вырастает решение или вопрос по продукту, его формулируем заново в `idea/skelet/decisions.md` / `idea/questions.md` своими словами, без ссылок на эту папку.

Недостающие данные помечаем `[TODO]`, ничего не выдумываем.

## Карта

- `README.md` — этот файл.
- `channel.md` — ссылка на канал акселератора, сводка программы и дедлайнов, открытые вопросы.
- `message-khakimovna.md` — черновик сообщения Маргарите Хакимовне: просим контакты компаний для пилота и интервью.
- `project-form.html` — заполненная анкета проекта для платформы «Университет 2035» (поля формы, источники, допущения по финансам); открывать в браузере, у каждого поля кнопка «копировать».
- `message-lyubushkina.md` — черновик сообщения Арине Любушкиной (потенциальный лидогенератор): перерегистрировать проект как Astronaut и попросить контакты, с упоминанием Вячеслава.
- `astronaut-pilot-deck.pdf` — короткая презентация для компаний-пилотов (5 слайдов, 16:9): четыре гипотезы с порогами из `idea/questions.md`, что получает пилот, сравнение с рынком из `differentiators.md`, условия и контакты. Слово MVP не используется, новых цифр нет.
- `pilot-deck/` — исходник дека: `deck.html` (бренд и шрифты по относительным путям из `idea/skelet/brand/`), `img/` (скриншот карточки груза из `idea/mvp/prototype/`), `build.sh` — сборка PDF: `bash idea/accelerator/pilot-deck/build.sh`.
- `message-alekseeva.md` — черновик сообщения Евгении Алексеевой (Сколково, Фонд содействия инновациям в Приморском крае), та же просьба, без упоминания Вячеслава.

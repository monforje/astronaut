# Доклад по дисциплине: Astronaut

Доклад на 10–12 минут и 5 минут вопросов, 13 слайдов, по критериям курса («8 вопросов простым языком»). Это учебный материал: наружу к клиентам и в `idea/product/` ничего отсюда не переносим.

Правило курса: каждая цифра помечена «источник» или «допущение». Все цифры и откуда они взяты: [numbers.md](numbers.md).

## Карта

- `slides.pdf` — презентация, 13 слайдов 16:9. Исходник `slides.html`.
- `handout.pdf` — раздатка, 1 страница A4: цифры, допущения, решение. Исходник `handout.html`.
- `text.pdf` — план и текст для чтения (около 11 минут вслух). Собирается из `plan.md` и `speech.md`; `text-head.html` — стили.
- `plan.md` — план по слайдам с таймингом, соответствие критериям курса, подготовка к вопросам.
- `speech.md` — текст доклада по слайдам.
- `numbers.md` — все цифры с метками, расчёты, сценарии.
- `build.sh` — собирает три PDF: `bash idea/course-talk/build.sh`. Превью слайдов в PNG: `PREVIEW=1 bash idea/course-talk/build.sh` (папка `preview/`, в git не нужна).

После правки цифр: поменять в `numbers.md`, затем в `slides.html`, `handout.html`, `speech.md`, `plan.md`, и пересобрать.

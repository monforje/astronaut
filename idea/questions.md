## Проверить на разговорах

План: 8–10 разговоров с экспедиторами из [первой очереди](skelet/audience/fit.md#кому-идём-в-первую-очередь). На каждом просим показать реальный комплект документов одной сделки. Порог — сколько разговоров из 10 должны подтвердить гипотезу, чтобы мы её оставили. Сценарий разговора — [product/08-intervyu.md](product/08-intervyu.md).

| Вопрос | Что проверяет | Порог |
|---|---|---|
| Кто сверяет документы сегодня, сколько времени уходит, кто платит за ошибку? | Главное отличие и кто покупатель | ≥ 5 из 10: сверка — заметная ручная работа экспедитора, а ошибки стоят ему денег |
| Сколько ЭТрН и других ЭПД отклонили с сентября и почему? | Боль «документы без расхождений» | ≥ 4 из 10: отклонения есть из-за реквизитов, адресов, массы |
| Есть ли дубли контрагентов и товаров, мешают ли они? | П2 «один справочник» | ≥ 4 из 10 называют дубли проблемой; иначе П2 уходит из первой продажи |
| Кто пишет обмены между системами, как часто они падают, как об этом узнают? | П1 «обмены, которые не ломаются молча» | ≥ 5 из 10: обмены самописные и падают незаметно |
| Сколько звонков и писем «где груз» в день? | Б «где мой контейнер» | ≥ 5 из 10 называют это нагрузкой; иначе трекинг уходит из MVP |
| Кто принимает решение о покупке: собственник, директор, главбух, ИТ? | Кому продаём | — собираем картину |
| Кто подаёт ПИ и ДТ: свой брокер или внешний? | Можно ли сверять с ПИ и ДТ | — |
| В какой доле сделок экспедитор сам делает букинг и видит драфт коносамента? | Сверка драфта до выпуска | — |
| Какая доля сделок с иностранными контрагентами? | Влияние исключения из ЭПД | — |
| Какие системы стоят (1С какой конфигурации, БИТ.Экспедирование, CRM, Excel)? | Какие коннекторы нужны первыми | — |
| Сколько готовы платить и за что: подписка, за документ, за внедрение? | Модель денег | — |
| Готовы ли держать данные 1С в нашем облаке на российском хостинге? Что для них условие «да»? | Модель поставки «Старта» | ≥ 5 из 10 «да» при российском хостинге; иначе «Старт» тоже нужно ставить на их сервер |
| Называем цены из [product/05-stoimost.md](product/05-stoimost.md): платформа 6 120 ₽, распознавание 8 990 ₽, сверка 12 000 ₽ в месяц, подключение 11 700 ₽. Дорого, дёшево, нормально? Что бы вы убрали? | Цены и состав «Старта» | ≥ 3 из 10 готовы к пилоту по этим ценам со скидкой |
| Достаточно ли «до 100 сделок в месяц» в тарифе? Сколько контейнеров и деклараций у вас в месяц? | Объём тарифа | — |
| Что для вас важнее в пилоте: скидка, ранний доступ, прямая связь с командой, гарантия результата? | Набор условий для первых трёх пилотов | — |

## Проверить письмами: доступ к данным

Блокеры MVP. Пишем параллельно с разговорами.

- [ ] **Контур, Saby:** API для ЭПД, условия, цена.
- [ ] **Альта-Софт:** формат обмена данными для ДТ (выгрузка пакета, получение ДТ для сверки).
- [ ] **ГосЛог:** есть ли API реестра экспедиторов и перевозчиков.
- [ ] **Росаккредитация:** доступ к реестру сертификатов и деклараций.
- [ ] **ВМТП, ВСК, Пасифик Лоджистик, СВХ:** дадут ли API или выгрузку событий по контейнерам.
- [ ] **Агрегатор трекинга** (CargoTime и др.): условия API.

## Проверить у юриста

- [ ] Точная формулировка обязанностей экспедитора по 140-ФЗ про сведения о грузе.
- [ ] К каким документам применяется исключение из ЭПД для сделок с иностранцами (приказ Минтранса, номера в источниках расходятся: № 115 и № 262).
- [ ] Схема работы AI с данными: анонимизация, токенизация, трансграничная передача по 152-ФЗ.
- [ ] Обязательна ли ПИ в свободном порту Владивосток по действующей редакции 212-ФЗ.
- [ ] Нужен ли реестр российского ПО для крупных клиентов (FESCO, ВМТП, ВСК), как и когда вносить.
- [ ] Размещение данных клиентов «Старта» у нас в облаке: российский хостинг, локализация, договор поручения обработки персональных данных, роли сторон (оператор или обработчик).
- [ ] Можно ли называть пилотов в материалах («первые клиенты») и какое согласие для этого нужно.

## Решить нам

- [ ] **Себестоимость:** серверы и российский хостинг, языковые модели, поддержка, внедрение. Без неё прайс из [product/05-stoimost.md](product/05-stoimost.md) клиентам не публикуем.
- [ ] **Перепроверить рыночные цены у поставщиков:** AI Декларант (4 990 и 9 990 ₽ при проверке 03.11.2026 не подтвердились), Fastsol CRM (цена из обзора, не с сайта), Контур.Логистика (тарифы), интеграции 1С на заказ у студий.
- [ ] **Цена «Сверки» (12 000 ₽ в месяц):** рынка нет, назначена по пользе. Проверить готовность платить на интервью.
- [ ] **Цены расширений, которые выйдут позже:** статус груза, ТН ВЭД, аналитика, качество данных, помощник для клиентов.
- [ ] **Объём в тарифе «Старт»:** сейчас «до 100 сделок в месяц» и что стоит сверх.
- [ ] **Рыночный эксклюзив для пилотов:** сейчас не обещаем, потому что первые пилоты конкурируют между собой. Решить, продавать ли его отдельно и за сколько.
- [ ] **Пилот:** какая одна сверка и какой критерий успеха. Срок и цена уже есть: 4 недели, −30%, гарантия результата ([product/05-stoimost.md](product/05-stoimost.md#первые-три-пилота)).
- [ ] **Франчайзи 1С:** партнёры или конкуренты? Они обслуживают наших целей и пишут им обмены; AI-агент, который «заменяет 1С-ника», может их отпугнуть.
- [ ] **Размер рынка:** сколько экспедиторов морского импорта по РФ и ДФО (по реестру экспедиторов ГосЛога).
- [ ] **Оплата лидгенераторам:** сумма за один состоявшийся разговор.
- [ ] **Подпись отправителя в письмах:** имя, должность, телефон, Telegram.
- [ ] **Демо-сайт и сквозной пример:** в моках `frontend/demo-site` пока нет контейнера MSKU1234567 и Ромашки, о которых рассказывает лендинг. Добавить ([frontend/landing/PLAN.md](../frontend/landing/PLAN.md#открытые-вопросы)).
- [ ] **DNS:** кто принимает решения по ИТ и закупкам в логистике и какие интеграции они пишут сами (см. [product/06-kompanii.md](product/06-kompanii.md)).

# Пост 2: сделали лендинг

Пост про первую версию лендинга и его визуал. Цель: показать, что появилась страница, и собрать реакцию на неё.

| Файл | Что |
|---|---|
| `post.md` | Текст для ручной вставки в Telegram, 761 знак из 1024 |
| `post.html` | Тот же текст в Telegram HTML |
| `preview.html` | Исходник картинки: заголовок и скриншот лендинга |
| `shot.png` | Скриншот первого экрана лендинга 1440×900 со стенда |
| `preview.png` | Готовая картинка 1280×1024 |
| `album/` | Альбом из 4 картинок для поста: первый экран, «Путь одного контейнера», агент, подключения. Первая картинка с подписью |
| `shots/` | Сырые скриншоты секций со стенда (1440 px, все блоки показаны) |

Пересобрать скриншот (стенд должен работать, `task start -- -d` в `frontend/landing`):

```bash
google-chrome --headless=new --no-sandbox --ignore-certificate-errors --hide-scrollbars \
  --window-size=1440,900 --virtual-time-budget=6000 --screenshot=shot.png https://landing.astronaut.localhost/
```

## Источники

Состав страницы из `frontend/landing/PLAN.md`, пример про контейнер MSKU1234567 из `idea/skelet/brand/messaging/story.md`.

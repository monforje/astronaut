# content/

Материалы для публикации: тексты постов, картинки, файлы. Одна папка на материал: `NNN-slug/` (например `001-znakomstvo/`). Папка `brand/` — симлинк на `../idea/skelet/brand`, оттуда берём логотипы, шрифты и цвета.

## Что лежит в папке поста

| Файл | Что |
|---|---|
| `post.md` | Текст для ручной вставки в Telegram (см. ниже) |
| `post.html` | Тот же текст в Telegram HTML, для отправки через бота или API |
| `preview.html` | Исходник картинки, берёт шрифты и логотип из `../brand/` |
| `preview.png` | Готовая картинка, её прикрепляем к посту как фото |
| `README.md` | Что в папке, источники фактов, `[TODO]` |

По необходимости (пример — `002-lendos/`):

| Файл | Что |
|---|---|
| `shot.png`, `shots/` | Скриншоты со стенда (`https://landing.astronaut.localhost`, стенд поднят `task start -- -d`); команда пересъёмки — в README поста |
| `album/` | Альбом вместо одной картинки: файлы `1-…png`, `2-…png` по порядку, подпись к первой |

Текст поста пишем один раз и держим в двух форматах синхронно. Правим один файл, правим и второй.

## Telegram: как вставить текст

HTML в окно Telegram вставить нельзя, он покажется тегами. Два пути:

1. **Руками, из `post.md`.** Telegram Desktop сам превращает разметку при отправке: `**жирный**`, `__курсив__`, `~~зачёркнутый~~`, `` `код` ``, `||спойлер||`. Вставляешь текст как есть, жмёшь отправить. Ссылки так не сделать: выдели слово и нажми Ctrl+K. В мобильном приложении разметку набирают через меню выделения текста.
2. **Через бота или API, из `post.html`.** `parse_mode: "HTML"`, теги `<b>`, `<i>`, `<code>`, `<a href>`, `<blockquote>`. Так публикует MCP `telegram-channel` (`sendPhoto` / `sendMessage`).

Пост с картинкой: подпись к фото не длиннее 1024 знаков без тегов. Длиннее: отправляем текст отдельным сообщением или без фото.

## Правила текста

Голос и запреты: [idea/skelet/brand/messaging/voice.md](../idea/skelet/brand/messaging/voice.md), тон для Telegram там же. Коротко:

- язык клиента: груз, декларация, накладная, 1С; без «шина», «мастер-данные», «коннектор»;
- без длинных тире, без «не X, а Y», без «революционный», «инновационный», «под ключ»;
- цифры только проверенные, остальное `[TODO]`; клиентов и кейсов пока нет, так и говорим;
- не обещаем быструю доставку и снижение ставок;
- факты берём из [idea/product/10-shpargalka.md](../idea/product/10-shpargalka.md).

## Превью

Размер 1280×1024, светлый фон `#FBF5EB`, без рамок, карточек и теней. Тёмно-синий `#082F53` для текста, бирюзовый `#00D4D0` как акцент, оранжевый `#FF9455` только точечно. Шрифты Onest и Fira Code. Рендер:

```bash
google-chrome --headless=new --no-sandbox --allow-file-access-from-files --hide-scrollbars \
  --window-size=1280,1024 --virtual-time-budget=3000 --screenshot=preview.png file://$PWD/preview.html
```

После рендера открыть PNG и проверить глазами: переносы, наложения, обрезки.
